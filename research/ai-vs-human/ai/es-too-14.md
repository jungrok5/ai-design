# 브라우저 지원

이 라이브러리는 최신 웹 표준을 기준으로 개발되었으며, 주요 에버그린(evergreen) 브라우저에서 별도 설정 없이 동작합니다. 이 문서에서는 공식 지원 범위, 빌드 산출물별 호환성, 구형 환경에서 사용하는 방법을 설명합니다.

## 지원 브라우저

아래 표는 공식 지원 대상인 브라우저와 최소 버전입니다. 이 버전 이상에서는 모든 API가 자동화 테스트를 통과합니다.

| 브라우저 | 최소 버전 | 비고 |
| --- | --- | --- |
| Chrome | 90 | Android용 Chrome 포함 |
| Edge | 90 | Chromium 기반 버전만 지원 |
| Firefox | 88 | ESR 최신 버전 포함 |
| Safari | 14 | iOS Safari 14 이상 포함 |
| Samsung Internet | 15 | |
| Opera | 76 | |

Internet Explorer는 어떤 버전도 지원하지 않습니다. 레거시 Edge(EdgeHTML 엔진)도 지원 대상이 아닙니다.

## 서버 측 런타임

브라우저 외에 다음 런타임도 지원합니다.

- **Node.js**: 18 이상 (LTS 버전 권장)
- **Deno**: 1.30 이상
- **Bun**: 1.0 이상

DOM에 의존하는 일부 함수(`debounceFrame`, `observeVisibility` 등)는 서버 환경에서 호출하면 아무 동작도 하지 않고 `undefined`를 반환합니다. 이때 예외는 발생하지 않습니다.

## 빌드 산출물별 호환성

패키지는 사용 환경에 맞춰 고를 수 있도록 세 가지 형태로 배포됩니다.

| 파일 | 형식 | 대상 문법 | 용도 |
| --- | --- | --- | --- |
| `dist/index.mjs` | ES 모듈 | ES2020 | 번들러, 최신 브라우저 |
| `dist/index.cjs` | CommonJS | ES2020 | Node.js `require` |
| `dist/index.legacy.js` | UMD | ES2015 | `<script>` 태그, 구형 환경 |

번들러(Vite, webpack, Rollup 등)를 사용한다면 `package.json`의 `exports` 필드를 통해 적절한 파일이 자동으로 선택됩니다. 트리 셰이킹은 ES 모듈 빌드에서만 완전하게 동작합니다.

## 필요한 런타임 기능

라이브러리는 다음 기능이 기본으로 제공된다고 가정합니다. 지원 브라우저에서는 모두 기본 제공됩니다.

- `Promise`, `async`/`await`
- `Map`, `Set`, `WeakMap`
- 옵셔널 체이닝(`?.`), 널 병합 연산자(`??`)
- `Object.fromEntries`, `Array.prototype.flat`
- `globalThis`

## 구형 환경에서 사용하기

지원 범위보다 오래된 브라우저에서 사용해야 한다면 다음 순서로 대응하는 것을 권장합니다.

1. **레거시 빌드 사용**: `dist/index.legacy.js`는 ES2015 문법으로 트랜스파일되어 있어 Safari 12, Chrome 60 수준에서도 파싱됩니다.
2. **폴리필 추가**: 레거시 빌드는 문법만 변환하며 내장 객체를 보완하지 않습니다. `core-js` 등을 이용해 위에 나열한 런타임 기능을 직접 보완해야 합니다.

```js
import 'core-js/stable/object/from-entries';
import 'core-js/stable/array/flat';
import { chunk, deepMerge } from 'your-utils/legacy';
```

3. **번들러에서 재트랜스파일**: Babel을 사용한다면 `node_modules` 내 이 패키지를 변환 대상에 포함하고 `browserslist` 설정에 맞게 변환하세요.

> **주의**: 레거시 빌드와 폴리필 조합은 공식 테스트 대상이 아닙니다. 동작은 최선의 노력(best effort) 수준으로만 보장되며, 관련 이슈는 낮은 우선순위로 처리됩니다.

## 지원 정책

- 지원 범위는 **메이저 버전 업데이트에서만** 변경됩니다. 마이너·패치 릴리스에서 최소 버전을 올리지 않습니다.
- 메이저 업데이트에서 지원을 중단할 때는 최소 한 개 마이너 버전 전에 변경 로그와 콘솔 경고로 미리 안내합니다.
- 일반적으로 출시된 지 2년이 넘었고 전 세계 점유율이 0.5% 미만인 브라우저 버전은 다음 메이저 버전에서 지원을 중단합니다.

## 문제 보고

지원 브라우저에서 예상과 다르게 동작한다면 이슈를 등록할 때 다음 정보를 포함해 주세요.

- 브라우저 이름과 정확한 버전, 운영체제
- 사용한 빌드 산출물(`mjs`, `cjs`, `legacy`)
- 문제를 재현할 수 있는 최소 코드

재현 가능한 예제가 있으면 문제를 훨씬 빠르게 확인하고 수정할 수 있습니다.
