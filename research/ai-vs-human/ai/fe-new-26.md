# 프론트엔드 월간 뉴스레터 — 2023-09

> 이번 호는 런타임 경쟁과 프레임워크 반응성 모델의 변화가 중심입니다. Bun이 정식 버전을 냈고, Svelte는 차기 메이저 버전의 방향을 공개했습니다. 브라우저 쪽에서도 CSS 기능이 많이 추가됐습니다.

---

## 🔥 이달의 헤드라인

### Bun 1.0 정식 출시

9월 8일 **Bun 1.0**이 출시됐습니다. Bun은 Zig로 작성된 JavaScript 런타임으로, 엔진은 JavaScriptCore를 씁니다. 런타임 외에 패키지 매니저, 번들러, 테스트 러너도 함께 들어 있습니다.

- `bun install`은 npm·yarn보다 훨씬 빠르다고 발표됐습니다.
- TypeScript와 JSX를 별도 설정 없이 바로 실행할 수 있습니다.
- Node.js API 호환성을 높이는 데 집중해, 기존 프로젝트를 옮기기 쉬워졌습니다.

다만 Windows 지원은 아직 실험 단계이고, 일부 Node API는 호환되지 않습니다. 운영 환경에 바로 쓰기보다 **로컬 개발 도구나 테스트 러너로 먼저 써 보는 것**을 권합니다.

### Svelte 5 "Runes" 공개

9월 20일 Svelte 팀이 블로그 글 *Introducing runes*에서 Svelte 5의 새 반응성 모델을 공개했습니다. 지금까지는 `let` 선언과 `$:` 구문으로 반응성을 암묵적으로 처리했습니다. 앞으로는 `$state`, `$derived`, `$effect` 같은 **룬(rune)**으로 명시적으로 선언합니다.

```svelte
<script>
  let count = $state(0);
  let double = $derived(count * 2);
</script>

<button onclick={() => count++}>{count} / {double}</button>
```

내부적으로는 시그널(signal) 기반으로 바뀝니다. 그래서 `.svelte` 파일 밖의 `.svelte.js` 파일에서도 같은 방식으로 반응성을 쓸 수 있습니다. Solid, Preact Signals, Angular Signals, Vue의 ref처럼 생태계 전반이 **시그널로 모이는 흐름**이 이번 발표로 더 뚜렷해졌습니다.

## 🌐 브라우저 업데이트

### Chrome 117 (9월 12일)

- **CSS Subgrid**가 지원됩니다. 이제 주요 브라우저 세 곳 모두 서브그리드를 쓸 수 있습니다.
- **`@starting-style`**과 **`transition-behavior: allow-discrete`**가 추가됐습니다. 그래서 `display: none` 상태에서 나타나는 요소에도 진입 애니메이션을 CSS만으로 줄 수 있습니다.
- 배열을 키별로 묶는 **`Object.groupBy` / `Map.groupBy`**가 지원됩니다.

### Safari 17 (9월 18일)

macOS Sonoma와 iOS 17에 맞춰 출시됐습니다.

- macOS에서 웹사이트를 **Dock에 웹 앱으로 추가**할 수 있습니다.
- JPEG XL 이미지 지원, Managed Media Source, `font-size-adjust` 등 기능이 많이 추가됐습니다.

### Firefox 117 · 118

- 8월 말에 나온 117에서 **CSS 중첩(Nesting)**이 기본으로 켜졌습니다. 이제 주요 브라우저에서 모두 네이티브 CSS 중첩을 쓸 수 있습니다.
- 9월 말에 나온 118에는 기기 안에서 동작하는 페이지 번역 기능이 들어갔습니다.

## 🛠 프레임워크 & 도구

### Next.js 13.5

9월 19일 출시됐습니다. 새 기능보다 **성능 개선**에 초점을 맞춘 릴리스입니다. 공식 발표 수치는 다음과 같습니다.

- 로컬 서버 시작 속도 약 22% 향상
- HMR 약 29% 향상
- 메모리 사용량 약 40% 감소

여기에 `optimizePackageImports` 옵션이 추가됐습니다. 아이콘 라이브러리처럼 큰 패키지를 불러올 때 필요한 모듈만 자동으로 가져와 줍니다.

### Node.js 20.6

- `--env-file` 플래그가 추가돼, dotenv 없이도 `.env` 파일을 읽을 수 있습니다.
- `module.register()` API가 들어와 커스텀 로더 등록 방식이 정리됐습니다.

### Deno 1.37

**Jupyter 노트북 커널**을 기본으로 지원합니다. TypeScript로 데이터를 살펴보거나 프로토타입을 만들기가 편해졌습니다.

### Biome

Rome 프로젝트를 이어받은 커뮤니티 포크 **Biome**이 활발하게 릴리스를 내고 있습니다. Rust로 만든 포매터 겸 린터이고, Prettier와 높은 호환성을 목표로 합니다. ESLint와 Prettier 조합을 대체할 후보로 주목받고 있습니다.

## 📌 지난달 돌아보기

- **TypeScript 5.2** (8월 말): `using` 선언으로 명시적 리소스 관리를 지원합니다. 파일 핸들이나 DB 연결 같은 리소스를 정리하는 코드가 단순해집니다.
- **Astro 3.0** (8월 말): View Transitions API를 기본으로 지원합니다. MPA에서도 SPA처럼 부드러운 페이지 전환을 쉽게 만들 수 있습니다.

## 📊 커뮤니티 소식

**State of HTML 2023** 설문이 처음 열렸습니다. State of JS·CSS를 만드는 팀이 진행하며, 폼, 접근성, 웹 컴포넌트, 새 HTML 요소 사용 현황 등을 묻습니다. 결과는 브라우저 벤더가 기능 우선순위를 정할 때 참고하는 자료가 되니 참여해 보시길 권합니다.

## ✍️ 편집자 한마디

9월 소식을 세 가지로 정리하면 다음과 같습니다.

1. **런타임 경쟁:** Node, Deno, Bun이 서로의 장점을 빠르게 흡수하고 있습니다.
2. **시그널 확산:** 반응성 모델이 프레임워크를 가리지 않고 시그널로 모이고 있습니다.
3. **CSS의 확장:** 중첩, 서브그리드, `@starting-style`처럼 예전에는 전처리기나 JS가 필요했던 일을 이제 브라우저가 직접 처리합니다.

새 도구를 무조건 도입하기보다는, 우리 프로젝트에서 **이미 쓰고 있는 의존성 중 무엇을 덜어낼 수 있을지** 살펴보면 좋겠습니다.
