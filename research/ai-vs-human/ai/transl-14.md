# CSS 선택자

CSS 선택자(selector)는 스타일을 적용할 HTML 요소를 고르는 패턴입니다. 선택자를 사용하면 문서의 특정 요소나 요소 묶음을 지정해 글꼴, 색, 배치 같은 속성을 설정할 수 있습니다. 선택자는 규칙 집합(rule set)의 앞부분에 위치하며, 그 뒤의 중괄호 안에 선언 블록이 옵니다.

```css
h1 {
  color: navy;
}
```

## 기본 선택자

**타입 선택자**는 요소 이름으로 대상을 고릅니다. 같은 이름의 모든 요소에 스타일이 적용됩니다.

```css
p {
  line-height: 1.6;
}
```

**클래스 선택자**는 점(`.`)으로 시작하며, `class` 속성 값이 일치하는 요소를 고릅니다. 한 요소가 여러 클래스를 가질 수 있고, 여러 요소가 같은 클래스를 공유할 수도 있어 재사용성이 높습니다.

```css
.warning {
  border-left: 4px solid orange;
}
```

**아이디 선택자**는 샵(`#`)으로 시작하며, `id` 속성 값과 일치하는 요소를 고릅니다. 문서 안에서 `id` 값은 하나여야 하므로 한 요소만 선택됩니다.

**전체 선택자**(`*`)는 모든 요소를 고릅니다. 초기화 스타일을 적용할 때 자주 쓰이지만, 범위가 넓어 남용하면 성능과 유지 관리에 부담이 됩니다.

## 속성 선택자

속성 선택자는 대괄호(`[ ]`) 안에 속성 조건을 적습니다.

| 형태 | 의미 |
| --- | --- |
| `[disabled]` | 해당 속성이 있는 요소 |
| `[type="email"]` | 속성 값이 정확히 일치하는 요소 |
| `[href^="https"]` | 값이 지정한 문자열로 **시작하는** 요소 |
| `[href$=".pdf"]` | 값이 지정한 문자열로 **끝나는** 요소 |
| `[class*="icon"]` | 값에 문자열이 **포함된** 요소 |

```css
a[href^="https"]::after {
  content: " ↗";
}
```

값 뒤에 `i`를 붙이면 대소문자를 구분하지 않습니다(예: `[lang="en" i]`).

## 결합자

결합자는 선택자들 사이의 관계를 지정합니다.

- **자손 결합자**(공백): `article p`는 `article` 안 어디에 있든 모든 `p`를 고릅니다.
- **자식 결합자**(`>`): `ul > li`는 직계 자식만 고릅니다.
- **인접 형제 결합자**(`+`): `h2 + p`는 `h2` 바로 다음에 오는 `p`만 고릅니다.
- **일반 형제 결합자**(`~`): `h2 ~ p`는 같은 부모 아래에서 `h2` 뒤에 오는 모든 `p`를 고릅니다.

```css
ul > li + li {
  margin-top: 0.5rem;
}
```

## 가상 클래스

가상 클래스(pseudo-class)는 요소의 **상태**나 **위치**에 따라 선택합니다. 콜론(`:`) 하나로 시작합니다.

- 사용자 상호작용: `:hover`, `:focus`, `:focus-visible`, `:active`
- 상태: `:checked`, `:disabled`, `:valid`, `:invalid`
- 구조: `:first-child`, `:last-child`, `:nth-child(2n+1)`, `:not(.hidden)`

`:is()`와 `:where()`는 여러 선택자를 묶어 간결하게 쓸 수 있게 해 줍니다. 둘의 차이는 우선순위에 있으며, `:where()`는 우선순위가 0입니다.

```css
:is(h1, h2, h3) {
  font-family: "Pretendard", sans-serif;
}
```

## 가상 요소

가상 요소(pseudo-element)는 문서에 실제로 없는 **부분**을 선택합니다. 이중 콜론(`::`)으로 표기하며, `::before`, `::after`, `::first-line`, `::first-letter`, `::marker`, `::placeholder` 등이 있습니다. `content` 속성과 함께 쓰면 요소 앞뒤에 내용을 덧붙일 수 있습니다.

## 선택자 우선순위

여러 규칙이 같은 요소에 충돌하면 브라우저는 **우선순위(specificity)**가 높은 규칙을 적용합니다. 우선순위는 대략 다음 순서로 비교합니다.

1. 인라인 스타일과 `!important` 선언
2. 아이디 선택자의 개수
3. 클래스, 속성 선택자, 가상 클래스의 개수
4. 타입 선택자와 가상 요소의 개수

우선순위가 같으면 문서에서 나중에 나온 규칙이 적용됩니다. 우선순위를 지나치게 높이면 나중에 스타일을 덮어쓰기 어려우므로, 가능한 한 클래스 선택자 중심으로 설계하는 것이 좋습니다.
