# 🗞️ 프론트엔드 월간 소식 — 2023-03

안녕하세요, 독자 여러분! 3월에는 굵직한 발표가 유난히 많았습니다. React 공식 문서가 새로 문을 열었고, TypeScript 5.0이 정식으로 나왔습니다. iOS Safari에서는 웹 푸시를 쓸 수 있게 됐습니다. 이번 호에서는 이 가운데 실무에 바로 영향을 주는 소식을 골라 정리했습니다.

## 📌 이달의 헤드라인

### 1. React 새 공식 문서 `react.dev` 공개

3월 16일, 오랫동안 베타였던 새 공식 문서가 **react.dev** 도메인으로 정식 공개되었습니다. 이번 개편에서 가장 크게 바뀐 점은 **함수 컴포넌트와 Hooks를 기본으로 설명한다**는 것입니다. 클래스 컴포넌트는 "레거시 API" 영역으로 옮겨졌습니다.

- 대화형 예제(샌드박스)와 연습 문제가 문서 곳곳에 들어갔습니다.
- `useEffect`를 언제 쓰지 말아야 하는지 다루는 「You Might Not Need an Effect」 같은 글이 많은 호응을 얻었습니다.
- 새 프로젝트를 시작할 때 Create React App 대신 **Next.js, Remix, Gatsby 같은 프레임워크**를 권장한다고 명시했습니다. 이를 두고 커뮤니티에서 활발한 토론이 이어졌습니다.

> 💡 팀에 React를 새로 배우는 사람이 있다면, 이제 레거시 문서 말고 react.dev의 "Learn" 섹션을 먼저 권해 주세요.

### 2. TypeScript 5.0 정식 출시

같은 날 **TypeScript 5.0**도 나왔습니다. 메이저 버전이 바뀐 만큼 변화가 큽니다.

- **ECMAScript 표준 데코레이터 지원**: 기존 `experimentalDecorators`와 별개로, TC39 Stage 3 명세를 따르는 데코레이터를 쓸 수 있습니다.
- **`const` 타입 파라미터**: 제네릭 함수에서 `<const T>`라고 쓰면 인자를 리터럴 타입으로 좁게 추론합니다. 호출하는 쪽에서 `as const`를 붙이지 않아도 됩니다.
- **`--moduleResolution bundler`**: Vite나 esbuild 같은 번들러 환경에 맞춘 모듈 해석 옵션이 추가되었습니다.
- `extends` 옵션에 여러 설정 파일을 배열로 지정할 수 있게 되었습니다.
- 내부 구조를 모듈 기반으로 옮기면서 패키지 용량과 빌드 속도가 함께 개선되었습니다.

일부 옛 옵션은 지원 중단(deprecated) 경고를 띄웁니다. 업그레이드 전에 `tsconfig.json`을 한 번 점검하시길 권합니다.

## 🌐 브라우저 업데이트

### Chrome 111

- **View Transitions API**(같은 문서 안에서 동작)가 정식 지원되었습니다. 이제 SPA에서 페이지 전환 애니메이션을 네이티브로 구현할 수 있습니다.
- **CSS Color Level 4**: `oklch()`, `lab()` 같은 새 색 공간과 `color-mix()`를 지원합니다.
- `sin()`, `cos()` 같은 **CSS 삼각함수**와 `:nth-child(… of S)` 문법이 추가되었습니다.

### Safari 16.4

이번 달 가장 반가운 소식일지도 모릅니다. 3월 말 배포된 Safari 16.4에서 다음이 지원되기 시작했습니다.

- **홈 화면에 추가한 웹 앱에서 Web Push 사용 가능**(iOS/iPadOS). PWA를 운영하는 팀이라면 기다려 온 기능입니다.
- **Badging API**, **Screen Wake Lock API**
- **Import Maps**, **OffscreenCanvas**, 정규식 **lookbehind**
- 미디어 쿼리 범위 문법(`width >= 768px`) 등 다수

크로스 브라우저 호환성 표의 빈칸이 한꺼번에 많이 채워진 업데이트입니다.

### Firefox 111

Origin Private File System(OPFS) 등이 들어갔습니다. 브라우저 안에서 파일을 저장하는 고성능 스토리지 활용 사례가 늘어날 것으로 보입니다.

## 🧰 프레임워크 & 도구

### React Labs: 3월 연구 현황

React 팀이 「React Labs: What We've Been Working On – March 2023」을 공개했습니다. 주요 내용은 다음과 같습니다.

- **React Server Components** 진행 상황과 Next.js App Router 연동
- 메모이제이션을 자동화하는 **React Optimizing Compiler(통칭 React Forget)**
- 화면 밖 UI를 미리 렌더링하는 **Offscreen**(이후 Activity) 개념
- 에셋 로딩, 트랜지션 추적(Transition Tracing)

당장 쓸 수 있는 기능은 아니지만, React가 앞으로 어디로 가는지 가늠할 수 있는 글입니다.

### Vite 4.2

CSS 소스맵 지원이 개선되었고 환경 변수 처리 등이 다듬어졌습니다. 4.x 대에서 꾸준히 안정성을 높이고 있습니다.

### Astro 2.1

실험적 **이미지 서비스(`astro:assets`)**와 **Markdoc** 통합이 추가되었습니다. 콘텐츠 중심 사이트를 만든다면 눈여겨볼 만합니다.

### Nuxt 3.3

개발 서버 성능 개선과 여러 DX 향상이 담긴 마이너 릴리스입니다. Nuxt 3 생태계가 빠르게 자리 잡고 있습니다.

## 🤖 AI와 프론트엔드

3월 14일 **GPT-4**가 공개되었습니다. 22일에는 GitHub가 **Copilot X** 비전을 발표하며 채팅, PR 설명 생성, 문서 Q&A 등을 예고했습니다. 손으로 그린 와이어프레임을 HTML로 바꾸는 데모가 화제가 되었고, "AI가 프론트엔드 개발자를 대체할까?"라는 질문도 다시 떠올랐습니다.
