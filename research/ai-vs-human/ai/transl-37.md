# 필요한 정보를 저장하기 - 변수

프로그래밍에서 **변수**(variable)는 값을 담아 두는 이름 붙은 상자입니다. 이번 글에서는 변수가 무엇인지, JavaScript에서 어떻게 선언하고 사용하는지, 그리고 어떤 종류의 값을 저장할 수 있는지 알아봅니다.

**사전 요구 사항:** 컴퓨터 활용 능력, HTML과 CSS에 대한 기초 지식, JavaScript가 무엇인지에 대한 이해

**목표:** 변수의 개념을 이해하고, 변수를 선언·초기화·갱신하며, 자료형의 차이를 구분할 수 있습니다.

## 변수란 무엇인가요?

변수는 값을 저장하는 컨테이너입니다. 실제 값은 변수 안에 들어 있고, 우리는 그 값을 *이름*으로 불러서 사용합니다. 예를 들어 "Bob"이라는 문자열을 `name`이라는 변수에 저장해 두면, 코드 어디서든 `name`이라고 쓰기만 해도 "Bob"을 꺼내 쓸 수 있습니다.

변수가 유용한 이유는 값이 *바뀔 수 있기* 때문입니다. 게임의 점수, 로그인한 사용자의 이름, 장바구니의 상품 개수처럼 프로그램이 실행되는 동안 달라지는 정보를 다룰 때 변수가 필수적입니다. 만약 변수가 없다면 같은 값을 코드 곳곳에 직접 적어야 하고, 값을 바꾸고 싶을 때마다 모든 위치를 찾아 수정해야 합니다.

## 변수 선언하기

변수를 사용하려면 먼저 **선언**해야 합니다. JavaScript에서는 `let` 키워드 뒤에 원하는 이름을 씁니다.

```js
let myName;
let myAge;
```

이 코드는 `myName`과 `myAge`라는 두 변수를 만듭니다. 아직 값을 넣지 않았으므로 두 변수의 값은 `undefined`입니다.

브라우저의 개발자 도구 콘솔에서 직접 입력해 보세요. 변수 이름만 입력하고 Enter 키를 누르면 현재 값이 출력됩니다. 선언하지 않은 이름을 입력하면 `ReferenceError`가 발생합니다.

### 초기화하기

변수에 처음으로 값을 넣는 일을 **초기화**라고 하며, 등호(`=`) 연산자를 사용합니다.

```js
myName = "Chris";
myAge = 37;
```

선언과 초기화를 한 줄로 합칠 수도 있고, 실무에서는 이 방식을 더 자주 씁니다.

```js
let myDog = "Rover";
```

### 값 갱신하기

초기화한 값은 나중에 다시 바꿀 수 있습니다. 이때는 `let`을 다시 쓰지 않고 이름과 새 값만 적습니다.

```js
let myName = "Chris";
myName = "Bob";
```

`let`을 한 번 더 쓰면 같은 이름을 두 번 선언하는 것이므로 오류가 발생합니다.

## 변수 이름 짓기

변수 이름에는 다음 규칙이 있습니다.

- 문자, 숫자, 밑줄(`_`), 달러 기호(`$`)만 사용할 수 있습니다.
- 숫자로 시작할 수 없습니다.
- 공백을 포함할 수 없습니다.
- `let`, `function`, `class` 같은 예약어는 쓸 수 없습니다.
- 대소문자를 구분합니다. `age`와 `Age`는 서로 다른 변수입니다.

규칙 외에 관례도 있습니다. 여러 단어로 된 이름은 첫 단어를 소문자로 쓰고 다음 단어부터 대문자로 시작하는 **카멜 표기법**(camelCase)을 권장합니다. 또한 이름은 *의미를 알 수 있게* 지어야 합니다. `x`나 `data1`보다 `userAge`, `totalPrice`처럼 쓰면 코드를 읽는 사람이 값의 용도를 바로 알 수 있습니다.

```js
// 좋은 예
let playerScore = 0;
let isLoggedIn = true;

// 나쁜 예
let 1stPlace = 1;   // 숫자로 시작
let my age = 20;    // 공백 포함
let a = 5;          // 의미 불명
```

## const로 상수 선언하기

값이 바뀌지 않아야 한다면 `const`를 사용합니다.

```js
const birthYear = 1990;
birthYear = 2000; // TypeError: 상수에는 다시 값을 할당할 수 없음
```

`const`로 선언한 변수는 반드시 선언과 동시에 초기화해야 하며, 이후 다시 할당할 수 없습니다. 의도치 않은 변경을 막아 주므로, 값을 바꿀 필요가 없다면 `const`를 먼저 고려하는 것이 좋습니다. 값이 바뀌어야 할 때만 `let`을 쓰세요.

### var에 대하여

오래된 코드에서는 `var` 키워드를 자주 볼 수 있습니다. `var`는 `let`이 등장하기 전부터 쓰이던 방식으로, 같은 이름을 중복 선언해도 오류가 나지 않고, 선언하기 전에 사용해도 `undefined`가 되는 *호이스팅* 동작 때문에 버그를 만들기 쉽습니다. 새로 작성하는 코드에서는 `let`과 `const`를 사용하세요.

## 변수에 저장할 수 있는 자료형

변수는 여러 종류의 값을 담을 수 있습니다. 주요 자료형은 다음과 같습니다.

| 자료형 | 설명 | 예시 |
| --- | --- | --- |
| Number | 정수와 소수 모두 포함하는 숫자 | `let age = 30;` |
| String | 따옴표로 감싼 문자열 | `let city = "서울";` |
| Boolean | 참 또는 거짓 | `let isOpen = true;` |
| Array | 여러 값을 하나로 묶은 목록 | `let list = [1, 2, 3];` |
| Object | 이름과 값의 쌍으로 이루어진 구조 | `let car = { brand: "Kia" };` |

### 숫자와 문자열

숫자는 따옴표 없이 씁니다. 문자열은 작은따옴표, 큰따옴표, 백틱 중 하나로 감싸며, 시작과 끝에 같은 종류를 써야 합니다. 따옴표를 붙이면 숫자도 문자열이 됩니다.

```js
let a = 10;     // 숫자
let b = "10";   // 문자열
```

### 배열

배열은 대괄호 안에 쉼표로 값을 나열합니다. 각 값은 0부터 시작하는 **인덱스**로 접근합니다.

```js
const fruits = ["사과", "배", "귤"];
console.log(fruits[0]); // "사과"
fruits[1] = "포도";     // 두 번째 값 변경
```

`const`로 선언한 배열도 내부 요소는 바꿀 수 있습니다. `const`가 막는 것은 변수 자체를 다른 값으로 *재할당*하는 것이지, 배열이나 객체의 내용을 수정하는 것이 아니기 때문입니다.

### 객체

객체는 현실 세계의 사물을 표현할 때 유용합니다. 중괄호 안에 `이름: 값` 쌍을 나열하고, 점(`.`) 표기법으로 접근합니다.

```js
const dog = { name: "Spot", breed: "Dalmatian" };
console.log(dog.name); // "Spot"
```

## 동적 타이핑

JavaScript는 **동적 타입 언어**입니다. 변수를 선언할 때 자료형을 지정하지 않아도 되고, 같은 변수에 나중에 다른 종류의 값을 넣을 수도 있습니다.

```js
let value = 5;
value = "다섯";
```

유연하지만 실수가 생기기 쉬우므로, 한 변수에는 한 가지 종류의 값만 담는 습관을 들이는 것이 좋습니다. 현재 값의 자료형은 `typeof` 연산자로 확인할 수 있습니다.

```js
console.log(typeof 42);       // "number"
console.log(typeof "안녕");   // "string"
console.log(typeof true);     // "boolean"
```

## 주석 활용하기

코드에 설명을 덧붙이고 싶다면 주석을 사용합니다. 한 줄 주석은 `//`, 여러 줄 주석은 `/* ... */`로 작성합니다. 주석은 실행되지 않으며, 변수의 용도나 단위를 기록해 두면 나중에 코드를 다시 볼 때 큰 도움이 됩니다.

```js
// 사용자의 나이 (단위: 세)
let userAge = 25;
```

## 요약

- 변수는 값을 저장하고 이름으로 불러 쓰는 컨테이너입니다.
- `let`으로 선언해 값을 바꿀 수 있고, `const`로 선언하면 재할당할 수 없습니다. 새 코드에서는 `var`를 피하세요.
- 변수 이름은 규칙을 지키고 의미가 드러나도록 카멜 표기법으로 짓습니다.
- 숫자, 문자열, 불리언, 배열, 객체 등 다양한 자료형을 저장할 수 있으며, JavaScript는 동적 타입 언어입니다.
