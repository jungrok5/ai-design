# 프론트엔드 월간 소식 — 2021-02

> 2021년 2월 프론트엔드 생태계에서 있었던 주요 소식을 정리했습니다. 이번 달은 빌드 도구와 타입 시스템 쪽 소식이 많았습니다.

---

## 🗞️ 이달의 헤드라인

### Vite 2.0 정식 출시

2월 중순 **Vite 2.0**이 정식으로 출시되었습니다. 1.x는 Vue 전용 개발 서버에 가까웠습니다. 2.0은 코어를 처음부터 다시 설계해 **특정 프레임워크에 묶이지 않는 빌드 도구**가 되었습니다. React, Preact, Svelte, Lit 등 여러 프레임워크용 템플릿도 공식으로 제공합니다.

주요 변화는 다음과 같습니다.

- **Rollup 호환 플러그인 시스템**: 기존 Rollup 플러그인을 상당수 그대로 쓸 수 있고, Vite 전용 훅으로 개발 서버 동작도 확장할 수 있습니다.
- **esbuild 기반 의존성 사전 번들링**: CommonJS로 배포된 패키지를 미리 ESM으로 변환합니다. 수백 개의 모듈 요청이 한꺼번에 생기는 문제도 해결해 콜드 스타트가 크게 빨라졌습니다.
- **CSS 코드 스플리팅 기본 지원**: 비동기 청크가 쓰는 CSS를 따로 분리해, 그 청크를 불러올 때 함께 로드합니다.
- **실험적 SSR 지원**과 구형 브라우저용 `@vitejs/plugin-legacy` 플러그인도 제공됩니다.

1월에 나온 Snowpack 3.0과 함께, 개발 중에는 번들하지 않는(unbundled) 방식이 확실한 흐름으로 자리 잡고 있습니다. webpack 기반 프로젝트를 당장 옮기기는 어렵더라도, 새로 시작하는 사이드 프로젝트에서 한 번 써 볼 만합니다.

### TypeScript 4.2 릴리스

2월 말 **TypeScript 4.2**가 정식 출시되었습니다. 눈에 띄는 변경 사항은 다음과 같습니다.

- **튜플 중간·앞쪽의 rest 요소**: `[...string[], number]`처럼 rest 요소를 튜플 끝이 아닌 곳에도 둘 수 있습니다.
- **타입 별칭 보존 개선**: 유니온 타입이 에디터 툴팁이나 오류 메시지에서 풀어 쓰이지 않고, 원래 별칭 이름으로 표시되는 경우가 늘었습니다.
- **`abstract` 생성자 시그니처**: `abstract new () => T` 형태로 추상 클래스를 받는 믹스인 패턴을 정확하게 타이핑할 수 있습니다.
- **`--noPropertyAccessFromIndexSignature` 옵션**: 인덱스 시그니처로 선언된 속성은 점 표기법 대신 대괄호 표기법으로만 접근하도록 강제합니다.
- **`in` 연산자 검사 강화**: 우변에 원시 타입이 오면 컴파일 단계에서 오류를 냅니다.

업그레이드하면 타입 오류가 몇 개 새로 보고될 수 있습니다. 대부분 원래 숨어 있던 버그를 잡아 주는 것이니 릴리스 노트의 Breaking Changes 항목을 먼저 확인하세요.

## 🌐 브라우저 소식

### Firefox 86: Total Cookie Protection

2월 23일 출시된 **Firefox 86**에 **Total Cookie Protection**이 들어갔습니다. 웹사이트마다 별도의 '쿠키 항아리'를 두어 서드파티 쿠키로 여러 사이트에 걸쳐 사용자를 추적하지 못하게 막는 기능입니다. 현재는 엄격(Strict) 모드에서 켜집니다. 여러 개의 Picture-in-Picture 창을 동시에 띄우는 기능도 추가되었습니다.

서드파티 쿠키에 기대는 로그인 연동, 임베드 위젯, 분석 스크립트를 운영 중이라면 지금부터 동작을 점검해 두는 게 좋습니다.

### Chrome 88 안정화, Chrome 89 베타

1월 말 배포된 **Chrome 88**에서 CSS **`aspect-ratio`** 속성이 기본으로 켜졌습니다. 이제 패딩 트릭 없이 `aspect-ratio: 16 / 9` 한 줄로 비율을 고정할 수 있습니다. 확장 프로그램 개발자를 위한 Manifest V3 지원도 시작되었고, Flash는 완전히 제거되었습니다.

현재 베타인 **Chrome 89**에는 WebHID, Web Serial, Web NFC(Android) 같은 하드웨어 연동 API가 포함될 예정입니다. 브라우저에서 할 수 있는 일의 범위가 계속 넓어지고 있습니다.

## 🧩 프레임워크·라이브러리 동향

- **React Server Components**: 지난 12월 공개된 RFC와 데모를 두고 커뮤니티 논의가 계속되고 있습니다. 서버에서만 실행되는 컴포넌트로 번들 크기를 줄이자는 아이디어입니다. 아직 실험 단계라 실무에 쓸 수는 없지만, 데이터 페칭 패턴이 앞으로 어떻게 바뀔지 가늠해 볼 수 있습니다.
- **Svelte 생태계**: 공식 애플리케이션 프레임워크인 **SvelteKit**이 공개 베타를 앞두고 막바지 작업 중입니다. 내부적으로 Vite를 사용할 예정이라 이번 Vite 2.0 출시와도 맞물립니다.
- **Vue 3**: 패치 릴리스가 꾸준히 이어지며 안정화되고 있습니다. 주요 UI 라이브러리와 Vue Router, Vuex 등 핵심 패키지도 Vue 3 대응을 거의 마쳐 마이그레이션 부담이 줄었습니다.
- **Deno 1.7**: 1월 릴리스에서 `deno compile`의 크로스 컴파일과 Data URL import 등이 추가되었습니다. 단일 실행 파일 배포가 쉬워진 점이 눈에 띕니다.

## 📊 읽을거리: State of JS 2020

1월에 발표된 **State of JS 2020** 결과를 다시 볼 만합니다. TypeScript는 사용률과 만족도 모두 상위를 유지했습니다. 프런트엔드 프레임워크 부문에서는 Svelte가 높은 만족도로 주목받았습니다. 빌드 도구 부문에서는 webpack이 여전히 압도적이지만, esbuild와 Snowpack 같은 새 도구에 대한 관심도가 빠르게 오르고 있습니다. 이번 달 Vite 2.0 출시와 함께 보면 흐름이 더 잘 보입니다.

## 📅 다가오는 일정

- **ES2021**: `String.prototype.replaceAll`, `Promise.any`, 논리 할당 연산자(`&&=`, `||=`, `??=`), 숫자 구분자(`1_000_000`), `WeakRef`가 올해 중반 표준으로 확정될 예정입니다. 주요 브라우저는 이미 대부분 지원합니다.
- **Node.js 10 지원 종료**: 4월 말 Node.js 10이 수명 종료(EOL)를 맞습니다. CI 환경과 서버 런타임을 14 LTS로 올릴 계획을 세워 두세요.
