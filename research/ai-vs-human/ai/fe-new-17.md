## 1. 브라우저: CSS의 큰 숙제들이 풀리다

### Chrome 105 / 106
8월 말에 나온 Chrome 105에는 **컨테이너 쿼리(`@container`)**와 **`:has()` 의사 클래스**가 함께 들어갔습니다. 그동안 반응형 컴포넌트는 뷰포트 크기만 기준으로 만들 수 있었습니다. 이제는 부모 컨테이너 크기를 기준으로 스타일을 바꿀 수 있어서, 컴포넌트를 어디에 놓아도 같은 방식으로 반응하는 설계가 가능해졌습니다.

```css
.card-wrapper { container-type: inline-size; }

@container (min-width: 400px) {
  .card { display: grid; grid-template-columns: 1fr 2fr; }
}
```

`:has()`는 흔히 '부모 선택자'라고 불립니다. 예를 들어 `form:has(input:invalid)`처럼 자식 상태에 따라 부모 스타일을 바꿀 수 있어서, 지금까지 JavaScript로 처리하던 UI 로직 상당수를 CSS로 옮길 수 있습니다. 9월 말에는 Chrome 106이 이어서 나와 안정화 작업이 계속되었습니다.

### Safari 16
9월 중순 iOS 16과 함께 **Safari 16**이 출시되었습니다. 주요 변경 사항은 다음과 같습니다.

- **컨테이너 쿼리** 지원: Chrome에 이어 두 번째로 지원하는 주요 엔진
- **CSS 서브그리드(subgrid)** 지원: Firefox와 함께 지원
- **AVIF 이미지 포맷** 지원
- **Shared Worker** 재지원과 웹 인스펙터 기능 강화

이로써 컨테이너 쿼리는 Chromium과 WebKit에서 모두 쓸 수 있게 되었습니다. Firefox가 지원하기 전까지는 `@supports`로 점진적 향상을 적용하는 방식을 권장합니다.

### Firefox 105
Firefox 105에서는 `OffscreenCanvas` 지원이 확대되는 등 성능 관련 개선이 이어졌습니다. Interop 2022 대시보드 점수도 브라우저마다 꾸준히 오르고 있어서, 크로스 브라우저 호환성이 확실히 나아지고 있습니다.

## 2. TypeScript 4.9 베타: `satisfies` 연산자

8월 말 TypeScript 4.8 정식 버전이 나왔고, 한 달 뒤 **4.9 베타**가 공개되었습니다. 이번 베타에서 가장 주목받은 기능은 **`satisfies` 연산자**입니다.

```ts
type Colors = "red" | "green" | "blue";
type RGB = [number, number, number];

const palette = {
  red: [255, 0, 0],
  green: "#00ff00",
  blue: [0, 0, 255],
} satisfies Record<Colors, string | RGB>;

palette.green.toUpperCase(); // ✅ string으로 추론 유지
```

타입 주석(`: Type`)을 붙이면 값의 구체적인 타입 정보가 사라집니다. `satisfies`는 값이 타입 조건을 만족하는지 검사하면서도 추론된 구체적인 타입을 그대로 남겨 둡니다. 설정 객체나 디자인 토큰처럼 형태 검증과 정확한 추론이 함께 필요한 곳에서 특히 유용합니다.

이 밖에 다음 기능도 포함되었습니다.
- `in` 연산자를 이용한, 선언되지 않은 속성의 타입 좁히기 개선
- 클래스 **자동 접근자(`accessor`)** 키워드
- `NaN`과 직접 비교하는 코드에 대한 오류 검사

## 3. 업계 소식: Adobe의 Figma 인수 발표

9월 15일 Adobe가 **Figma를 약 200억 달러에 인수한다**고 발표했습니다. Figma는 브라우저 기반 협업 디자인 도구로 시작해, 프론트엔드 개발자와 디자이너가 함께 쓰는 사실상 표준 도구가 되었습니다. 그래서 이 소식은 개발자 커뮤니티에서도 큰 화제가 되었습니다.

커뮤니티에서는 주로 두 가지를 우려했습니다.
- 무료 플랜과 가격 정책이 바뀔 가능성
- 개발자 핸드오프와 플러그인 생태계가 앞으로 어떻게 될지

규제 당국 심사가 남아 있으므로 실제로 무엇이 바뀌는지는 지켜봐야 합니다.

## 4. 빌드 도구와 런타임

- **Vite 3.1**: 7월 Vite 3 출시 뒤 첫 마이너 업데이트입니다. 3.x 계열의 안정성과 개발 서버 성능 개선이 이어졌습니다. Vite를 기본 빌드 도구로 쓰는 프레임워크도 계속 늘고 있습니다.
- **Astro 1.x**: 8월 1.0 정식 출시 이후 빠르게 업데이트되고 있습니다. 콘텐츠 중심 사이트에서 '아일랜드 아키텍처'를 적용한 사례가 많아졌습니다.
- **Deno**: npm 패키지를 가져오는 `npm:` 지정자를 실험적으로 도입한 뒤, Node.js 호환성 개선을 계속하고 있습니다.
- **Bun**: 7월 공개와 8월 투자 유치 이후 커뮤니티 관심이 계속 높습니다. 아직 초기 단계이므로 프로덕션 도입은 신중하게 판단하는 편이 좋습니다.
