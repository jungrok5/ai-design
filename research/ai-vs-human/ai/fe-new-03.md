## 1. React, 서버 컴포넌트를 선보이다

12월 21일, React 팀이 연말 선물처럼 **서버 컴포넌트** 연구 결과를 공개했습니다. 아직 정식 기능이 아니라 실험 단계의 데모와 RFC입니다.

핵심 아이디어는 다음과 같습니다.

- 컴포넌트를 서버에서만 실행해 **클라이언트로 보내는 JS 번들 크기를 줄입니다.**
- 서버 컴포넌트는 데이터 소스(DB, 파일 시스템)에 직접 접근할 수 있습니다.
- 상호작용이 필요한 부분만 기존처럼 클라이언트 컴포넌트로 둡니다.

당장 프로덕션에 도입할 단계는 아닙니다. 다만 "데이터 패칭과 번들 크기를 프레임워크 차원에서 해결하겠다"는 방향이 분명해졌으니, 영상과 RFC를 한 번 읽어 두면 좋겠습니다.

## 2. 런타임과 도구 생태계

### Deno 1.6
- `deno compile`로 스크립트를 **독립 실행 파일**로 묶을 수 있습니다.
- 공식 언어 서버(LSP)가 내장되어 에디터 연동이 한결 매끄러워졌습니다.
- Node.js를 대체하기보다는 "TypeScript가 기본인 보안 중심 런타임"이라는 색깔이 뚜렷해지고 있습니다.

### 빌드 도구의 세대교체
- 10월에 정식 출시된 **webpack 5**의 영속 캐시와 모듈 페더레이션이 실무에서 본격적으로 쓰이기 시작했습니다.
- ESM 기반의 **Snowpack** 같은 "번들 없는 개발 서버"가 주목받고 있습니다. 개발 서버 기동 속도가 체감될 만큼 빠릅니다.

## 3. 브라우저 소식

| 브라우저 | 소식 |
|---|---|
| Firefox 84 | Apple Silicon 네이티브 지원, Flash 지원 제거 |

## 4. 프레임워크·라이브러리 동향

- **TypeScript 4.1**(11월 출시): 템플릿 리터럴 타입, 키 리매핑이 들어왔습니다. 문자열 기반 API를 타입으로 안전하게 다룰 수 있습니다.
- **Angular 11**(11월 출시): 빌드 성능 개선, 실험적 HMR, 폰트 인라이닝을 지원합니다.
- **Tailwind CSS 2.0**(11월 출시): 다크 모드, 확장된 색상 팔레트가 추가되었습니다. 유틸리티 퍼스트 CSS의 확산세가 이어지고 있습니다.
- **Next.js 10**: 이미지 컴포넌트와 자동 최적화로 성능 작업이 한결 쉬워졌습니다.
- **Vue 3**: 생태계(Vuex, Vue Router, Vite 등)가 3 버전에 맞춰 정비되는 중입니다.

## 5. 성능과 웹 품질

구글이 예고한 **Core Web Vitals**의 검색 랭킹 반영이 2021년 상반기로 다가오고 있습니다. 세 가지 지표를 기억해 두세요.

1. **LCP**: 가장 큰 콘텐츠가 그려지는 시간. 목표는 2.5초 이내입니다.
2. **FID**: 첫 입력 지연. 목표는 100ms 이내입니다.
3. **CLS**: 누적 레이아웃 이동. 목표는 0.1 이하입니다.

이미지에 `width`·`height`를 명시하고, 폰트 로딩 전략을 점검하고, 불필요한 메인 스레드 작업을 줄이는 것만으로도 상당히 개선됩니다.

## 6. 이달의 팁: 이미지 지연 로딩

```html
<img src="photo.jpg" loading="lazy" width="640" height="360" alt="설명">
```

`loading="lazy"` 속성은 이제 주요 브라우저에서 널리 쓸 수 있습니다. 화면 밖 이미지는 나중에 불러오고, 크기를 명시해 레이아웃 이동도 막을 수 있습니다. 첫 화면(above the fold) 이미지에는 쓰지 않는 것이 좋습니다.

## 7. 올해를 돌아보며

2020년 프론트엔드를 키워드로 정리하면 이렇습니다.

- **React 17, Vue 3, Angular 11**: 큰 프레임워크가 모두 한 번씩 업데이트되었습니다.
- **webpack 5와 번들러 경쟁**: 빌드 속도가 화두였습니다.
- **TypeScript의 일상화**: 이제 "쓸까 말까"보다 "어떻게 잘 쓸까"를 고민하는 단계입니다.
- **재택 환경에서의 협업**: 원격 코드 리뷰와 디자인 시스템, 문서화의 중요성이 커졌습니다.
