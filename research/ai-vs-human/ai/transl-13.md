# 문법과 자료형

이 장에서는 JavaScript의 기초 문법, 변수 선언, 자료형, 리터럴을 다룹니다.

## 기초

JavaScript는 대부분의 문법을 Java에서 빌려왔지만, Awk, Perl, Python의 영향도 받았습니다.

JavaScript는 **대소문자를 구분**하며 **유니코드** 문자 집합을 사용합니다. 예를 들어 `früh`(독일어로 "이른")라는 단어를 변수 이름으로 쓸 수 있습니다.

```js
const früh = "foo";
```

다만 `Früh`는 `früh`와 다른 변수입니다. 대문자와 소문자가 다르기 때문입니다.

JavaScript에서 명령어는 [구문](/ko/docs/Web/JavaScript/Reference/Statements)(statement)이라 하며, 세미콜론(`;`)으로 구분합니다. 구문 끝에 줄바꿈이 있으면 대부분의 경우 세미콜론을 생략할 수 있지만, 자동 세미콜론 삽입(ASI) 규칙 때문에 예상치 못한 동작이 생길 수 있으므로 세미콜론을 명시하는 습관을 권장합니다.

소스 텍스트는 왼쪽에서 오른쪽으로 스캔되며, 토큰, 제어 문자, 줄 종결자, 주석, 공백으로 변환됩니다. 스페이스, 탭, 줄 바꿈 문자는 공백으로 취급합니다.

## 주석

주석 문법은 C++ 및 여러 언어와 같습니다.

```js
// 한 줄 주석

/* 이것은 더 길고,
   여러 줄 주석입니다.
 */

/* 하지만 /* 중첩할 수는 없습니다 */ 문법 오류 */
```

주석은 공백처럼 취급되어 스크립트 실행 시 무시됩니다. 또한 파일 맨 앞에 `#!/usr/bin/env node` 형태의 해시뱅 주석을 둘 수 있으며, 이는 스크립트를 실행할 인터프리터를 지정합니다.

## 선언

JavaScript에는 세 종류의 변수 선언이 있습니다.

- `var`: 변수를 선언하며, 선택적으로 값을 초기화합니다.
- `let`: 블록 스코프 지역 변수를 선언하며, 선택적으로 값을 초기화합니다.
- `const`: 블록 스코프 읽기 전용 상수를 선언합니다.

### 변수

변수는 값을 담는 상징적인 이름으로 사용합니다. 변수의 이름을 **식별자**(identifier)라 하며, 특정 규칙을 따라야 합니다. 식별자는 문자, 밑줄(`_`), 달러 기호(`$`)로 시작해야 하고, 이후에는 숫자(`0`–`9`)도 사용할 수 있습니다. `é`, `ü` 같은 문자는 물론 유니코드 문자도 쓸 수 있습니다. 예약어는 식별자로 쓸 수 없습니다.

올바른 이름의 예: `Number_hits`, `temp99`, `$credit`, `_name`

### 변수 선언

변수는 다음과 같은 방법으로 선언할 수 있습니다.

- `var x = 42;` 처럼 선언합니다. 이 구문은 실행 문맥에 따라 지역 변수와 전역 변수를 모두 선언할 수 있습니다.
- `const y = 13;` 처럼 선언합니다. 블록 스코프 읽기 전용 상수를 선언합니다.
- `let z = 13;` 처럼 선언합니다. 블록 스코프 지역 변수를 선언합니다.

값을 할당하지 않고 `let x;`처럼 선언만 할 수도 있습니다. 단, `const`는 선언과 동시에 초기화해야 합니다.

### 변수 평가

`var` 또는 `let`으로 선언하면서 초기값을 지정하지 않은 변수의 값은 `undefined`입니다. 선언하지 않은 변수에 접근하면 `ReferenceError` 예외가 발생합니다.

```js
let a;
console.log("a의 값은 " + a); // a의 값은 undefined
console.log("b의 값은 " + b); // ReferenceError (var로 선언했다면 undefined)
let x;
```

`undefined` 값은 불리언 문맥에서 `false`로, 숫자 문맥에서 `NaN`으로 변환됩니다. `null` 값은 불리언 문맥에서 `false`, 숫자 문맥에서 `0`처럼 동작합니다.

### 변수 호이스팅

JavaScript 변수의 특이한 점은 나중에 선언한 변수를 예외 없이 참조할 수 있다는 것입니다. 이를 **호이스팅**(hoisting)이라 합니다. `var`로 선언한 변수는 함수 맨 위로 끌어올려진 것처럼 동작하며, 선언 전에 접근하면 `undefined`를 반환합니다. 단, 초기화는 끌어올려지지 않습니다.

`let`과 `const`도 호이스팅되지만, 선언 전까지 **일시적 데드존**(temporal dead zone)에 있어 접근하면 `ReferenceError`가 발생합니다. 따라서 항상 변수를 스코프 맨 위에서 선언하는 것이 좋습니다.

### 전역 변수

전역 변수는 사실 *전역 객체*의 속성입니다. 웹 페이지에서 전역 객체는 [`window`](/ko/docs/Web/API/Window)이므로 `window.변수` 형식으로 접근할 수 있습니다. 최상위 수준의 `var` 선언은 전역 객체의 속성이 되지만, `let`과 `const`는 그렇지 않습니다. `globalThis`를 사용하면 실행 환경에 관계없이 전역 객체에 접근할 수 있습니다.

### 상수

`const` 키워드로 읽기 전용 상수를 만들 수 있습니다. 식별자 규칙은 변수와 같습니다.

```js
const PI = 3.14;
```

상수에 값을 재할당하거나 같은 스코프에서 다시 선언할 수 없습니다. 다만 상수가 객체라면 객체의 속성은 보호되지 않아 변경할 수 있습니다.

```js
const MY_OBJECT = { key: "value" };
MY_OBJECT.key = "otherValue"; // 문제없음
```

## 자료형

최신 ECMAScript 표준은 여덟 가지 자료형을 정의합니다.

- 일곱 가지 [원시 값](/ko/docs/Glossary/Primitive)
  - [불리언](/ko/docs/Glossary/Boolean): `true`와 `false`
  - [null](/ko/docs/Glossary/Null): 값이 없음을 나타내는 특별한 키워드
  - [undefined](/ko/docs/Glossary/Undefined): 값이 할당되지 않은 변수의 속성
  - [숫자](/ko/docs/Glossary/Number): `42`, `3.14159` 등
  - [BigInt](/ko/docs/Glossary/BigInt): 임의 정밀도 정수
  - [문자열](/ko/docs/Glossary/String): `"안녕하세요"` 등
  - [심볼](/ko/docs/Glossary/Symbol): 인스턴스가 고유하며 변경 불가능한 자료형
- [객체](/ko/docs/Glossary/Object)

함수도 자료형의 하나이지만, 사실 호출 가능한 객체입니다.

### 자료형 변환

JavaScript는 **동적 형지정** 언어입니다. 변수를 선언할 때 자료형을 지정하지 않으며, 스크립트 실행 중 자료형이 필요에 따라 자동으로 바뀝니다.

```js
let answer = 42;
answer = "감사합니다 모두들...";
```

숫자와 문자열을 `+` 연산자로 더하면 숫자가 문자열로 변환됩니다.

```js
x = "The answer is " + 42; // "The answer is 42"
y = 42 + " is the answer"; // "42 is the answer"
```

다른 연산자(`-`, `*` 등)에서는 문자열이 숫자로 변환됩니다.

```js
"37" - 7; // 30
"37" + 7; // "377"
```

### 문자열을 숫자로 변환

메모리에 숫자가 문자열로 저장된 경우 변환하는 함수를 사용합니다.

- `parseInt()`: 정수로 변환합니다. 두 번째 인수로 진법(기수)을 항상 지정하세요.
- `parseFloat()`: 부동소수점 수로 변환합니다.

더 간단한 방법은 단항 더하기 연산자 `+`입니다.

```js
"1.1" + "1.1"; // '1.11.1'
+"1.1" + +"1.1"; // 2.2
```

## 리터럴

리터럴은 스크립트에 *문자 그대로* 적는 고정 값입니다. 변수가 아닙니다.

### 배열 리터럴

```js
const coffees = ["프렌치 로스트", "콜롬비안", "카푸치노"];
```

배열은 생성 시 지정한 요소로 초기화되며, 길이는 지정한 요소의 수가 됩니다. 쉼표를 연속해서 쓰면 빈 슬롯이 생깁니다. 마지막 요소 뒤의 쉼표(후행 쉼표)는 무시됩니다.

### 불리언 리터럴

불리언 타입에는 `true`와 `false` 두 가지 값이 있습니다. 원시 불리언 값과 `Boolean` 객체를 혼동하지 마세요. `Boolean` 객체는 원시 불리언을 감싼 래퍼입니다.

### 숫자 리터럴

`Number`와 `BigInt` 타입에는 10진수, 16진수, 8진수, 2진수 리터럴을 사용할 수 있습니다.

```js
0, 117, -345, 123456789123456789n; // 10진수
015, 0001, -0o77, 0o777n;          // 8진수
0x1123, 0x00111, -0xF1A7, 0xABCn;  // 16진수
0b11, 0b0011, -0b11, 0b11n;        // 2진수
```

부동소수점 리터럴은 소수점, 지수(`e` 또는 `E`)를 포함할 수 있습니다.

```js
3.14;
-.2345789;  // -0.23456789
-3.12e+12;  // -3.12 × 10¹²
.1e-23;     // 0.1 × 10⁻²³
```

숫자 구분자 `_`를 쓰면 가독성을 높일 수 있습니다: `1_000_000_000_000`.

### 객체 리터럴

객체 리터럴은 중괄호(`{}`)로 묶은 속성 이름과 값 쌍의 목록입니다.

```js
const sales = "Toyota";

function carTypes(name) {
  return name === "Honda" ? name : `죄송합니다. ${name}은(는) 취급하지 않습니다.`;
}

const car = { myCar: "Saturn", getCar: carTypes("Honda"), special: sales };

console.log(car.myCar);   // Saturn
console.log(car.getCar);  // Honda
console.log(car.special); // Toyota
```

속성 이름에 숫자나 문자열 리터럴을 쓸 수도 있고, 대괄호로 계산된 속성 이름을 쓸 수도 있습니다.

```js
const unusualPropertyNames = {
  "": "빈 문자열",
  "!": "뱅!",
};
console.log(unusualPropertyNames[""]); // 빈 문자열
```

### 정규 표현식 리터럴

정규 표현식 리터럴은 슬래시(`/`) 사이에 들어가는 패턴입니다.

```js
const re = /ab+c/;
```

### 문자열 리터럴

문자열 리터럴은 작은따옴표나 큰따옴표로 묶은 0개 이상의 문자입니다. 같은 종류의 따옴표로 시작하고 끝나야 합니다.

```js
"foo";
'bar';
"1234";
"한 줄 \n 다른 줄";
```

문자열 리터럴 값에 대해 `String` 객체의 모든 메서드를 호출할 수 있습니다. JavaScript가 자동으로 임시 `String` 객체로 변환한 뒤 메서드를 호출하고 객체를 버립니다. `length` 속성도 사용할 수 있습니다.

#### 템플릿 리터럴

템플릿 리터럴은 백틱(`` ` ``)으로 감싸며, 여러 줄 문자열과 문자열 보간을 지원합니다.

```js
const name = "철수";
console.log(`안녕하세요, ${name}님!
오늘도 좋은 하루 되세요.`);
```

#### 이스케이프 시퀀스

특수 문자는 이스케이프해서 사용합니다.

| 문자 | 의미 |
| --- | --- |
| `\0` | NULL 문자 |
| `\b` | 백스페이스 |
| `\n` | 줄 바꿈 |
| `\r` | 캐리지 리턴 |
| `\t` | 탭 |
| `\'` | 작은따옴표 |
| `\"` | 큰따옴표 |
| `\\` | 역슬래시 |
| `\xXX` | Latin-1 문자 |
| `\uXXXX` | 유니코드 문자 |
| `\u{XXXXX}` | 유니코드 코드 포인트 |
