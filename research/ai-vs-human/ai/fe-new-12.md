# 프론트엔드 인사이트 | 2023-11

안녕하세요, 11월호입니다. 이번 달은 **Angular 17**과 **Vite 5**의 메이저 릴리스, **TypeScript 5.3** 출시가 있었습니다. 10월 말에 나온 **Next.js 14**의 여파도 이어졌습니다. 아래에 핵심만 정리했습니다.

## 🔥 이달의 헤드라인

### Angular 17: "르네상스"의 시작
11월 8일 공개된 Angular 17은 최근 몇 년 사이 가장 큰 변화입니다.

- **새로운 제어 흐름 문법**: `*ngIf`, `*ngFor` 대신 `@if`, `@for`, `@switch` 블록을 씁니다. 템플릿이 읽기 쉬워지고, `@for`는 `track`을 필수로 요구해 렌더링 성능에 유리합니다.
- **지연 로딩 블록(`@defer`)**: 뷰포트 진입, 유휴 상태, 사용자 상호작용 같은 조건에 맞춰 컴포넌트를 선언적으로 지연 로딩합니다.
- **빌드 체인 교체**: 새 프로젝트의 기본 빌더가 esbuild와 Vite 기반으로 바뀌었습니다. 공식 발표에서 빌드 속도가 크게 개선됐다고 했습니다.
- **새 공식 사이트 angular.dev**: 튜토리얼과 문서가 새로 정비됐습니다.

기존 프로젝트는 `ng update`로 마이그레이션할 수 있고, 새 제어 흐름용 마이그레이션 스키매틱도 제공됩니다.

### Vite 5.0 출시
11월 16일 출시된 Vite 5는 Rollup 4 기반으로 올라갔고, Node.js 18 이상이 필요합니다. 개발 서버 쪽에서는 CJS 형태의 Node API 사용이 deprecated 되었습니다. 대부분 프로젝트는 설정 변경 없이 올라가지만, 커스텀 플러그인을 쓴다면 **Rollup 4 호환성**을 먼저 확인하세요.

## 🧰 언어와 도구

### TypeScript 5.3
11월 20일경 정식 출시되었습니다. 눈에 띄는 변화는 다음과 같습니다.

- **Import Attributes** 지원: `import data from "./data.json" with { type: "json" }`
- **`switch (true)` 좁히기(narrowing)** 개선
- 일부 문맥에서 타입 좁히기와 성능이 개선됨

타입 시스템 쪽 큰 신기능보다는 **안정성과 편의성**에 집중한 릴리스입니다. 모노레포라면 CI에서 먼저 버전을 올려 빌드 에러가 나는지 확인해 보세요.

### Next.js 14 이후의 논쟁
10월 말 발표된 Next.js 14는 **Server Actions 안정화**, **Turbopack 개선**, **Partial Prerendering(프리뷰)** 를 내세웠습니다. 커뮤니티에서는 App Router 도입 부담, 캐싱 동작의 예측 가능성, 벤더 종속성을 두고 논의가 계속되고 있습니다. 도입을 고민한다면 **프로젝트 규모와 팀의 서버 컴포넌트 이해도**를 먼저 따져 보길 권합니다.

## 💡 이달의 실무 팁

1. **Vite 5 업그레이드 체크리스트**
   - Node 버전 18 이상 확인
   - 사용 중인 플러그인의 Rollup 4 호환 여부 확인
   - `vite.config`의 CJS 사용 여부 점검
2. **Angular 17 점진적 적용**: 한 번에 전부 바꾸지 말고, 새 컴포넌트부터 `@if`, `@for`를 쓰고 스키매틱으로 나머지를 옮기세요.
3. **TypeScript 업그레이드 전략**: `npm i -D typescript@5.3`을 별도 브랜치에서 돌려 보고, 새로 뜨는 타입 에러만 선별해 처리하세요.
4. **성능 지표 습관화**: 2024년 3월부터 **INP(Interaction to Next Paint)** 가 Core Web Vitals에서 FID를 대체합니다. 지금부터 상호작용 지연을 측정해 두면 좋습니다.
