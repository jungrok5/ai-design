# 프론트엔드 월간 소식 — 2022-12

> 2022년 마지막 호입니다. 12월에는 메이저 릴리스가 몰렸고, 연말 회고 글도 많이 올라왔습니다. 이번 달 꼭 짚어볼 소식을 정리했습니다.

## 🔥 이달의 헤드라인

### Vite 4.0 출시

Vite 3가 나온 지 약 5개월 만에 **Vite 4.0**이 출시되었습니다. 가장 큰 변화는 내부 번들러가 **Rollup 3**으로 올라간 것입니다. 사용자가 체감하는 API 변화는 적지만 Rollup 플러그인 생태계의 변화를 따라가야 하므로, 커스텀 플러그인을 쓰는 팀은 업그레이드 전에 호환성을 확인하는 것이 좋습니다.

함께 나온 **`@vitejs/plugin-react-swc`**도 눈여겨볼 만합니다. 개발 중 Babel 대신 SWC로 변환해 큰 React 프로젝트의 HMR 속도를 크게 줄일 수 있습니다. 자세한 마이그레이션 내용은 공식 가이드를 참고하세요.

### SvelteKit 1.0 정식 출시

오래 기다려 온 **SvelteKit 1.0**이 드디어 나왔습니다. 2년 가까운 베타 기간 동안 라우팅 구조가 여러 번 크게 바뀌었습니다. 이제 파일 기반 라우팅(`+page.svelte`, `+layout.svelte`, `+page.server.ts`)과 `load` 함수 중심의 데이터 흐름으로 정리되었습니다.

1.0 출시로 API 안정성이 약속되었기 때문에, 실무 도입을 망설이던 팀도 이제 진지하게 검토해 볼 수 있습니다. 어댑터 구조 덕분에 Vercel, Netlify, Cloudflare, Node 서버 등 다양한 배포 대상을 지원하는 점도 장점입니다.

### Next.js 13.1

10월에 `app` 디렉터리와 Turbopack을 공개한 Next.js가 **13.1**을 내놓았습니다. 주요 내용은 다음과 같습니다.

- **`transpilePackages` 내장**: `next-transpile-modules` 같은 외부 패키지 없이 모노레포 내부 패키지를 트랜스파일할 수 있습니다.
- **Middleware 개선**: 응답을 직접 반환하거나 요청 헤더를 쉽게 조작할 수 있습니다.
- **import 해석 최적화**: 아이콘 라이브러리처럼 큰 배럴 파일을 가져올 때 필요한 모듈만 불러오도록 개선되었습니다.
- `app` 디렉터리(베타)의 안정성과 성능 개선

`app` 디렉터리는 아직 베타이므로, 프로덕션에서는 기존 `pages` 구조를 유지하면서 점진적으로 실험해 보길 권합니다.

## 🌐 브라우저 소식

### Firefox 108 — Import Maps 지원

Firefox 108이 **Import Maps**를 기본으로 지원하면서 주요 브라우저 엔진 모두 이 기능을 사용할 수 있게 되었습니다. 번들러 없이 아래처럼 베어 모듈 지정자를 쓸 수 있습니다.

```html
<script type="importmap">
{
  "imports": {
    "lodash": "https://cdn.jsdelivr.net/npm/lodash-es@4.17.21/lodash.js"
  }
}
</script>
<script type="module">
  import { debounce } from "lodash";
</script>
```

간단한 데모나 프로토타입이라면 빌드 도구 없이 시작해 보는 것도 좋은 선택입니다.

### Chrome 108 — 새로운 뷰포트 단위

11월 말에 나온 Chrome 108이 **`svh`, `lvh`, `dvh`** 같은 새로운 뷰포트 단위를 지원합니다. 그동안 모바일에서 주소창이 나타나고 사라질 때 `100vh`가 어긋나서 꽤 고생했는데, 이제 CSS만으로 해결할 수 있습니다.

```css
.hero {
  min-height: 100svh; /* 주소창이 보일 때 기준 */
}
```

Safari와 Firefox는 이미 지원하고 있어서, 이번 Chrome 지원으로 실무에서도 쓸 만한 수준이 되었습니다.

### Safari 16.2

Safari 16.2에서는 `color-mix()` 등 CSS 기능이 추가되었습니다. 디자인 토큰에서 색상을 파생할 때 Sass 함수 대신 네이티브 CSS를 쓸 날이 가까워지고 있습니다.

## ⚡ 런타임 & 툴링

- **Deno 1.29**: npm 패키지 호환성이 계속 개선되고 있습니다. Node 생태계와의 간극이 빠르게 줄고 있습니다.
- **Bun**: 0.3 버전대 업데이트로 Node API 호환성과 안정성이 개선되었습니다. 아직 프로덕션에 쓰기는 이르지만 스크립트 실행기나 테스트 러너로 써 보는 사례가 늘고 있습니다.
- **Storybook 7 베타**: Vite 기반 빌더의 일급 지원, CSF3 기본화, 새로운 UI 등을 담은 베타가 공개되었습니다. 정식 출시는 내년 초로 예상됩니다.
- **TypeScript 4.9 정착**: 지난달 나온 `satisfies` 연산자를 실무 코드에 도입한 사례가 많이 공유되었습니다. 타입 추론을 유지하면서 형태를 검증할 수 있어 설정 객체에 특히 잘 맞습니다.

```ts
const routes = {
  home: "/",
  about: "/about",
} satisfies Record<string, `/${string}`>;
```
