# React 참고서 개요

React 참고서(Reference)는 React가 제공하는 함수, 훅(Hook), 컴포넌트, DOM 관련 API를 항목별로 정리한 공식 문서입니다. React를 처음 배우는 단계라면 가이드 문서로 기본 개념을 익히고, 특정 API의 정확한 시그니처나 동작이 궁금할 때 참고서를 찾아보는 것이 좋습니다.

## 참고서의 구성

참고서는 다음과 같은 영역으로 나뉩니다.

- **React**: `useState`, `useEffect`, `useRef` 같은 훅과 `Fragment`, `Suspense`, `StrictMode` 같은 내장 컴포넌트를 다룹니다.
- **React DOM**: `react-dom` 패키지가 제공하는 API를 설명합니다. 브라우저 DOM과 상호작용하는 기능과 루트 생성 방법이 여기에 포함됩니다.
- **React DOM 서버 API**: 서버 렌더링과 스트리밍에 사용하는 함수를 다룹니다.
- **Rules of React**: 컴포넌트와 훅을 올바르게 작성하기 위한 규칙을 정리합니다.
- **도구**: React Compiler, ESLint 플러그인처럼 개발을 돕는 도구를 소개합니다.
- **레거시 API**: 현재는 권장되지 않지만 기존 코드에서 여전히 볼 수 있는 API를 설명합니다.

## 각 항목의 형식

API 문서는 대체로 같은 형식을 따릅니다.

1. **개요**: API가 무엇을 하는지 한두 문장으로 설명합니다.
2. **레퍼런스**: 인자, 반환값, 주의사항을 정리합니다.
3. **사용법**: 상황별 예제 코드를 보여줍니다.
4. **문제 해결**: 자주 발생하는 오류와 해결 방법을 안내합니다.

## 효과적으로 읽는 방법

참고서는 처음부터 끝까지 읽기보다 필요한 항목을 검색해 보는 용도로 설계되어 있습니다. 예를 들어 `useEffect`의 의존성 배열이 헷갈린다면 해당 훅 문서의 의존성 관련 항목을 확인하면 됩니다. 예제 코드는 대부분 함수 컴포넌트와 훅을 기준으로 작성되어 있으므로, 클래스 컴포넌트 관련 내용은 레거시 항목을 참고하세요.

항목마다 "주의" 또는 "경고" 박스가 있어 흔히 하는 실수나 예상과 다르게 동작하는 부분을 미리 알려 줍니다. 이 부분을 꼼꼼히 읽으면 디버깅 시간을 크게 줄일 수 있습니다.

## 버전과 실험 기능 확인

React는 버전이 올라가면서 API가 추가되거나 동작이 바뀌기도 합니다. 따라서 사용 중인 React 버전에 해당 API가 포함되어 있는지 먼저 확인하는 것이 중요합니다. 일부 API는 아직 안정화되지 않은 실험(Experimental) 또는 Canary 채널에서만 제공되므로, 문서에 해당 표시가 있다면 프로덕션 코드에 바로 적용하기 전에 공식 릴리스 노트를 함께 확인하세요.

## 정리

React 참고서는 React를 사용하는 개발자가 정확한 동작을 확인하기 위해 찾아보는 공식 자료입니다. 구성과 항목 형식을 미리 익혀 두면 필요한 정보를 빠르게 찾을 수 있고, 버전과 실험 기능 표시를 함께 살피면 잘못된 API를 사용하는 실수도 줄일 수 있습니다.
