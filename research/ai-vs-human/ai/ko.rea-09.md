## React 재단 {/*the-react-foundation*/}

React는 처음 공개된 뒤 10년이 넘는 시간 동안 개인 개발자부터 대규모 기업까지 수많은 사람이 웹과 네이티브 애플리케이션을 만드는 데 사용하는 기술로 성장했습니다. 지금의 React는 Meta 내부의 작은 팀만 만든 것이 아닙니다. 전 세계 기여자, 라이브러리 메인테이너, 프레임워크 개발자, 교육자, 커뮤니티 구성원이 함께 만들어 왔습니다.

이처럼 넓은 생태계를 장기적으로 지원하려면 특정 회사 하나에 기대지 않는 중립적인 보금자리가 필요합니다. 그래서 React와 React Native를 Meta에서 새로운 React 재단으로 옮기기로 했습니다.

React 재단의 역할은 다음과 같습니다.

- **인프라 관리:** GitHub 저장소, CI, 공식 웹사이트 등 React 프로젝트 운영에 필요한 인프라를 관리합니다.
- **행사 운영:** React Conf를 비롯한 커뮤니티 행사를 주관합니다.
- **생태계 지원:** 메인테이너와 기여자를 돕는 프로그램을 통해 생태계 전반을 지원합니다.

재단의 창립 회원사는 Amazon, Callstack, Expo, Meta, Microsoft, Software Mansion, Vercel입니다. 앞으로 더 많은 회사와 단체가 함께하기를 기대합니다.

재단의 전무이사(Executive Director)는 Seth Webster가 맡습니다. Meta는 5년 동안 300만 달러 이상의 자금과 전담 엔지니어링 인력을 지원하며 재단과 협력합니다.

## 기술 거버넌스 {/*technical-governance*/}

React의 기술적 방향은 재단 이사회와 **분리**해서 결정합니다. 재단은 프로젝트를 운영하고 지원하는 데 집중하며, 기술 로드맵은 React에 직접 기여하고 프로젝트를 유지보수하는 사람들이 정합니다.

이를 위해 새로운 기술 거버넌스 구조를 만들고 있습니다. 목표는 다음과 같습니다.

1. 특정 회사나 조직이 React의 방향을 혼자 결정하지 않도록 합니다.
2. 다양한 배경의 기여자가 의사 결정에 참여할 수 있는 투명한 절차를 마련합니다.
3. 지금까지 React를 만들어 온 핵심 원칙과 높은 품질 기준을 유지합니다.

세부 구조는 커뮤니티의 의견을 들으며 앞으로 몇 달 안에 확정하고 공유할 예정입니다.

## 앞으로의 계획 {/*next-steps*/}

재단 설립과 프로젝트 이전에는 시간이 걸립니다. 그 기간에도 React 개발과 릴리스는 평소처럼 계속되며, React를 사용하는 방식에는 아무 변화가 없습니다.

React가 지금의 모습이 될 수 있었던 건 커뮤니티 덕분입니다. React 재단은 이 커뮤니티가 다음 10년도 함께 성장할 수 있는 토대가 될 것입니다. 진행 상황은 이 블로그를 통해 계속 알려드리겠습니다.
