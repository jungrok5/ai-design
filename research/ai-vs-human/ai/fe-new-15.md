## 1. 프레임워크 & 라이브러리

### React 17: "새 기능 없는" 릴리스
10월 말 공개된 React 17은 새 API가 거의 없습니다. 대신 **점진적 업그레이드**에 초점을 맞췄습니다.

- 한 앱 안에서 서로 다른 React 버전을 함께 쓸 수 있어, 큰 앱을 단계적으로 옮기기 쉬워졌습니다.
- 이벤트 위임 대상이 `document`에서 **루트 컨테이너**로 바뀌었습니다. 여러 React 버전이나 다른 라이브러리와 공존할 때 충돌이 줄어듭니다.
- 새 **JSX Transform**이 도입되어, JSX를 쓰는 파일마다 `import React`를 하지 않아도 됩니다.

> 💡 업그레이드할 때는 `e.persist()` 관련 변경(이벤트 풀링 제거)과 `useEffect` cleanup의 비동기 실행 타이밍을 꼭 확인하세요.

### Next.js 10
Next.js Conf와 함께 10 버전이 나왔습니다.

- **`next/image`**: 이미지 크기 최적화, 지연 로딩, 최신 포맷 변환을 기본 제공합니다.
- **국제화(i18n) 라우팅** 내장
- 커머스용 템플릿과 분석 기능 소개

이미지 최적화를 직접 구성하느라 고생했던 팀이라면 도입을 검토해 볼 만합니다.

### Angular 11
11월 중순에 출시되었습니다.

- 새 프로젝트의 기본 설정이 더 엄격한 **strict 모드** 쪽으로 이동했습니다.
- **Webpack 5** 실험적 지원
- 개발 서버의 **HMR(Hot Module Replacement)** 개선
- 폰트 인라이닝으로 초기 렌더링 성능 개선
- 오래된 **TSLint** 대신 ESLint로의 이전을 권장

### Vue 3 생태계
9월에 정식 출시된 Vue 3를 따라 주변 도구도 정리되는 중입니다. 상태 관리와 라우터가 Vue 3 대응을 마쳐 가고 있어, 신규 프로젝트에서 Composition API를 본격적으로 쓰는 사례가 늘고 있습니다.

## 2. 언어 & 빌드 도구

### TypeScript 4.1
11월 하순에 정식 출시되었습니다. 이번 버전의 주인공은 **템플릿 리터럴 타입**입니다.

```ts
type Axis = "x" | "y";
type Event = `${Axis}-changed`; // "x-changed" | "y-changed"
```

- 매핑된 타입의 **키 리매핑**(`as` 절)
- **재귀 조건부 타입** 지원
- `noUncheckedIndexedAccess` 옵션 추가

문자열 기반 API(이벤트 이름, 라우트 경로 등)를 훨씬 정밀하게 타이핑할 수 있게 되었습니다.

### Webpack 5
10월에 정식 릴리스되었고, 이번 달부터 마이그레이션 후기가 많이 올라왔습니다.

- **영구 캐시**로 재빌드 속도 개선
- **Module Federation**: 서로 다른 빌드 간에 모듈을 런타임에 공유해, 마이크로 프론트엔드 구성에 새 선택지를 줍니다.
- Node.js 폴리필 자동 포함 제거. 일부 라이브러리는 직접 대응이 필요합니다.

### npm 7
10월 중순 공개되었습니다. **workspaces** 지원과 **peerDependencies 자동 설치**가 핵심이며, lockfile 형식도 바뀌었습니다. 기존 프로젝트에서는 peer 의존성 충돌이 새로 드러날 수 있으니 CI에서 먼저 시험해 보세요.

## 3. 런타임 & 브라우저

### Node.js
- **Node.js 15** 출시: 처리되지 않은 Promise rejection이 기본적으로 프로세스를 종료시킵니다. npm 7이 기본 번들로 들어갔습니다.
- **Node.js 14**는 LTS로 전환되었습니다. 운영 환경에는 짝수 버전 LTS를 권장합니다.

### Chrome 87
- 개발자 도구의 **성능 패널**과 CSS Grid 디버깅이 개선되었습니다.
- 백그라운드 탭의 CPU 사용량 감소 등 전반적인 효율 개선

### Firefox 83
- 자바스크립트 엔진 SpiderMonkey에 **Warp**가 도입되어 성능이 개선되었습니다.
- **HTTPS-Only 모드** 추가

### Apple M1
Apple Silicon(M1) 맥이 공개되면서 개발 환경에 관한 관심이 큽니다. 일부 네이티브 모듈과 도구는 아직 Rosetta 2 의존이 있어, 당분간은 호환성 확인이 필요합니다.

## 4. 웹 성능: Core Web Vitals

구글이 **Core Web Vitals를 2021년 5월부터 검색 순위 신호에 반영**하겠다고 예고했습니다. 측정 지표는 다음 세 가지입니다.

1. **LCP**(Largest Contentful Paint): 로딩 성능
2. **FID**(First Input Delay): 상호작용 응답성
3. **CLS**(Cumulative Layout Shift): 시각적 안정성

**지금 점검해 볼 것**
- 이미지·폰트 로딩 최적화 (크기 지정, `font-display`, 지연 로딩)
- 큰 자바스크립트 번들 분할 및 불필요한 서드파티 스크립트 정리
- 광고·이미지 영역에 공간을 미리 확보해 레이아웃 이동 방지

Lighthouse, PageSpeed Insights, 크롬 개발자 도구에서 바로 측정할 수 있으니 서비스의 현재 점수부터 확인해 보세요.
