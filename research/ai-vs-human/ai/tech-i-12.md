# X and Y data

## 1. 개념
X와 Y data는 같은 관측 단위에서 얻은 두 변수의 짝 (xᵢ, yᵢ) 집합입니다. 예를 들어 광고비(X)와 매출(Y), 공부 시간(X)과 시험 점수(Y)처럼 두 값이 함께 기록된 데이터입니다. 면접에서는 "두 변수가 함께 변하는가?", "X로 Y를 예측할 수 있는가?"를 묻는 경우가 많습니다.

## 2. 시각화: 산점도 (Scatter Plot)
- 가로축에 X, 세로축에 Y를 점으로 찍습니다.
- 양의 상관, 음의 상관, 무상관, 비선형 관계를 한눈에 파악할 수 있습니다.
- 상관계수가 비슷해도 패턴이 전혀 다를 수 있으므로 계산 전에 먼저 그려 보는 것이 중요합니다. (Anscombe's quartet 예시)

## 3. 상관계수 (Correlation)
피어슨 상관계수 r은 다음과 같습니다.

r = Σ(xᵢ − x̄)(yᵢ − ȳ) / √(Σ(xᵢ − x̄)² · Σ(yᵢ − ȳ)²)

- 범위는 −1 ≤ r ≤ 1입니다.
- |r|이 1에 가까울수록 선형 관계가 강합니다.
- 상관관계는 인과관계가 아닙니다.
- 이상치에 민감하므로 순위 기반의 스피어만 상관계수를 고려할 수 있습니다.

## 4. 선형 회귀 (Linear Regression)
모델은 ŷ = β₀ + β₁x입니다. 최소제곱법(OLS)은 잔차제곱합 Σ(yᵢ − ŷᵢ)²을 최소화합니다.

- β₁ = cov(X, Y) / var(X) = r · (s_y / s_x)
- β₀ = ȳ − β₁x̄
- 결정계수 R² = r²은 모델이 Y의 분산을 몇 % 설명하는지를 나타냅니다.

## 5. 구현 예시 (Python)
```python
import numpy as np

x = np.array([1, 2, 3, 4, 5], dtype=float)
y = np.array([2.1, 3.9, 6.2, 7.8, 10.1])

r = np.corrcoef(x, y)[0, 1]              # 피어슨 상관계수
slope, intercept = np.polyfit(x, y, 1)   # 1차 회귀
print(f"r={r:.3f}, y={slope:.2f}x+{intercept:.2f}")
```

## 6. 면접 체크포인트
- **상관계수가 0이면 독립인가?** 아닙니다. 비선형 관계에서는 r이 0이어도 강한 관계가 있을 수 있습니다.
- **X와 Y를 바꾸면 기울기는?** 부호는 같지만 크기는 다릅니다. 두 기울기의 곱이 r²입니다.
- **결측치는 어떻게 처리하는가?** X와 Y의 짝이 깨지지 않도록 쌍 단위로 제거해야 합니다.
- **회귀의 가정은?** 선형성, 독립성, 등분산성, 잔차의 정규성을 말할 수 있어야 합니다.
- **시계열 X, Y 데이터의 주의점은?** 자기상관 때문에 독립 가정이 깨지므로 가짜 상관(spurious correlation)에 주의해야 합니다.
- **다중 X로 확장하면?** 다중 회귀가 되며, X 사이의 상관이 높으면 다중공선성 문제가 생깁니다.
