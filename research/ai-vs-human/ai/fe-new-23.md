# 🗞️ 프론트엔드 월간 뉴스레터 — 2023-10

안녕하세요, 프론트엔드 개발자 여러분! 10월에는 콘퍼런스와 메이저 릴리스가 몰려 있었습니다. Next.js 14가 공개됐고, Node.js 20이 LTS가 됐고, 브라우저에는 CSS 기능이 새로 들어왔습니다. 이번 호에서는 이 소식들을 정리해 드립니다.

---

## 🔥 이달의 헤드라인: Next.js 14 공개

10월 26일 열린 **Next.js Conf 2023**에서 **Next.js 14**가 발표됐습니다. 이번에는 새 API를 늘리기보다 이미 있던 기능을 안정화하고 성능을 개선하는 데 집중했습니다.

- **Server Actions 안정화**: 폼 제출이나 데이터 변경을 위해 API 라우트를 따로 만들 필요 없이, 서버 함수를 컴포넌트에서 바로 호출할 수 있습니다. 프로그레시브 인핸스먼트도 기본으로 지원합니다.
- **Turbopack 개선**: `next dev --turbo` 기준으로 로컬 서버 시작은 최대 53%, Fast Refresh를 통한 코드 업데이트 반영은 최대 94% 빨라졌다고 합니다.
- **Partial Prerendering(프리뷰)**: 한 페이지 안에서 정적 셸은 바로 보내고, 동적인 부분만 스트리밍으로 채우는 렌더링 모델입니다. 정적 렌더링과 동적 렌더링 중 하나를 고르는 대신 둘을 섞어 쓰는 방향을 보여 줍니다.
- 최소 지원 Node.js 버전은 **18.17**로 올라갔습니다.

> 💡 **한 줄 평**: App Router로 옮길지 고민하던 팀이라면 지금이 다시 검토하기 좋은 때입니다. Server Actions를 쓰면 데이터 변경 로직이 크게 단순해집니다.

## ⚙️ 런타임 & 언어

### Node.js 20 LTS 전환, Node.js 21 출시
10월 17일에 **Node.js 21**이 나왔고, 10월 24일에는 **Node.js 20**이 코드네임 *Iron*으로 Active LTS가 됐습니다. 프로덕션 환경에서 버전을 올릴 계획을 세울 때입니다.

Node.js 21의 주요 변경점은 다음과 같습니다.
- `fetch`와 Web Streams API **안정화**
- 브라우저 호환 **WebSocket 클라이언트**를 실험적으로 추가(`--experimental-websocket`)
- 확장자가 없는 파일 등을 ES 모듈로 해석할 수 있는 `--experimental-default-type` 플래그
- V8 11.8 업데이트

### TypeScript 5.3 베타
10월 초에 **TypeScript 5.3 베타**가 공개됐습니다. 주요 기능은 이렇습니다.
- **Import Attributes**(`import data from "./data.json" with { type: "json" }`) 지원
- `switch (true)` 패턴에서 타입 좁히기(narrowing) 개선
- import 타입에서 `resolution-mode`를 모든 모듈 해석 모드에서 쓸 수 있게 됨

## 🌐 브라우저 플랫폼

### Chrome 118: `@scope`가 들어왔습니다
10월 초 안정 채널에 배포된 **Chrome 118**은 **CSS `@scope` 규칙**을 지원합니다. 스타일이 적용되는 범위를 특정 DOM 하위 트리로 제한할 수 있고, "도넛 스코프"를 쓰면 하위 일부 영역은 제외할 수도 있습니다. BEM 같은 명명 규칙이나 CSS-in-JS 없이도 스타일 격리를 일부 해결할 수 있게 된 것입니다.

```css
@scope (.card) to (.card__content) {
  img { border-radius: 8px; }
}
```

같은 버전에는 `prefers-reduced-transparency` 미디어 쿼리도 추가됐습니다. 사용자가 OS에서 투명도 줄이기를 설정했다면 그 설정을 존중하는 UI를 만들 수 있습니다.

> ⚠️ `@scope`는 아직 모든 브라우저가 지원하지는 않으므로, 실무에서는 점진적 적용(progressive enhancement)을 전제로 써 주세요.

## 🛠️ 빌드 도구 & 프레임워크

### Rollup 4 릴리스
10월 초에 **Rollup 4**가 나왔습니다. 가장 큰 변화는 파서를 Acorn에서 **SWC 기반 네이티브 파서**로 바꾼 것입니다. 성능은 좋아졌고, 플랫폼별 네이티브 바이너리가 함께 배포됩니다. Rollup을 내부에서 쓰는 **Vite 5**도 베타를 진행 중이어서, 머지않아 정식 릴리스가 나올 것으로 보입니다.

### Remix, Vite를 품다
10월 말에 Remix 팀이 **실험적(unstable) Vite 플러그인**을 공개했습니다. Remix 앱을 Vite 위에서 바로 빌드할 수 있어, HMR 속도와 Vite 플러그인 생태계를 그대로 활용할 수 있습니다. 메타 프레임워크들이 Vite를 공통 기반으로 삼는 흐름이 한층 뚜렷해졌습니다.

### Astro 3.3 / 3.4
- **3.3**: 반응형 이미지와 여러 포맷 출력을 지원하는 `<Picture />` 컴포넌트 추가
- **3.4**: 레이아웃 없이 HTML 조각만 반환하는 **Page Partials** 추가. htmx 같은 라이브러리와 함께 쓰기 좋습니다.
