# 프론트엔드 월간 뉴스레터 — 2020-04

안녕하세요, 4월 호입니다. 이번 달에는 많은 콘퍼런스가 취소되거나 온라인으로 바뀌었고, 브라우저 출시 일정도 조정됐습니다. 그래도 Node.js 14와 Vue 3 베타 같은 큰 소식이 이어졌습니다. 이번 달 주요 소식을 정리했습니다.

---

## 🟢 Node.js 14 출시

4월 21일 **Node.js 14**가 나왔습니다. 올해 10월에 LTS로 전환될 예정이어서 많은 프로젝트가 기본 런타임으로 삼게 될 버전입니다.

- **V8 8.1 탑재**: 옵셔널 체이닝(`a?.b`)과 널 병합 연산자(`a ?? b`)를 트랜스파일 없이 바로 쓸 수 있습니다. `Intl.DisplayNames`도 추가됐습니다.
- **Diagnostic Report 안정화**: 크래시나 성능 문제를 분석하는 리포트 기능이 정식 기능이 됐습니다.
- **ESM 경고 제거**: ECMAScript 모듈을 쓸 때 나오던 실험 기능 경고가 사라졌습니다. 아직 실험 단계이지만 `import`/`export`를 쓰기가 한결 편해졌습니다.
- **실험적 Async Local Storage API**: 비동기 흐름을 따라 컨텍스트를 유지할 수 있어 로깅과 추적 도구에 쓸모가 있습니다.

빌드 도구나 SSR 서버를 운영하고 있다면 CI 매트릭스에 14 버전을 추가해 두는 것을 권합니다.

## 💚 Vue 3.0 베타 공개

4월 중순 **Vue 3.0이 베타 단계**에 들어갔습니다. 알파 기간에 RFC로 논의하던 기능들이 확정되면서 큰 API 변경은 없을 것으로 보입니다.

- **Composition API**: `setup()` 함수 안에서 로직을 함수 단위로 묶고 재사용할 수 있습니다. 기존 Options API도 그대로 지원합니다.
- **성능 개선**: 가상 DOM을 다시 작성하고 컴파일 단계의 최적화 힌트를 활용해 렌더링 속도와 메모리 사용량이 좋아졌습니다.
- **트리 셰이킹 지원 강화**: 쓰지 않는 기능은 번들에서 빠지므로 런타임 크기가 줄어듭니다.
- **TypeScript 기반 재작성**: 타입 추론이 크게 좋아졌습니다.

Vue Router, Vuex 같은 공식 라이브러리와 Vue CLI도 3.0 대응을 진행하고 있습니다. 실무에 바로 도입하기보다는 사이드 프로젝트에서 Composition API를 먼저 써 보며 익숙해지는 방법을 추천합니다.

## 🌐 브라우저 소식

### Chrome 81 — 일정 조정 후 출시
구글은 3월에 코로나19로 출시를 잠시 멈췄다가 4월 초 **Chrome 81**을 내놓았습니다. **Chrome 82는 건너뛰고** 다음 버전은 83으로 바로 넘어갑니다.
- WebXR **Hit Test API**가 추가돼 AR 콘텐츠를 현실 공간의 표면에 배치할 수 있습니다.
- **Web NFC** 오리진 트라이얼이 시작됐습니다.
- 이미지의 EXIF 방향 정보를 기본으로 반영합니다(`image-orientation: from-image`).
- TLS 1.0/1.1 지원 중단은 상황을 고려해 연기됐습니다.

### Firefox 75
- `<img loading="lazy">` **네이티브 지연 로딩**을 지원합니다. 이제 Chromium 계열과 Firefox 모두에서 별도 라이브러리 없이 이미지 지연 로딩을 할 수 있습니다.
- 주소창이 새로 디자인됐고, 리눅스용 Flatpak 배포가 시작됐습니다.

### Safari 13.1 (3월 말 출시)
지난 호 이후 나온 버전이라 함께 소개합니다.
- **Web Animations API**, **ResizeObserver**, **Async Clipboard API**를 지원합니다.
- ITP 업데이트로 **서드파티 쿠키를 기본 전면 차단**합니다. 서드파티 쿠키에 의존하는 로그인, 임베드, 분석 기능은 Storage Access API 같은 대안을 검토해야 합니다.

## 📦 GitHub, npm 인수 완료

3월에 발표된 GitHub의 npm 인수가 4월 중순 마무리됐습니다. GitHub는 npm 레지스트리를 계속 무료로 공개 운영하겠다고 밝혔습니다. 앞으로는 GitHub 계정과의 연동 강화, 패키지 게시 과정의 보안 개선, GitHub Packages와의 통합 등을 기대할 수 있습니다. 생태계의 핵심 인프라가 안정적인 운영 주체를 찾았다는 점에서 대체로 반기는 분위기입니다.

## ⚡ 짧은 소식

- **TypeScript 3.9**: 베타가 나와 정식 출시를 앞두고 있습니다. 타입 검사 속도 개선, `// @ts-expect-error` 주석, `Promise.all` 타입 추론 개선 등이 포함됩니다.
- **Deno 1.0 임박**: 안정 버전 출시가 다가오면서 커뮤니티의 관심이 커지고 있습니다. 보안 샌드박스, TypeScript 기본 지원, URL 기반 모듈 임포트가 특징입니다.
- **Next.js 9.3 확산**: 3월에 추가된 `getStaticProps`/`getStaticPaths` 기반 정적 생성(SSG)을 적용한 사례가 늘고 있습니다.
- **webpack 5 베타**: 장기 캐싱 개선과 Module Federation 기능이 꾸준히 다듬어지고 있습니다. 마이크로 프런트엔드에 관심이 있다면 주목할 만합니다.
- **온라인 콘퍼런스 확산**: 대형 행사가 취소되거나 온라인으로 바뀌고 있습니다. 많은 밋업이 라이브 스트리밍으로 열리고 있으니 해외 행사도 집에서 편하게 참여해 보세요.

## 💡 이달의 팁: 옵셔널 체이닝, 이제 써도 될까?

Node.js 14와 최신 브라우저(Chrome 80+, Firefox 74+, Safari 13.1+)는 모두 `?.`와 `??`를 지원합니다. 다만 구형 브라우저 사용자가 있다면 Babel(`@babel/preset-env` 7.8 이상)로 트랜스파일해야 합니다. TypeScript 3.7 이상을 쓰고 있다면 이미 쓸 수 있습니다.

```js
const city = user?.profile?.address?.city ?? '알 수 없음';
```
