## 🛠 1. 빌드 도구: Vite 5.1

2월 초 **Vite 5.1**이 공개되었습니다. 이번 릴리스의 중심은 성능 개선과 확장성입니다.

- **Runtime API 실험적 도입**: 서버 환경에서 모듈을 실행하는 방식을 다듬어, 프레임워크와 메타프레임워크가 Vite 위에서 SSR 환경을 만들기 쉬워졌습니다.
- **파일 시스템 접근 최적화**: 불필요한 파일 확인을 줄여 개발 서버와 빌드 속도를 개선했습니다.
- **플러그인 생태계 대응**: 플러그인 작성자가 쓸 수 있는 훅과 옵션이 보강되었습니다.

Vite 5를 쓰고 있다면 마이너 업그레이드 부담이 크지 않습니다. 다만 커스텀 플러그인이 있는 프로젝트는 CI에서 빌드 결과를 먼저 비교해 보세요.

## 🔷 2. 언어: TypeScript 5.4 베타·RC

1월 말 베타가 나온 **TypeScript 5.4**는 2월에 RC 단계로 넘어갔고, 정식 버전은 3월 초 예정입니다. 주요 변화는 다음과 같습니다.

1. **클로저 내 타입 좁히기 개선**: 마지막 할당 이후 값이 바뀌지 않는다고 판단되면, 콜백 안에서도 좁혀진 타입이 유지됩니다. 불필요한 non-null 단언이 줄어듭니다.
2. **`NoInfer` 유틸리티 타입**: 제네릭 추론 대상에서 특정 위치를 제외할 수 있어, 의도하지 않은 타입 추론을 막기 좋습니다.
3. **`Object.groupBy`, `Map.groupBy` 지원 관련 개선**: 최신 ECMAScript 기능을 타입 수준에서 다루기가 한결 편해졌습니다.

팀에서 사용하는 `typescript-eslint`, 빌드 도구와의 호환성은 RC 단계에서 미리 확인해 두면 정식 출시 후 업그레이드가 수월합니다.

## 🌐 3. 웹 플랫폼

### Interop 2024 시작
Apple, Google, Microsoft, Mozilla, Igalia 등이 함께하는 호환성 프로젝트 **Interop 2024**가 2월 초 공개되었습니다. 올해 초점은 다음과 같습니다.

- **Popover API**, **`<dialog>`**: 모달과 팝오버를 네이티브로 구현하는 흐름이 강화됩니다.
- **`@property`**, **상대 색상 문법**, **`text-wrap: balance`** 등 CSS 기능
- **View Transitions**
- **Declarative Shadow DOM**

브라우저 간 차이가 줄어들면 라이브러리 의존도를 낮추고 네이티브 기능을 쓸 수 있는 범위가 넓어집니다. 올해 신규 프로젝트에서 어떤 컴포넌트를 네이티브로 대체할 수 있을지 점검해 볼 만합니다.

### Safari 17.4 베타
Safari 17.4 베타가 공개되어, 정식 출시 전에 새 CSS와 JavaScript 기능을 미리 확인할 수 있게 되었습니다. iOS 사용자 비중이 큰 서비스라면 베타 단계에서 레이아웃과 폼 동작을 테스트해 보세요.

### Chrome 122
Chrome 122 안정 버전이 2월 하순에 배포되었습니다. 호환성 변화는 DevTools의 릴리스 노트와 chromestatus에서 확인할 수 있습니다.

## ⚙️ 4. 프레임워크 동향

### Angular 17.2
**Signal 기반 입력(`input()`)**과 양방향 바인딩용 **`model()`**이 포함되었습니다. 변경 감지를 Signal 중심으로 옮기는 Angular의 방향이 한 단계 더 구체화된 릴리스입니다. 기존 `@Input()`도 계속 동작하므로 점진적으로 전환할 수 있습니다.

### Next.js 14.1
1월 중순에 나온 14.1의 후속 패치가 2월 내내 이어졌습니다. 개발 서버 성능, 이미지·캐시 처리, Server Actions 안정화가 중심입니다. App Router를 도입한 팀이라면 패치 버전을 꾸준히 따라가는 편이 안전합니다.

### React와 Vue
- **React**: 서버 컴포넌트와 Actions 같은 새 기능은 Canary 채널에서 계속 다듬어지고 있습니다. 정식 안정화 전에는 실험적 기능을 프로덕션에 바로 쓰지 않는 편이 좋습니다.
- **Vue**: 3.4 계열 패치가 계속 나오고 있습니다. 파서 성능 개선과 반응성 시스템 안정화가 이어지는 흐름입니다.
