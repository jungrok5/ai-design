# 개발자를 위한 웹 기술

웹 기술(Web technology)은 브라우저와 서버가 정보를 주고받으며 사용자에게 문서와 애플리케이션을 전달하는 데 쓰이는 표준과 도구의 집합입니다. 이 문서는 웹 개발을 처음 시작하는 개발자가 전체 구조를 파악하고, 각 기술이 맡은 역할을 이해하도록 돕는 것을 목표로 합니다.

## 개요

웹 페이지는 보통 세 가지 층으로 나뉩니다. 구조를 담당하는 HTML, 표현을 담당하는 CSS, 동작을 담당하는 JavaScript입니다. 이 세 가지는 서로 독립적이면서도 긴밀하게 연결되어 있어 함께 사용됩니다. 예를 들어 HTML로 버튼을 정의하고, CSS로 색과 모양을 지정하며, JavaScript로 클릭했을 때의 동작을 구현합니다.

## HTML: 문서의 구조

HTML(HyperText Markup Language)은 웹 페이지의 뼈대를 정의하는 마크업 언어입니다. 제목, 문단, 목록, 링크, 이미지 등 각 요소는 태그로 표시되며, 요소의 의미(semantics)를 올바르게 나타내는 것이 중요합니다. 내비게이션은 `<nav>`, 본문의 주요 영역은 `<main>`, 독립적인 글은 `<article>`로 표현하면 검색 엔진과 보조 기술이 페이지를 더 잘 이해합니다.

접근성도 HTML 단계에서 고려해야 합니다. 이미지에는 `alt` 속성을 제공하고, 폼 입력에는 `<label>`을 연결하며, 제목 수준(`<h1>`~`<h6>`)을 논리적 순서에 맞게 사용해야 합니다.

## CSS: 표현과 레이아웃

CSS(Cascading Style Sheets)는 HTML 요소의 모양을 지정합니다. 글꼴, 색상, 여백, 크기뿐 아니라 레이아웃까지 담당합니다. 과거에는 `float`와 표를 이용해 배치했지만, 현재는 플렉스박스(Flexbox)와 그리드(Grid)가 대부분의 레이아웃을 맡고 있습니다.

CSS는 선택자의 명세도와 상속 규칙에 따라 적용되므로, 이를 이해하는 것이 디버깅의 핵심입니다. 미디어 쿼리를 사용하면 화면 너비에 따라 스타일을 바꿔 모바일과 데스크톱 모두에 대응할 수 있습니다.

## JavaScript: 동작과 상호작용

JavaScript는 웹 페이지에 동적인 기능을 부여하는 프로그래밍 언어입니다. 브라우저는 JavaScript 엔진을 내장하고 있어 별도의 설치 없이 코드를 실행할 수 있습니다. 개발자는 DOM(Document Object Model) API로 HTML 요소를 조회하고 수정하며, 이벤트 리스너로 사용자 입력에 반응합니다.

최근에는 `let`과 `const`, 화살표 함수, 프라미스(Promise), `async`/`await` 같은 문법이 표준화되어 비동기 작업을 더 읽기 쉽게 작성할 수 있습니다. 네트워크 요청에는 주로 `fetch()`를 사용합니다.

## 웹 API

브라우저는 JavaScript에서 호출할 수 있는 다양한 웹 API를 제공합니다. 대표적인 예는 다음과 같습니다.

- **DOM API**: 문서 구조를 조작합니다.
- **Fetch API**: HTTP 요청을 보내고 응답을 처리합니다.
- **Web Storage**: `localStorage`와 `sessionStorage`에 데이터를 저장합니다.
- **Canvas와 WebGL**: 2차원 및 3차원 그래픽을 그립니다.
- **Geolocation API**: 사용자의 위치 정보를 요청합니다. 이때는 반드시 사용자의 권한이 필요합니다.

## HTTP와 서버 통신

웹은 HTTP(HyperText Transfer Protocol)를 기반으로 동작합니다. 클라이언트가 요청(request)을 보내면 서버가 응답(response)을 반환하는 구조이며, 요청에는 메서드(GET, POST, PUT, DELETE 등), URL, 헤더, 본문이 포함됩니다. 응답의 상태 코드(200, 404, 500 등)는 요청의 결과를 알려 줍니다.

HTTP는 기본적으로 상태를 저장하지 않는(stateless) 프로토콜입니다. 로그인 상태 같은 정보를 유지하려면 쿠키나 토큰을 사용합니다. 통신 내용을 보호하려면 HTTPS로 암호화하는 것이 필수입니다.

## 개발 도구

브라우저의 개발자 도구(DevTools)는 웹 개발에 없어서는 안 될 도구입니다. 요소 검사, 콘솔 로그 확인, 네트워크 요청 분석, 성능 프로파일링 기능을 제공합니다. Git 같은 버전 관리 시스템, npm 같은 패키지 관리자, Vite나 webpack 같은 빌드 도구도 현대 웹 개발의 일상적인 구성 요소입니다.

## 웹 표준과 브라우저 호환성

웹 기술의 명세는 W3C와 WHATWG 같은 표준화 단체가 관리합니다. 같은 기능이라도 브라우저마다 지원 수준이 다를 수 있으므로, 새 기능을 도입하기 전에 호환성 정보를 확인하는 습관이 필요합니다.

점진적 향상(progressive enhancement)은 기본 기능을 먼저 제공하고, 지원되는 환경에서 고급 기능을 추가하는 전략입니다. 반대로 우아한 성능 저하(graceful degradation)는 최신 환경을 기준으로 만든 뒤 구형 환경에서 기능을 축소하는 방식입니다. 기능 감지(feature detection)로 API의 존재 여부를 확인하고, 필요하면 폴리필을 사용해 격차를 메울 수 있습니다.

## 학습 순서

처음에는 HTML로 문서 구조를 익히고, 이어서 CSS로 시각적 표현을 배우는 것을 권장합니다. 그다음 JavaScript로 간단한 상호작용을 구현하면서 DOM과 이벤트를 이해하고, HTTP와 API 호출을 학습하면 실제 서비스를 만들 수 있는 기초가 갖춰집니다. 이후 React나 Vue 같은 프레임워크를 배우면 대규모 애플리케이션 개발에 더 쉽게 접근할 수 있습니다. 프레임워크도 결국 기반 기술 위에 세워져 있으므로, 브라우저의 기본 동작을 이해하는 것이 장기적으로 가장 중요합니다.
