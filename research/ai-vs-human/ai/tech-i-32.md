# Binary Search Tree (BST)

## 1. 정의
이진 탐색 트리는 각 노드가 최대 두 개의 자식을 갖고, **왼쪽 서브트리의 모든 값 < 노드 값 < 오른쪽 서브트리의 모든 값**을 만족하는 트리다. 보통 중복 키는 허용하지 않거나 별도 규칙(카운트 필드 등)으로 처리한다. 중위 순회(in-order)를 하면 **오름차순 정렬 결과**가 나온다.

## 2. 핵심 연산과 시간 복잡도
| 연산 | 평균 | 최악(편향 트리) |
|---|---|---|
| 탐색 | O(log n) | O(n) |
| 삽입 | O(log n) | O(n) |
| 삭제 | O(log n) | O(n) |

- **탐색**: 루트에서 시작해 값이 작으면 왼쪽, 크면 오른쪽으로 이동한다.
- **삽입**: 탐색하듯 내려가 null 위치에 새 노드를 붙인다.
- **삭제**: 세 가지 경우로 나뉜다.
  1. 자식이 없음 → 그냥 제거
  2. 자식이 하나 → 자식을 부모에 연결
  3. 자식이 둘 → 오른쪽 서브트리의 최솟값(후继자, successor) 또는 왼쪽의 최댓값(전임자)으로 값을 대체한 뒤 그 노드를 삭제

## 3. 간단한 구현 (탐색/삽입)
```python
def insert(node, key):
    if not node: return Node(key)
    if key < node.key: node.left = insert(node.left, key)
    elif key > node.key: node.right = insert(node.right, key)
    return node
```

## 4. 최악의 경우와 균형 트리
정렬된 데이터를 순서대로 넣으면 한쪽으로만 자라 **연결 리스트처럼 높이가 n**이 된다. 이를 막기 위해 **AVL 트리**(균형 인수 ±1 유지, 회전)나 **레드-블랙 트리**(색 규칙으로 대략적 균형 유지)를 쓴다. Java의 `TreeMap`, C++의 `std::map`이 레드-블랙 트리 기반이다.

## 5. 면접 단골 질문
- **Q. BST와 해시 테이블의 차이는?** 해시는 평균 O(1) 탐색이지만 순서 정보가 없다. BST는 O(log n)이지만 정렬 순회, 범위 검색, 최솟값/최댓값, 선행·후행 원소 탐색이 가능하다.
- **Q. BST 유효성 검사는?** 각 노드가 허용 범위 (min, max)를 갖고 재귀하거나, 중위 순회 결과가 strictly 증가하는지 확인한다. 부모와만 비교하면 오답이다.
- **Q. 삭제 시 왜 후계자를 쓰나?** BST 성질을 유지하면서 대체할 수 있는 값이기 때문이다.
- **Q. 순회 방식은?** 전위(루트 먼저), 중위(정렬), 후위(자식 먼저, 삭제에 유용), 레벨 순회(BFS).

## 6. 정리
BST는 정렬된 상태를 유지하며 동적 삽입·삭제·탐색을 지원하는 구조다. 평균 O(log n)이지만 균형이 깨지면 O(n)이므로, 실무에서는 **자가 균형 트리**를 사용한다는 점을 반드시 언급하자.
