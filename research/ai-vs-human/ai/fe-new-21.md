## 1. 프레임워크 & 라이브러리

### React 18, 동시성 기능을 점진적으로 도입한다
6월 초 React 팀은 **React 18 계획**을 공개했고, 7월에는 알파 버전을 바탕으로 Working Group에서 논의가 이어졌습니다. 핵심은 "기존 앱을 깨지 않고 동시성(Concurrent) 기능을 **선택적으로** 켤 수 있게 한다"는 방향입니다. 주요 키워드는 다음과 같습니다.

- **자동 배칭(Automatic Batching)**: 이벤트 핸들러 밖(Promise, `setTimeout` 등)의 상태 업데이트도 한 번에 묶어 렌더링합니다.
- **Transition API**: 급한 업데이트(입력)와 덜 급한 업데이트(목록 필터링)를 구분합니다.
- **서버 사이드 Suspense**: 스트리밍 SSR과 선택적 하이드레이션으로 초기 로딩 체감을 개선합니다.

새 루트 API인 `createRoot`로 옮기는 것이 업그레이드의 출발점이 될 것으로 보입니다. 지금 당장 바꿀 필요는 없지만, `StrictMode` 경고를 미리 정리해 두면 나중에 편합니다.

### Vue 3.2 RC: `<script setup>`이 정식이 된다
Vue 3.2가 릴리스 후보 단계에 들어갔습니다. 실험 기능이던 `<script setup>`과 `<style>` 안의 `v-bind()`(CSS 변수 연동)가 **정식 기능**으로 올라올 예정입니다. 반응성 시스템도 내부적으로 손봐서 `ref` 생성과 의존성 추적이 눈에 띄게 빨라졌다고 합니다. Composition API의 보일러플레이트를 줄이고 싶었던 분들에게 반가운 소식입니다.

### Next.js 11 이후의 흐름
6월에 나온 Next.js 11이 Webpack 5 기본 적용, 이미지 컴포넌트 개선 등으로 계속 화제입니다. 커뮤니티에서는 Conformance와 Lighthouse 기반 성능 개선 이야기가 많이 오갔습니다.

## 2. 언어: TypeScript 4.4 베타

월말에 **TypeScript 4.4 베타**가 나왔습니다. 눈여겨볼 변경은 세 가지입니다.

1. **별칭 조건식의 제어 흐름 분석**: 조건을 변수에 담아도 타입 좁히기가 유지됩니다.
   ```ts
   function f(x: string | number) {
     const isString = typeof x === "string";
     if (isString) {
       x.toUpperCase(); // 4.4부터 x가 string으로 좁혀짐
     }
   }
   ```
2. **`--useUnknownInCatchVariables`**: `catch (e)`의 `e`를 `any` 대신 `unknown`으로 다룹니다. `strict` 모드에 포함될 예정이라 업그레이드 시 컴파일 에러가 늘 수 있습니다.
3. **`--exactOptionalPropertyTypes`**: `?` 속성에 `undefined`를 명시적으로 넣는 것과 속성이 없는 것을 구분합니다.

정식 출시는 8월 예정입니다. 큰 코드베이스라면 베타로 미리 빌드해 보는 것을 권합니다.

## 3. 브라우저 & 웹 표준

- **Chrome 92**(7월 20일경): `Array.prototype.at()`을 지원합니다. `arr.at(-1)`처럼 음수 인덱스로 마지막 요소에 접근할 수 있습니다. 보안 쪽에서는 교차 출처 격리 관련 개선도 이어졌습니다.
- **Firefox 90**: FTP 지원이 제거되었고, 자바스크립트 private 클래스 필드/메서드(`#field`) 지원이 들어왔습니다.
- **Safari 15 베타**: 새 탭 바 디자인과 주소창 동작을 두고 개발자·사용자 피드백이 많았습니다. 모바일 웹을 만든다면 `theme-color` 메타 태그 동작과 하단 주소창 환경에서의 레이아웃을 미리 점검해 보세요.
- **IE 11 지원 종료**(2022년 6월 예고): 레거시 브라우저 지원 범위를 정리하기 좋은 시점입니다. 폴리필과 번들 타깃(`browserslist`)을 점검해 보세요.

## 4. 도구 & 생태계

### Vite 2.4
빠른 개발 서버로 입지를 넓히고 있는 **Vite**가 2.4로 올라왔습니다. 최적화 의존성 처리와 SSR 관련 개선이 포함되었습니다. Vue 외에 React, Svelte 프로젝트에서도 CRA를 대체하는 선택지로 자주 언급됩니다.

### GitHub Copilot 기술 프리뷰
6월 말 발표된 **GitHub Copilot**이 7월 내내 화두였습니다. 주석이나 함수 시그니처만 쓰면 코드를 제안하는 AI 페어 프로그래머입니다. 반복적인 보일러플레이트와 테스트 코드 작성에는 도움이 되지만, 라이선스와 코드 품질 이슈는 아직 논쟁 중입니다. 제안을 그대로 받아들이기보다 리뷰어의 시선으로 검토하는 습관이 필요합니다.

### 스타일링
Tailwind CSS의 JIT 모드가 안정화되면서 빌드 시간과 CSS 용량 이슈가 크게 줄었다는 후기가 많습니다. 유틸리티 퍼스트 접근을 고민 중이라면 다시 평가해 볼 만합니다.

## 5. 이달의 팁: `Array.prototype.at()` 활용

```js
const items = ["a", "b", "c"];

// 기존
items[items.length - 1]; // "c"

// 이제는
items.at(-1);            // "c"
```

아직 모든 환경에서 지원되는 것은 아니므로, 프로덕션에서는 지원 범위를 확인하고 필요하면 폴리필(core-js 등)을 함께 쓰세요.
