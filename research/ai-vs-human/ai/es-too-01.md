# flow

함수형 프로그래밍에서 여러 함수를 **왼쪽에서 오른쪽 순서**로 합성해 하나의 새 함수를 만드는 유틸리티입니다. 중첩 호출(`h(g(f(x)))`)을 순서대로 읽히는 파이프라인 형태로 바꿀 수 있습니다.

## 시그니처

```js
flow(...fns) => (...args) => result
```

## 매개변수

| 이름 | 타입 | 설명 |
|---|---|---|
| `fns` | `Function[]` | 합성할 함수들. 첫 번째 함수는 임의의 인자를 받을 수 있고, 이후 함수는 직전 함수의 반환값 하나를 인자로 받습니다. 최소 1개 이상이어야 합니다. |

## 반환값

`Function`: 호출하면 첫 번째 함수에 인자를 전달하고, 각 함수의 반환값을 다음 함수로 넘긴 최종 결과를 돌려주는 새 함수입니다.

## 예제

```js
const add1 = (x) => x + 1;
const double = (x) => x * 2;
const toString = (x) => `결과: ${x}`;

const compute = flow(add1, double, toString);

compute(3); // "결과: 8"
```

## 동작 규칙

- 함수는 `fns` 배열의 순서대로 실행됩니다.
- 어느 단계에서든 예외가 발생하면 이후 함수는 실행되지 않고 예외가 그대로 전파됩니다.
- 입력으로 받은 함수는 변경되지 않으며, 만들어진 함수는 여러 번 재사용할 수 있습니다.

## 관련 항목

- `compose`: 오른쪽에서 왼쪽 방향으로 합성합니다.
- `pipe`: 방향은 `flow`와 같지만, 초기값을 첫 번째 인자로 직접 받습니다.
