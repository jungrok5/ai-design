# 서버 측 웹 프레임워크

**서버 측 웹 프레임워크**(서버 측 프레임워크 또는 "웹 애플리케이션 프레임워크")는 동적 웹 사이트를 만들 때 필요한 작업을 단순화해 주는 소프트웨어 프레임워크입니다. 이 프레임워크는 HTTP 요청 처리, URL 라우팅, 데이터베이스 접근, 템플릿 렌더링, 보안과 같이 거의 모든 웹 사이트에서 반복되는 기능을 미리 만들어 제공합니다. 이 문서에서는 서버 측 프레임워크가 무엇이고 왜 필요한지, 어떤 기준으로 선택해야 하는지 살펴보고, 널리 쓰이는 프레임워크 몇 가지를 소개합니다.

## 사전 요구 사항

- 기본적인 컴퓨터 활용 능력
- 서버 측 프로그래밍의 개념과 [클라이언트-서버 상호작용](https://developer.mozilla.org/ko/docs/Learn/Server-side/First_steps/Client-Server_overview)에 대한 이해

## 학습 목표

- 서버 측 웹 프레임워크가 코드 작성을 어떻게 쉽게 해 주는지 이해합니다.
- 프레임워크가 제공하는 핵심 기능을 설명할 수 있습니다.
- 프로젝트에 적합한 프레임워크를 고르는 기준을 알아봅니다.
- 대표적인 프레임워크의 특징을 비교합니다.

## 웹 프레임워크가 필요한 이유

서버 측 코드를 아무 도구 없이 작성한다고 생각해 봅시다. 요청이 들어올 때마다 URL을 직접 분석하고, 요청 방식(GET, POST 등)에 따라 분기하고, 폼 데이터를 파싱하고, 데이터베이스에 연결해 쿼리를 실행하고, 그 결과를 HTML로 조립해 응답해야 합니다. 이 과정은 반복적일 뿐 아니라 실수하기 쉽고, 보안 취약점으로 이어질 수도 있습니다.

웹 프레임워크는 이런 문제를 해결하기 위해 검증된 도구와 규칙을 제공합니다. 개발자는 저수준 세부 사항 대신 사이트의 고유한 동작, 즉 비즈니스 로직에 집중할 수 있습니다.

## 웹 프레임워크가 제공하는 기능

### HTTP 요청 처리와 응답

프레임워크는 들어오는 요청을 객체로 만들어 URL, 헤더, 쿠키, 폼 데이터 등에 쉽게 접근하게 해 줍니다. 응답 역시 상태 코드와 헤더를 직접 다루지 않고 간단한 함수나 클래스로 만들 수 있습니다.

### URL 라우팅

특정 URL 패턴을 특정 처리 함수(뷰, 컨트롤러, 핸들러 등)에 연결하는 기능입니다. 다음은 Express(Node.js)로 작성한 간단한 예시입니다.

```js
const express = require("express");
const app = express();

// "/users/42" 같은 요청을 처리한다.
app.get("/users/:id", (req, res) => {
  res.send(`사용자 번호: ${req.params.id}`);
});

app.listen(3000);
```

URL의 일부를 매개변수로 추출할 수 있으므로, 수많은 URL을 일일이 처리하는 코드를 쓰지 않아도 됩니다.

### 데이터베이스 접근

대부분의 프레임워크는 **ORM**(Object-Relational Mapper, 객체 관계 매핑)이나 이와 유사한 데이터 접근 계층을 제공합니다. 개발자는 SQL을 직접 작성하는 대신 객체와 메서드로 데이터를 다룹니다. 또한 SQL 인젝션 같은 공격을 막는 데도 도움이 됩니다.

```python
# Django ORM 예시
from django.db import models

class Book(models.Model):
    title = models.CharField(max_length=200)

# 제목에 "웹"이 포함된 책 조회
books = Book.objects.filter(title__contains="웹")
```

### 데이터 렌더링을 위한 템플릿

템플릿 엔진을 사용하면 HTML 구조에 자리 표시자를 두고 서버에서 데이터를 채워 최종 페이지를 만들 수 있습니다. 반복문과 조건문을 지원하는 경우가 많고, 출력값을 자동으로 이스케이프해 [교차 사이트 스크립팅(XSS)](https://developer.mozilla.org/ko/docs/Glossary/Cross-site_scripting) 위험을 줄여 줍니다.

### 세션과 인증

로그인 상태를 유지하는 세션 관리, 사용자 인증, 권한 부여 기능을 내장하거나 확장 기능 형태로 제공합니다. 비밀번호 해시 처리 같은 민감한 부분을 직접 구현하지 않아도 됩니다.

### 보안 기능

잘 만들어진 프레임워크는 CSRF(사이트 간 요청 위조) 방어, 클릭재킹 방지, 안전한 쿠키 설정 등 흔한 공격에 대한 보호 장치를 기본으로 제공합니다. 수많은 개발자가 사용하며 검증해 온 코드이므로 직접 만든 코드보다 안전한 경우가 많습니다.

### 기타 기능

- 폼 처리와 입력값 검증
- 관리자 페이지 자동 생성
- 파일 업로드와 정적 파일 제공
- 캐싱, 국제화(i18n), 로깅
- 테스트 도구와 개발용 서버

## 프레임워크 선택 기준

서버 측 프레임워크는 수십 가지가 있으며, "가장 좋은" 프레임워크는 없습니다. 다음 항목을 고려해 선택하세요.

**학습 곡선**: 이미 알고 있는 언어를 사용하는 프레임워크, 혹은 문서와 튜토리얼이 풍부한 프레임워크가 시작하기 쉽습니다.

**생산성**: 반복 작업을 얼마나 줄여 주는지 살펴봅니다. 이른바 "배터리 포함(batteries-included)" 프레임워크는 대부분의 기능을 기본 제공하고, 마이크로 프레임워크는 최소한의 핵심만 제공하며 필요한 부분을 직접 조합하게 합니다.

**성능**: 대부분의 사이트에서 프레임워크 자체의 속도 차이는 병목이 아닙니다. 데이터베이스, 네트워크, 캐싱 전략이 훨씬 큰 영향을 주는 경우가 많습니다. 다만 대규모 트래픽이 예상된다면 동시성 모델도 확인해 보세요.

**캐싱 및 확장성**: 캐시 백엔드를 지원하는지, 수평 확장이 쉬운 구조인지 확인합니다.

**커뮤니티와 지원**: 활발한 커뮤니티, 꾸준한 업데이트, 풍부한 서드파티 라이브러리는 장기적으로 큰 자산입니다. 보안 패치가 신속히 제공되는지도 중요합니다.

**호스팅 환경**: 사용하려는 호스팅 서비스나 클라우드 플랫폼이 해당 언어와 프레임워크를 지원하는지 확인합니다.

**라이선스와 유지 관리**: 오픈 소스 여부와 라이선스 조건, 프로젝트가 지속적으로 관리되고 있는지 살펴봅니다.

**HTTP 기능 지원**: REST API, 웹소켓, 스트리밍 등 프로젝트에 필요한 통신 방식을 지원하는지 검토합니다.

## 대표적인 서버 측 프레임워크

| 프레임워크 | 언어 | 특징 |
| --- | --- | --- |
| Django | Python | 배터리 포함형. ORM, 관리자 페이지, 인증을 기본 제공 |
| Flask | Python | 가볍고 유연한 마이크로 프레임워크 |
| Express | JavaScript (Node.js) | 최소한의 구조, 풍부한 미들웨어 생태계 |
| Ruby on Rails | Ruby | "설정보다 관례" 원칙, 빠른 개발 |
| Laravel | PHP | 우아한 문법, 풍부한 기능과 생태계 |
| Spring Boot | Java | 대규모 엔터프라이즈 환경에 적합 |
| ASP.NET Core | C# | 고성능, 크로스 플랫폼 |

### Django (Python)

Django는 "마감 기한에 쫓는 완벽주의자를 위한 웹 프레임워크"를 표방합니다. ORM, 템플릿, 인증, 관리자 인터페이스, 보안 기능이 모두 포함되어 있어 처음부터 완성도 높은 사이트를 빠르게 만들 수 있습니다. MDN의 [Django 튜토리얼](https://developer.mozilla.org/ko/docs/Learn/Server-side/Django)에서 단계별로 배울 수 있습니다.

### Express (Node.js)

Express는 Node.js 위에서 동작하는 가장 대중적인 프레임워크입니다. 구조를 강제하지 않아 자유도가 높고, 미들웨어를 조합해 원하는 기능을 추가합니다. 클라이언트와 서버에서 같은 언어(JavaScript)를 사용할 수 있다는 점이 장점입니다.

### Ruby on Rails

Rails는 "설정보다 관례(Convention over Configuration)"와 "반복하지 말라(DRY)"를 핵심 철학으로 삼습니다. 정해진 규칙을 따르면 적은 코드로 많은 일을 할 수 있어 프로토타입 제작에 강합니다.

### Laravel (PHP)

Laravel은 현대적인 PHP 개발을 대표하는 프레임워크로, 라우팅, ORM(Eloquent), 큐, 스케줄러 등 폭넓은 기능과 활발한 생태계를 갖추고 있습니다.

## 프레임워크를 사용하지 않아도 될까?

아주 작은 사이트라면 프레임워크 없이도 충분할 수 있습니다. 그러나 사이트가 커질수록 구조, 보안, 유지 보수 문제가 빠르게 늘어납니다. 학습 목적이 아니라면, 대부분의 실무 프로젝트에서는 프레임워크 사용이 훨씬 효율적이고 안전합니다.

## 요약

서버 측 웹 프레임워크는 라우팅, 데이터베이스 접근, 템플릿 렌더링, 인증, 보안과 같은 공통 작업을 대신 처리해 줍니다. 프레임워크를 고를 때는 학습 곡선, 생산성, 성능, 커뮤니티, 호스팅 환경 등을 종합적으로 고려해야 합니다. 어떤 프레임워크를 선택하든 핵심 개념은 서로 비슷하므로, 하나를 익히면 다른 프레임워크를 배우기도 한결 수월합니다.
