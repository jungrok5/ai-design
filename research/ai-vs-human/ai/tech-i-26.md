# ARM 프로세서

## 1. 개요
ARM(Advanced RISC Machines)은 영국 ARM Holdings가 설계하는 **RISC 기반 명령어 집합 구조(ISA)** 입니다. ARM은 칩을 직접 만들지 않고 **IP(설계 자산)를 라이선스**하는 비즈니스 모델을 씁니다. 삼성, 퀄컴, 애플, 엔비디아 등이 이를 받아 자사 SoC를 만듭니다. 저전력·고효율이 강점이라 모바일, 임베디드, IoT에서 사실상 표준이 되었고, 최근에는 서버(AWS Graviton)와 PC(Apple Silicon)로 확장되고 있습니다.

## 2. RISC 특징
- **고정 길이 명령어**(AArch64는 32비트): 디코딩이 단순하고 파이프라이닝에 유리합니다.
- **Load/Store 아키텍처**: 연산은 레지스터끼리만 하고, 메모리 접근은 LDR/STR 명령으로만 합니다.
- **많은 범용 레지스터**: AArch64는 X0~X30의 64비트 레지스터 31개를 둡니다.
- **조건부 실행**: ARM32에서는 대부분의 명령에 조건 코드를 붙여 분기를 줄일 수 있었습니다.

## 3. 아키텍처 버전과 실행 상태
| 구분 | 설명 |
|---|---|
| AArch32 | 32비트 상태. ARM / Thumb / Thumb-2 명령 세트 |
| AArch64 | 64비트 상태 (ARMv8-A 이후). A64 명령 세트 |

Thumb은 16비트 압축 명령으로 코드 밀도를 높이고, Thumb-2는 16/32비트를 혼합합니다.

## 4. 프로파일 (Cortex 계열)
- **Cortex-A**: 애플리케이션용. MMU와 가상 메모리를 지원하며 스마트폰과 서버에 쓰입니다.
- **Cortex-R**: 실시간용. 결정적 지연 시간이 필요한 하드디스크, 자동차 제동 제어 등에 씁니다.
- **Cortex-M**: 마이크로컨트롤러용. 초저전력이며 MMU 대신 MPU를 둡니다. STM32가 대표적입니다.

## 5. 동작 모드와 예외 레벨
ARM32에는 User, FIQ, IRQ, Supervisor, Abort, Undefined, System 모드가 있습니다. ARMv8에서는 **예외 레벨(EL0~EL3)** 로 정리됩니다.
- EL0: 사용자 애플리케이션
- EL1: OS 커널
- EL2: 하이퍼바이저
- EL3: Secure Monitor (TrustZone)

## 6. 주요 기술
- **TrustZone**: Secure World와 Normal World를 하드웨어로 분리합니다.
- **big.LITTLE / DynamIQ**: 고성능 코어와 고효율 코어를 섞어 전력 대비 성능을 최적화합니다.
- **NEON / SVE**: SIMD 벡터 연산 확장입니다. 멀티미디어와 ML에 쓰입니다.
- **메모리 모델**: Weakly-ordered라서 재정렬이 일어나므로 DMB, DSB, ISB 같은 배리어가 필요합니다.

## 7. x86과의 비교
| 항목 | ARM | x86 |
|---|---|---|
| 설계 철학 | RISC | CISC |
| 명령어 길이 | 고정(주로) | 가변 |
| 전력 효율 | 높음 | 상대적으로 낮음 |
| 비즈니스 | IP 라이선스 | 인텔·AMD 자체 생산 |
| 메모리 순서 | 약한 순서 | 상대적으로 강한 순서(TSO) |

## 8. 면접 예상 질문
1. **ARM이 저전력인 이유는?** 단순한 명령어와 디코더 덕분에 트랜지스터가 적고, big.LITTLE로 부하에 맞게 코어를 고르기 때문입니다.
2. **Thumb 모드를 쓰는 이유는?** 코드 크기를 줄여 메모리와 캐시 효율을 높이기 위해서입니다.
3. **인터럽트 처리 순서는?** 예외 발생 → 현재 상태를 LR/SPSR에 저장 → 벡터 테이블로 분기 → ISR 실행 → 복귀 순서입니다.
4. **멀티스레드에서 배리어가 필요한 이유는?** 약한 메모리 모델에서는 CPU가 읽기/쓰기 순서를 바꿀 수 있기 때문입니다.
5. **Cortex-A와 Cortex-M의 차이는?** MMU 유무, 대상 OS(리눅스 vs RTOS/베어메탈), 성능과 전력 목표가 다릅니다.

## 9. 한 줄 요약
> ARM은 **RISC 철학 + IP 라이선스 모델**로 저전력 시장을 장악했고, 예외 레벨·TrustZone·약한 메모리 모델을 이해하면 면접에서 깊이 있게 답할 수 있다.
