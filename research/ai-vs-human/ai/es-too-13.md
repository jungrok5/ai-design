# dedent

여러 줄 문자열의 공통 들여쓰기를 제거하는 유틸리티 함수입니다. 코드 안에서는 템플릿 리터럴을 들여쓰기에 맞춰 보기 좋게 작성하고, 결과 문자열에는 불필요한 앞쪽 공백이 남지 않도록 할 때 사용합니다.

## 시그니처

```js
dedent(strings, ...values)
dedent(text)
```

- `strings`: 태그드 템플릿으로 호출될 때 전달되는 문자열 배열(`TemplateStringsArray`)
- `values`: 템플릿에 삽입된 표현식 값
- `text`: 일반 문자열로 호출할 때의 입력 문자열

## 매개변수

| 이름 | 타입 | 설명 |
|---|---|---|
| `text` | `string` | 들여쓰기를 제거할 원본 문자열 |
| `...values` | `any[]` | 태그드 템플릿에 삽입되는 값 |

## 반환값

`string`: 공백만 있는 줄을 제외한 모든 줄에서 공통으로 나타나는 가장 작은 들여쓰기를 제거하고, 문자열 앞뒤의 빈 줄을 정리한 결과입니다.

## 동작 규칙

1. 공백만 있는 줄은 들여쓰기 계산에서 제외합니다.
2. 공통 들여쓰기 너비를 구한 뒤 각 줄 앞에서 같은 길이만큼 제거합니다.
3. 문자열 시작과 끝에 있는 빈 줄은 제거합니다.

## 예제

```js
const sql = dedent`
  SELECT id, name
  FROM users
  WHERE active = ${true}
`;
// "SELECT id, name\nFROM users\nWHERE active = true"
```

## 주의

- 탭과 공백을 섞어 들여쓰면 너비가 일치하지 않아 의도와 다르게 제거될 수 있습니다.
- 한 가지 문자(공백 또는 탭)로 들여쓰기를 통일하는 것을 권장합니다.
