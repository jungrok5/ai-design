# React 영상

React에 대해 더 깊이 알고 싶다면 글과 문서뿐 아니라 영상도 좋은 학습 자료가 됩니다. 이 페이지에서는 React 팀과 커뮤니티가 공개한 컨퍼런스 발표와 강연 중, React의 설계 철학과 핵심 개념을 이해하는 데 도움이 되는 영상을 소개합니다.

> 영상 대부분은 영어로 제공되며, 일부는 자동 생성 자막이나 커뮤니티 번역 자막을 지원합니다. 발표 시점에 따라 일부 API가 현재와 다를 수 있으니, 최신 내용은 항상 공식 문서를 함께 확인하세요.

## React Conf 2021

2021년 열린 React Conf에서는 React 18의 방향성과 새로운 동시성(Concurrency) 기능이 처음으로 폭넓게 소개되었습니다.

### React 18 키노트

React 팀이 직접 발표한 키노트입니다. React 18에서 도입된 **동시성 렌더링**의 배경과 목표를 설명하고, 사용자 경험을 해치지 않으면서 복잡한 UI 업데이트를 처리하는 방법을 소개합니다. 다음과 같은 내용을 다룹니다.

- 자동 배칭(Automatic Batching)을 통한 렌더링 성능 개선
- `startTransition`을 활용한 긴급 업데이트와 비긴급 업데이트의 구분
- Suspense를 이용한 서버 사이드 렌더링 스트리밍
- 점진적 도입(Gradual Adoption)을 위한 업그레이드 전략

### 모두를 위한 React 18

React 18이 라이브러리 작성자와 애플리케이션 개발자 각각에게 어떤 의미인지 설명하는 발표입니다. 기존 코드를 크게 수정하지 않고도 새로운 기능을 선택적으로 사용할 수 있다는 점을 강조합니다. `createRoot`로 전환하는 방법과 Strict Mode의 변화도 함께 다룹니다.

### Suspense를 활용한 스트리밍 서버 렌더링

서버에서 HTML을 한 번에 보내지 않고 조각 단위로 스트리밍하는 방식을 설명합니다. 느린 데이터 요청 때문에 전체 페이지 표시가 지연되는 문제를 어떻게 해결하는지, 그리고 선택적 하이드레이션(Selective Hydration)이 사용자 상호작용을 어떻게 우선 처리하는지 살펴볼 수 있습니다.

## React Conf 2019

### Hooks 이후의 React

Hooks가 도입된 이후 React 개발 방식이 어떻게 달라졌는지 돌아보는 발표입니다. 클래스 컴포넌트의 한계, 로직 재사용의 어려움, 그리고 Hooks가 이 문제들을 어떻게 해결했는지를 다룹니다. 아직 Hooks가 낯선 분들에게 설계 의도를 이해하는 좋은 출발점입니다.

### Suspense와 동시성 모드의 미래

데이터 가져오기, 코드 분할, 로딩 상태 처리를 선언적으로 표현하려는 Suspense의 초기 구상을 소개합니다. 당시 구상이 현재의 React 18과 이후 버전으로 어떻게 발전했는지 비교하며 보면 더욱 흥미롭습니다.

## React Conf 2018

### Hooks 소개

Sophie Alpert와 Dan Abramov가 Hooks를 처음 공개한 유명한 발표입니다. `useState`와 `useEffect`의 기본 개념과 함께, 왜 클래스 없이도 상태와 생명주기를 다룰 수 있어야 하는지를 라이브 코딩으로 보여줍니다.

```js
import { useState } from 'react';

function Counter() {
  const [count, setCount] = useState(0);

  return (
    <button onClick={() => setCount(count + 1)}>
      {count}번 클릭했습니다
    </button>
  );
}
```

위 예시처럼 간단한 함수 하나로 상태를 가진 컴포넌트를 작성할 수 있다는 점이 당시 많은 개발자에게 큰 인상을 남겼습니다.

### React 로드맵: 시간 분할과 Suspense

React의 장기 계획을 소개한 발표로, 시간 분할(Time Slicing)과 Suspense라는 두 축을 중심으로 동시성 모드의 비전을 설명합니다. 렌더링이 CPU 성능에 의존하는 경우와 네트워크 지연에 의존하는 경우를 구분하여, 각각에 맞는 해결책을 제시합니다.

## React 핵심 개념 강연

### 선언적 UI로 생각하기

React의 가장 기본이 되는 사고방식인 선언적 UI를 설명합니다. "어떻게" 화면을 바꿀지가 아니라 "무엇을" 보여줄지를 기술하는 방식이 코드 복잡도를 어떻게 낮추는지 알려줍니다. 입문자라면 가장 먼저 보기를 권합니다.

### 상태 끌어올리기와 데이터 흐름

컴포넌트 사이에서 데이터를 어떻게 공유할지 고민할 때 도움이 되는 강연입니다. 단방향 데이터 흐름, 상태 끌어올리기, 그리고 Context를 사용해야 하는 시점을 사례 중심으로 설명합니다.

### 이펙트를 올바르게 사용하는 방법

`useEffect`를 남용하면 발생하는 문제와 이를 피하는 방법을 다룹니다. 다음 항목을 중심으로 살펴보면 좋습니다.

1. 이펙트가 필요 없는 경우와 필요한 경우를 구분하는 기준
2. 의존성 배열을 정직하게 작성해야 하는 이유
3. 정리(cleanup) 함수가 하는 역할
4. 데이터 가져오기에서 발생하는 경쟁 상태(Race Condition) 처리

## 성능과 도구

### React Developer Tools 활용하기

React DevTools의 Components 탭과 Profiler 탭을 사용해 컴포넌트 트리를 살펴보고 불필요한 리렌더링을 찾는 방법을 시연합니다. 성능 문제를 감으로 추측하지 않고 측정을 통해 접근하는 습관을 기를 수 있습니다.

### 메모이제이션을 언제 써야 할까

`memo`, `useMemo`, `useCallback`을 무조건 사용하는 것이 능사가 아니라는 점을 설명합니다. 실제로 비용이 큰 계산이나 참조 동일성이 중요한 경우에만 적용하는 것이 좋으며, 먼저 컴포넌트 구조를 개선하는 편이 효과적일 때가 많다는 사례를 소개합니다.

## 영상 학습 팁

영상을 더 효과적으로 활용하려면 다음 방법을 추천합니다.

- **공식 문서와 함께 보기**: 영상에서 개념을 먼저 접한 뒤, 공식 문서의 해당 페이지에서 정확한 API와 예제를 확인하세요.
- **직접 따라 해 보기**: 발표에 나오는 코드를 샌드박스에서 직접 작성해 보면 이해가 훨씬 깊어집니다.
- **발표 시점 확인하기**: React는 계속 발전하므로, 오래된 영상은 현재 권장 방식과 다를 수 있습니다. 설명 란의 날짜와 댓글을 확인하세요.
- **재생 속도 조절하기**: 익숙한 주제라면 배속 재생으로 빠르게 훑고, 어려운 부분만 천천히 다시 보세요.
