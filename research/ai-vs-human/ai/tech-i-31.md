# [C] 포인터(Pointer)

## 1. 정의
**포인터**는 다른 변수의 **메모리 주소**를 값으로 저장하는 변수입니다. `&` 연산자로 주소를 얻고, `*` 연산자로 그 주소에 있는 값에 접근합니다(역참조).

```c
int a = 10;
int *p = &a;   // p는 a의 주소를 저장
*p = 20;       // a의 값이 20으로 바뀜
```

## 2. 포인터의 크기와 타입
- 포인터의 크기는 가리키는 타입과 관계없이 **플랫폼에 따라 정해집니다**. 32비트에서는 4바이트, 64비트에서는 8바이트입니다.
- 포인터 타입은 **역참조할 때 읽을 바이트 수**와 **포인터 연산의 이동 단위**를 정합니다.

## 3. 포인터 연산
`p + 1`은 주소를 1바이트가 아니라 **`sizeof(*p)`만큼** 옮깁니다. 그래서 `int *p`라면 보통 4바이트 이동합니다.

## 4. 배열과 포인터
- 배열 이름은 대부분의 식에서 **첫 원소의 주소로 바뀝니다(decay)**. 그래서 `arr[i]`와 `*(arr + i)`는 같습니다.
- 다만 배열 이름은 상수라서 다른 값을 대입할 수 없습니다. 또 `sizeof(arr)`는 포인터 크기가 아니라 배열 전체의 크기를 돌려줍니다.

## 5. 주요 개념
| 개념 | 설명 |
|---|---|
| NULL 포인터 | 아무것도 가리키지 않는 포인터. 역참조하면 정의되지 않은 동작(UB)이 됩니다 |
| 댕글링 포인터 | 이미 해제된 메모리를 가리키는 포인터 |
| 와일드 포인터 | 초기화하지 않아 쓰레기 주소를 가진 포인터 |
| `void *` | 타입이 없는 범용 포인터. 역참조하기 전에 형변환이 필요합니다 |
| 이중 포인터 | 포인터의 주소를 저장합니다(`int **pp`) |
| 함수 포인터 | 함수의 주소를 저장합니다. 콜백 구현에 씁니다 |

## 6. Call by Value vs Call by Reference
C는 기본적으로 **값에 의한 전달(Call by Value)**만 지원합니다. 함수 안에서 호출한 쪽의 변수를 바꾸려면 포인터를 넘겨 **참조에 의한 전달처럼** 동작하게 만듭니다.

```c
void swap(int *x, int *y) { int t = *x; *x = *y; *y = t; }
```

## 7. const와 포인터
- `const int *p`: 가리키는 **값**을 바꿀 수 없습니다.
- `int *const p`: 포인터 **자체(주소)**를 바꿀 수 없습니다.
- `const int *const p`: 값과 주소 모두 바꿀 수 없습니다.

## 💡 면접 예상 질문
1. **포인터를 왜 쓰나요?** 동적 메모리 할당(`malloc`)을 하고, 큰 데이터를 복사하지 않고 효율적으로 넘기고, 연결 리스트나 트리 같은 자료구조를 만들고, 함수 밖의 값을 바꾸기 위해서입니다.
2. **메모리 누수와 댕글링 포인터는 어떻게 막나요?** `malloc`에는 반드시 `free`를 짝지어 호출합니다. 해제한 뒤에는 포인터에 `NULL`을 대입합니다.
3. **배열과 포인터의 차이는?** `sizeof` 결과, 대입 가능 여부, 메모리 할당 방식이 다릅니다.
