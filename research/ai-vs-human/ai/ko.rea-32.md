# 설치하기

React는 처음 시작하는 사람도 쉽게 사용할 수 있도록 설계되어 있습니다. 이 페이지에서는 React를 바로 체험해 보는 방법, 새 프로젝트를 만드는 방법, 기존 프로젝트에 React를 추가하는 방법을 안내합니다.

## React 바로 체험하기

별도의 설치 없이 브라우저에서 React를 써 보고 싶다면 온라인 샌드박스를 이용할 수 있습니다. CodeSandbox나 StackBlitz 같은 서비스에서 React 템플릿을 고르면 바로 코드를 작성하고 결과를 확인할 수 있습니다. 간단한 컴포넌트를 실험하거나 개념을 익힐 때 특히 유용합니다.

## 새 React 프로젝트 시작하기

실제 서비스를 만든다면 빌드 도구와 개발 서버가 갖춰진 프레임워크를 사용하는 것을 권장합니다. 대표적인 선택지는 다음과 같습니다.

- **Next.js**: 서버 렌더링과 라우팅을 기본으로 제공하는 풀스택 프레임워크입니다.
- **React Router**: 클라이언트 라우팅을 중심으로 한 프레임워크 모드를 제공합니다.
- **Expo**: React Native로 모바일 앱을 만들 때 사용합니다.
- **Vite**: 빠른 개발 서버와 빌드를 제공하는 도구로, 설정을 직접 구성하고 싶을 때 适합니다.

이 도구들을 사용하려면 Node.js가 설치되어 있어야 합니다. 터미널에서 프로젝트 생성 명령을 실행하면 필요한 파일과 기본 설정이 자동으로 만들어집니다.

## 기존 프로젝트에 React 추가하기

이미 운영 중인 웹사이트의 일부만 React로 만들고 싶다면 기존 프로젝트에 점진적으로 도입할 수 있습니다. npm이나 yarn 같은 패키지 매니저로 `react`와 `react-dom`을 설치한 뒤, 원하는 HTML 요소를 루트로 지정하고 `createRoot`로 컴포넌트를 렌더링하면 됩니다.

```bash
npm install react react-dom
```

## 설치 확인하기

개발 서버를 실행하고 브라우저에서 화면이 정상적으로 나타나는지 확인합니다. 개발자 도구 콘솔에 경고나 오류가 없는지도 함께 살펴보세요. 문제가 생기면 Node.js 버전과 패키지 설치 상태를 먼저 점검하는 것이 좋습니다.
