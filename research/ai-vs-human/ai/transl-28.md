# 소개

MDN 웹 문서(MDN Web Docs)는 웹 개발자를 위한 가장 폭넓고 신뢰할 수 있는 참고 자료 중 하나입니다. 이 문서는 MDN이 어떤 프로젝트인지, 누구를 위한 것인지, 그리고 어떻게 활용하면 좋은지를 간략히 안내합니다.

## MDN 웹 문서란?

MDN 웹 문서는 HTML, CSS, JavaScript와 같은 개방형 웹 기술과 웹 API를 설명하는 무료 온라인 문서 저장소입니다. 과거 "Mozilla Developer Network"에서 출발해 지금은 MDN이라는 이름으로 널리 알려져 있으며, Mozilla와 여러 기여자가 함께 운영합니다. 문서의 모든 내용은 커뮤니티가 함께 작성하고 검토하며, 오픈 소스 방식으로 개선됩니다.

MDN의 목표는 단순합니다. **웹을 만드는 모든 사람이 정확한 정보를 쉽게 찾고, 더 나은 웹을 만들 수 있도록 돕는 것**입니다. 이를 위해 MDN은 특정 브라우저나 기업의 이익에 치우치지 않고, 표준 명세와 실제 브라우저 동작을 기준으로 내용을 서술합니다.

## 누구를 위한 문서인가요?

MDN은 다양한 수준의 독자를 고려하여 구성되어 있습니다.

- **입문자**: 웹 개발을 처음 접하는 학습자는 "학습 영역"에서 단계별 안내를 따라 기초부터 익힐 수 있습니다.
- **현업 개발자**: 특정 요소, 속성, 메서드의 정확한 동작이나 문법이 궁금할 때 참고 문서를 빠르게 찾아볼 수 있습니다.
- **디자이너와 기획자**: 웹 기술이 무엇을 할 수 있고 어떤 제약이 있는지 이해하는 데 도움을 받을 수 있습니다.
- **교육자**: 강의 자료의 근거나 예제를 찾을 때 신뢰할 만한 출처로 활용할 수 있습니다.
- **기여자와 번역가**: 문서를 직접 고치거나 새로운 언어로 번역하여 커뮤니티에 보탬이 될 수 있습니다.

## 문서의 구성

MDN의 내용은 크게 몇 가지 영역으로 나뉩니다.

### 참고 문서(Reference)

각 기술의 세부 사항을 사전처럼 정리한 영역입니다. HTML 요소, CSS 속성, JavaScript 내장 객체, 웹 API, HTTP 헤더 등이 여기에 속합니다. 각 항목에는 보통 다음과 같은 내용이 담겨 있습니다.

1. 개요와 용도에 대한 설명
2. 문법(구문)과 매개변수
3. 사용 예제와 실행 가능한 데모
4. 관련 명세 링크
5. 브라우저 호환성 표

### 가이드(Guide)

참고 문서가 "무엇이 있는가"를 설명한다면, 가이드는 "어떻게 사용하는가"를 설명합니다. 특정 주제를 처음부터 끝까지 이어서 읽을 수 있도록 서술되어 있어, 개념을 깊이 이해하고 싶을 때 적합합니다.

### 학습 영역(Learn)

웹 개발을 체계적으로 배울 수 있도록 설계된 교육 과정입니다. 웹의 작동 원리, 기본 도구 설정, HTML 구조 만들기, CSS로 꾸미기, JavaScript로 동작 추가하기처럼 순서대로 학습하도록 구성되어 있습니다. 실습 과제와 평가 문제가 포함된 단원도 많아, 읽는 데 그치지 않고 직접 만들어 보며 익힐 수 있습니다.

## 문서를 읽는 방법

### 예제 코드 활용하기

MDN의 많은 페이지에는 라이브 예제(interactive example)가 포함되어 있습니다. 코드를 직접 수정하고 결과를 바로 확인할 수 있으므로, 설명을 읽은 뒤 값을 바꿔 가며 실험해 보는 것을 권장합니다. 아래는 간단한 예입니다.

```js
const greeting = "안녕하세요, MDN!";
console.log(greeting);
```

### 브라우저 호환성 확인하기

웹 기술은 브라우저마다 지원 시점과 범위가 다를 수 있습니다. 각 참고 문서 하단의 **브라우저 호환성** 표를 확인하면 어떤 브라우저의 어떤 버전부터 기능을 사용할 수 있는지 알 수 있습니다. 실제 서비스에 새 기능을 도입하기 전에는 반드시 이 표를 살펴보세요.

### 상태 표시 읽기

문서에는 기능의 성숙도를 나타내는 배지가 붙기도 합니다.

- **실험적(Experimental)**: 아직 명세가 확정되지 않아 앞으로 바뀔 수 있는 기능
- **더 이상 사용되지 않음(Deprecated)**: 사용을 권장하지 않으며 향후 제거될 수 있는 기능
- **표준 아님(Non-standard)**: 표준 트랙에 올라 있지 않은 기능

이러한 표시가 있는 기능은 운영 환경에서 신중하게 사용해야 합니다.

## 검색과 탐색

MDN 상단의 검색창에서 키워드를 입력하면 관련 문서를 찾을 수 있습니다. 요소 이름(`<div>`), 속성 이름(`flex-direction`), 메서드 이름(`Array.prototype.map`)처럼 구체적으로 입력할수록 정확한 결과를 얻습니다. 또한 페이지 왼쪽의 사이드바는 같은 주제의 문서를 계층적으로 보여 주므로, 관련 항목을 이어서 살펴볼 때 유용합니다.

## 커뮤니티와 기여

MDN은 누구나 참여할 수 있는 열린 프로젝트입니다. 오타를 바로잡거나, 설명을 보강하거나, 새로운 예제를 추가하는 일 모두 소중한 기여입니다. 기여 방법은 대체로 다음과 같습니다.

1. 문서 하단의 "이 페이지에 기여하기" 링크를 통해 GitHub 저장소로 이동합니다.
2. 수정하고 싶은 내용을 편집하거나, 이슈로 문제를 제보합니다.
3. 풀 리퀘스트(Pull Request)를 제출하면 검토자가 내용을 확인하고 반영합니다.

한국어 번역에 참여하는 것도 좋은 방법입니다. 영어 원문을 정확하게 옮기면서도 한국어 독자가 자연스럽게 읽을 수 있도록 다듬는 작업은 국내 웹 개발 생태계 전체에 큰 도움이 됩니다.

## 라이선스

MDN의 텍스트 콘텐츠는 일반적으로 Creative Commons 라이선스(CC-BY-SA)에 따라 공유되며, 예제 코드는 별도의 퍼블릭 도메인 계열 라이선스로 제공되는 경우가 많습니다. 자료를 재사용하거나 재배포할 때는 각 페이지 하단의 라이선스 안내를 확인하고 출처를 명시해야 합니다.

## 다음 단계

MDN을 처음 사용한다면 다음 순서를 추천합니다.

- 웹 개발이 처음이라면 **학습 영역**의 "웹 시작하기" 단원부터 읽어 보세요.
- 이미 기본기가 있다면 **HTML**, **CSS**, **JavaScript** 참고 문서를 둘러보며 모르는 요소와 속성을 찾아보세요.
- 새 기능을 도입하려 한다면 해당 문서의 **브라우저 호환성** 표와 **명세** 항목을 먼저 확인하세요.
- 문서에서 개선할 점을 발견했다면 주저하지 말고 **기여**에 참여해 보세요.

MDN은 읽고 끝나는 문서가 아니라, 함께 만들어 가는 웹의 공용 지식 기반입니다. 필요한 정보를 찾는 데서 시작해 점차 더 깊이 배우고, 언젠가는 직접 기여하는 경험까지 이어 가시길 바랍니다.
