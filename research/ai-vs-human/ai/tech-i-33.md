# 데이터 타입 (Data Types)

## 1. 개념
데이터 타입은 값의 **종류**, 메모리에서 차지하는 **크기**, 그 값에 가능한 **연산**을 정의합니다. 컴파일러와 런타임은 이 정보로 메모리를 해석하고 잘못된 연산을 막습니다.

## 2. 기본 타입 (Primitive)
- **정수**: `int`, `long` 등은 고정 크기라 표현 범위를 넘으면 **오버플로**가 발생합니다.
- **실수**: `float`, `double`은 IEEE 754 이진 부동소수점 방식이라 `0.1 + 0.2 != 0.3`처럼 오차가 생깁니다. 금액 계산에는 `BigDecimal`처럼 십진수 타입을 씁니다.
- **문자/불리언**: `char`, `boolean`.

## 3. 값 타입과 참조 타입
기본 타입은 값 자체를 저장합니다. 배열, 객체, 문자열 같은 참조 타입은 **힙(heap)** 에 있는 객체의 **주소**를 변수에 저장합니다.
- 값 타입은 대입 시 값이 **복사**됩니다.
- 참조 타입은 대입 시 주소가 **공유**됩니다. 그래서 함수에 객체를 넘긴 뒤 내부 상태를 바꾸면 원본에도 영향이 갑니다.

## 4. 스택과 힙
- **스택**: 지역 변수와 함수 호출 정보를 저장합니다. LIFO 구조이고 빠르며 수명이 짧습니다.
- **힙**: 동적으로 할당된 객체를 저장합니다. GC가 회수하거나 수동으로 해제해야 합니다.

## 5. 문자열의 불변성
Java `String`, Python `str`, JavaScript 문자열은 **불변(immutable)** 입니다. 반복해서 이어 붙이면 매번 새 객체가 생기므로 `StringBuilder`나 `join`을 사용합니다.

## 6. null과 undefined
- `null`: 값이 없음을 명시적으로 나타냅니다.
- `undefined`(JavaScript): 선언만 되고 값이 할당되지 않은 상태입니다.
- `Optional`처럼 타입 시스템에서 null 가능성을 드러내면 NPE를 줄일 수 있습니다.

## 7. 형 변환
- **묵시적(implicit)**: 손실이 없는 방향으로 자동 변환됩니다. 예: `int` → `long`.
- **명시적(explicit)**: 캐스팅으로 강제 변환합니다. 예: `double` → `int`는 소수점이 버려집니다.

## 8. 정적 타입과 동적 타입
- **정적**(Java, TypeScript): 컴파일 시점에 타입을 검사해 오류를 일찍 발견합니다.
- **동적**(Python, JavaScript): 실행 시점에 타입이 정해집니다. 유연하지만 런타임 오류 가능성이 높습니다.

## 9. 면접 예상 질문
- **값 타입과 참조 타입의 차이는?** 복사하느냐, 주소를 공유하느냐입니다.
- **`==`와 `equals`의 차이는?** `==`는 참조(또는 기본값)를 비교하고, `equals`는 내용을 비교합니다.
- **Java에서 `Integer` 값 -128~127은 `==`로 비교해도 true인 이유는?** 이 범위는 정수 캐시에 저장되어 같은 객체를 가리키기 때문입니다. 이 범위 밖에서는 `equals`로 비교해야 합니다.
- **부동소수점을 금융 계산에 쓰면 안 되는 이유는?** 이진 표현 오차가 누적되기 때문입니다.
