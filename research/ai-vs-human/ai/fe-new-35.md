# 프론트엔드 월간 뉴스레터 — 2025-01

> 새해 첫 호입니다. 연말연초에 굵직한 메이저 릴리스가 몰려서 업그레이드 계획을 세울 거리가 많은 달이었습니다. 이번 호에서는 꼭 알아야 할 소식만 추렸습니다.

## 🔥 이달의 헤드라인

### 1. React 19 정식 출시

작년 12월 초, React 19가 드디어 정식 버전이 되었습니다. RC 기간이 길었던 만큼 안정성에 대한 기대가 큽니다.

- **Actions**: 비동기 함수를 트랜지션에 바로 넘길 수 있습니다. pending 상태, 에러, 낙관적 업데이트를 React가 처리해 줍니다.
- **새 훅**: `useActionState`, `useOptimistic`가 추가되었고, 렌더링 중에 Promise나 Context를 읽는 `use` API도 들어왔습니다.
- **`ref`를 prop으로 전달**: 함수 컴포넌트에서 `forwardRef` 없이 `ref`를 받을 수 있습니다.
- **문서 메타데이터 지원**: 컴포넌트 안에서 `<title>`, `<meta>`를 렌더링하면 `<head>`로 자동으로 옮겨집니다.
- **Server Components / Server Actions**: 안정 기능으로 자리 잡았습니다.

업그레이드 전에는 공식 마이그레이션 가이드와 codemod를 먼저 확인하세요. `propTypes`, 문자열 ref 같은 레거시 API가 제거되었으므로 오래된 라이브러리의 호환성부터 점검하는 것이 좋습니다.

### 2. Tailwind CSS v4.0 출시

1월 말에 Tailwind CSS v4.0이 공개되었습니다. 엔진을 처음부터 다시 만든 수준의 변화입니다.

- **CSS 우선 설정**: `tailwind.config.js` 대신 CSS 안의 `@theme` 블록에서 디자인 토큰을 정의합니다.
- **한 줄 임포트**: `@import "tailwindcss";` 한 줄이면 설정이 끝납니다.
- **빌드 속도 향상**: 새 엔진 덕분에 전체 빌드와 증분 빌드가 모두 크게 빨라졌습니다.
- **콘텐츠 자동 감지**: `content` 경로를 따로 적지 않아도 템플릿 파일을 찾아냅니다.
- **모던 CSS 활용**: 캐스케이드 레이어, `@property`, `color-mix()` 등을 적극적으로 사용합니다.

공식 업그레이드 도구(`npx @tailwindcss/upgrade`)가 있지만, 최신 브라우저를 전제로 하므로 지원 범위를 먼저 확인하세요.

### 3. Vite 6과 Environment API

11월 말에 나온 Vite 6이 생태계 전반에 퍼지고 있습니다. 가장 큰 변화는 실험 단계인 **Environment API**입니다. 클라이언트, SSR, 엣지 런타임처럼 서로 다른 실행 환경을 하나의 개발 서버에서 일관되게 다룰 수 있게 해 줍니다. 일반 SPA 사용자는 체감할 변화가 거의 없지만, 프레임워크와 플러그인 작성자에게는 중요한 기반입니다.

## ⚡ 빠르게 훑어보기

- **Next.js 15.1**: React 19 정식 버전을 지원합니다. 응답 이후에 작업을 실행하는 `after()` API가 안정화되었고, 에러 디버깅 화면도 개선되었습니다.
- **Astro 5**: Content Layer로 다양한 출처의 콘텐츠를 하나의 방식으로 불러올 수 있습니다. 정적 페이지에 동적 조각을 끼워 넣는 Server Islands도 추가되었습니다.
- **Angular 19**: standalone 컴포넌트가 기본값이 되었습니다. 점진적 하이드레이션(프리뷰)과 `linkedSignal`, `resource` 같은 신호 기반 API도 추가되었습니다.
- **Svelte 5 안정화 진행 중**: runes 기반 반응성 모델로의 전환이 계속되고 있고, 새 CLI `sv`로 프로젝트 셋업이 간편해졌습니다.
- **React Router v7**: Remix의 기능을 흡수해 라이브러리로도, 풀스택 프레임워크로도 쓸 수 있게 되었습니다.

## 🛠️ 도구와 런타임

- **Vitest 3.0**: 리포터가 개선되었고 브라우저 모드 설정이 정리되었습니다. 테스트 필터링 옵션도 더 유연해졌습니다.
- **Bun 1.2**: 내장 S3·Postgres 클라이언트가 추가되었고, 텍스트 기반 lockfile(`bun.lock`)로 바뀌었습니다. Node.js 호환성도 크게 개선되었습니다.
- **Node.js 23.6**: 타입 스트리핑이 플래그 없이 기본 활성화되어, 간단한 `.ts` 파일을 별도 빌드 없이 실행할 수 있습니다. 다만 enum처럼 런타임 변환이 필요한 문법은 지원하지 않습니다.
- **TypeScript 5.8 베타**: 이런 흐름에 맞춰 `--erasableSyntaxOnly` 옵션이 추가되었습니다. "타입만 지우면 실행되는 코드"를 강제하는 옵션입니다.

## 💡 이달의 팁: 업그레이드 순서 정하기

메이저 업데이트가 한꺼번에 몰렸다면 순서가 중요합니다.

1. **런타임과 빌드 도구 먼저**: Node.js와 Vite를 올리고 CI가 통과하는지 확인합니다.
2. **프레임워크 다음**: React 19나 Next.js 15처럼 영향 범위가 큰 것은 별도 브랜치에서 진행하고, codemod를 적극 활용합니다.
3. **스타일링은 마지막에**: Tailwind v4는 결과 화면이 미묘하게 달라질 수 있습니다. 시각 회귀 테스트나 스크린샷 비교를 함께 쓰는 것을 추천합니다.
