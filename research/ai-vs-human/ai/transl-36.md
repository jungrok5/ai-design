# 웹 작동방식

**웹 작동방식**은 컴퓨터나 휴대폰의 웹 브라우저에서 웹 페이지를 볼 때 어떤 일이 일어나는지 간단히 설명합니다.

## 클라이언트와 서버

웹에 연결된 컴퓨터는 **클라이언트**와 **서버**로 나뉩니다.

- **클라이언트**는 사용자가 인터넷에 연결하는 기기와, 그 기기에서 웹에 접근하는 소프트웨어(보통 Firefox나 Chrome 같은 웹 브라우저)를 말합니다.
- **서버**는 웹 페이지, 사이트, 앱을 저장하는 컴퓨터입니다. 클라이언트가 웹 페이지를 요청하면 서버는 페이지 사본을 클라이언트로 보내고, 브라우저가 이를 표시합니다.

## 그 밖의 구성 요소

웹이 작동하려면 클라이언트와 서버 말고도 다음 요소가 필요합니다.

- **인터넷 연결**: 웹에서 데이터를 주고받을 수 있게 해 줍니다.
- **TCP/IP**: 데이터가 웹을 오가는 방식을 정하는 통신 프로토콜입니다.
- **DNS**: 웹사이트 주소를 찾아 주는 전화번호부와 같습니다. 브라우저는 사람이 기억하기 쉬운 도메인 이름(예: `developer.mozilla.org`)을 서버의 실제 IP 주소로 바꿔야 합니다.
- **HTTP**: 클라이언트와 서버가 서로 소통하는 데 쓰는 언어를 정의한 프로토콜입니다.
- **구성 파일**: 웹사이트는 여러 파일로 이루어집니다. 크게 두 종류가 있습니다.
  - **코드 파일**: 주로 HTML, CSS, JavaScript로 만듭니다.
  - **애셋**: 이미지, 음악, 동영상, PDF 등 나머지 파일입니다.

## 어떤 일이 일어날까요?

브라우저 주소창에 웹 주소를 입력하면 다음 순서로 진행됩니다.

1. 브라우저가 DNS 서버에 접속해 웹사이트가 있는 서버의 실제 주소를 찾습니다.
2. 브라우저가 서버에 HTTP 요청을 보내 웹사이트 사본을 달라고 합니다. 이 메시지와 클라이언트·서버 사이의 모든 데이터는 TCP/IP로 전송됩니다.
3. 서버가 요청을 승인하면 "200 OK" 메시지를 보냅니다. 이는 요청이 성공했다는 뜻입니다. 이어서 서버는 웹사이트 파일을 **패킷**이라는 작은 조각으로 나눠 브라우저로 보냅니다.
4. 브라우저가 패킷을 다시 합쳐 완전한 웹 페이지로 만들어 화면에 표시합니다.

### 패킷이란?

데이터는 수천 개의 작은 조각으로 나뉘어 전송됩니다. 이렇게 하면 패킷 하나가 손상되거나 사라져도 그 부분만 다시 보내면 됩니다. 또한 패킷마다 다른 경로로 보낼 수 있어서 데이터를 더 빨리 주고받을 수 있습니다.
