# 다익스트라(Dijkstra) 알고리즘

## 개요
다익스트라 알고리즘은 **음이 아닌 가중치**를 가진 그래프에서 시작 정점으로부터 다른 모든 정점까지의 최단 거리를 구하는 알고리즘이다. 1959년 에츠허르 다익스트라가 고안했으며, 매 단계에서 가장 가까운 정점을 확정하는 그리디(탐욕) 방식으로 동작한다.

## 동작 원리
1. 시작 정점의 거리는 0, 나머지 정점의 거리는 무한대(∞)로 초기화한다.
2. 아직 방문하지 않은 정점 중 거리가 가장 작은 정점을 선택하고 방문 처리한다.
3. 선택한 정점을 거쳐 인접 정점으로 가는 거리를 계산해 갱신한다. (`dist[v] = min(dist[v], dist[u] + w)`)
4. 모든 정점을 방문할 때까지 2~3을 반복한다.

## 구현 (우선순위 큐 사용)
```python
import heapq

def dijkstra(graph, start):
    dist = {v: float('inf') for v in graph}
    dist[start] = 0
    pq = [(0, start)]
    while pq:
        d, u = heapq.heappop(pq)
        if d > dist[u]:          # 이미 더 짧은 거리로 처리된 정점은 건너뜀
            continue
        for v, w in graph[u]:
            if dist[u] + w < dist[v]:
                dist[v] = dist[u] + w
                heapq.heappush(pq, (dist[v], v))
    return dist
```

## 복잡도
- 배열에서 최솟값을 선형 탐색하는 방식: O(V²)
- 최소 힙(우선순위 큐) 방식: O((V + E) log V)

## 주의사항
- **음수 가중치가 있으면 올바르게 동작하지 않는다.** 이미 확정한 정점의 거리가 나중에 더 줄어들 수 있기 때문이다. 음수 간선이 있다면 벨만-포드 알고리즘을 사용한다.
- 거리뿐 아니라 실제 경로가 필요하면 각 정점의 이전 정점을 저장하는 `prev` 배열을 함께 관리한다.
- 모든 간선의 가중치가 같다면 BFS로 충분하다.

## 면접 포인트
- **왜 그리디인가?** 음수 간선이 없으면 현재 가장 가까운 정점까지의 거리는 다른 경로를 거쳐도 더 짧아질 수 없으므로 확정해도 안전하다.
- **알고리즘 비교:** 다익스트라(단일 시작점, 음수 불가) / 벨만-포드(단일 시작점, 음수 가능, O(VE)) / 플로이드-워셜(모든 쌍, O(V³))
