# 프론트엔드 월간 뉴스레터 2023-12

안녕하세요, 12월호입니다. 올해 마지막 호라서 연말에 나온 주요 릴리스와 브라우저 소식을 모았고, 내년에 챙겨 볼 흐름도 함께 정리했습니다.

---

## 🔥 이달의 헤드라인

### Vue 3.4 "Slam Dunk" 릴리스 (12월 28일)
연말에 나온 이번 릴리스의 핵심은 **템플릿 파서 재작성**입니다.

- 파서 속도가 이전보다 약 2배 빨라졌고, 전체 빌드 성능도 좋아졌습니다.
- 속성명과 변수명이 같을 때 `:id="id"`를 `:id`로 줄여 쓸 수 있는 **same-name shorthand**가 추가되었습니다.
- `defineModel`이 안정화되어 양방향 바인딩 컴포넌트를 훨씬 간결하게 작성할 수 있습니다.
- 하이드레이션 불일치 오류 메시지가 개선되어 SSR 디버깅이 한결 편해졌습니다.

일부 deprecated 기능이 제거되었으니, 업그레이드 전에 마이그레이션 가이드와 호환 빌드를 꼭 확인하세요.

### Tailwind CSS v3.4 (12월 19일)
- `vh` 대신 `dvh`, `svh`, `lvh` 같은 **동적 뷰포트 단위** 유틸리티가 추가되었습니다. 모바일 주소창 때문에 생기던 높이 문제를 줄여 줍니다.
- `:has()` 기반의 `has-*` 변형이 생겼습니다.
- `size-*` 유틸리티로 `w-*`와 `h-*`를 한 번에 지정할 수 있습니다.
- `text-wrap: balance` 같은 최신 CSS도 유틸리티로 쓸 수 있습니다.

### Astro 4.0 (12월 초)
- 개발 중 접근성과 성능 이슈를 바로 보여 주는 **Dev Toolbar**가 추가되었습니다.
- View Transitions API 지원이 개선되었습니다.
- 다국어 라우팅 기능이 확장되었습니다.

콘텐츠 중심 사이트를 만든다면 올해의 주목할 프레임워크 중 하나입니다.

## 🌐 브라우저와 웹 플랫폼

- **Firefox 121**(12월 19일): 마침내 **`:has()` 선택자**를 지원합니다. 이제 주요 3대 엔진이 모두 지원하므로, 폴백 없이 실무에서 쓰기 훨씬 수월해졌습니다. 리눅스에서는 Wayland가 기본으로 적용됩니다.
- **Chrome 120**: 정식 배포와 함께 서드파티 쿠키 폐지 일정이 구체화되었습니다. 2024년 1분기에 일부 사용자(약 1%)를 대상으로 제한 테스트를 시작할 계획입니다. 광고와 트래킹뿐 아니라 임베드 위젯, SSO, 결제 연동 등 쿠키에 기대는 기능이 있다면 미리 점검해 두세요.
- **Safari 17.2**: 시스템 업데이트와 함께 여러 웹 플랫폼 기능이 보강되었습니다. 세부 내용은 WebKit 블로그의 릴리스 노트를 참고하세요.

> 💡 **한 줄 팁**: `:has()`, 컨테이너 쿼리, CSS 중첩, `text-wrap: balance`처럼 최근 몇 달 사이 크로스 브라우저 지원이 갖춰진 기능이 많습니다. 연말에 CSS 리팩터링 계획을 세워 보기 좋은 시점입니다.

## 🛠 도구와 생태계 (직전 릴리스 정리)

11월 말부터 12월 초까지 나온 릴리스가 많아서, 놓쳤을 수 있는 것들을 함께 정리합니다.

| 도구 | 버전 | 주요 변화 |
|---|---|---|
| **Angular** | 17 (11월 8일) | 새로운 블록 제어 흐름(`@if`, `@for`), 지연 로딩 `@defer`, Vite·esbuild 기반 빌드, 새 로고와 문서 사이트 |
| **Vite** | 5.0 (11월 16일) | Rollup 4 기반, Node 18 이상 필요, CJS Node API 지원 중단 예고 |
| **TypeScript** | 5.3 (11월 20일) | import attributes, `switch (true)` 타입 좁히기 개선 |
| **Next.js** | 14 (10월 26일) | Server Actions 안정화, Partial Prerendering 프리뷰 |

특히 Angular 17은 템플릿 문법이 크게 바뀌었습니다. 기존 `*ngIf`, `*ngFor`도 계속 동작하므로 마이그레이션 스키매틱을 이용해 점진적으로 옮기면 됩니다.

## 🔮 2024년을 앞두고 챙겨 볼 흐름

- **시그널(Signals) 확산**: Angular, Vue, Solid, Preact에 이어 Svelte 5의 룬(Runes)까지, 세밀한 반응성 모델이 프레임워크마다 자리 잡고 있습니다.
- **서버 중심 렌더링의 성숙**: React Server Components와 Server Actions, 부분 프리렌더링 등 서버와 클라이언트의 경계를 다시 설계하는 흐름이 이어집니다.
- **빌드 도구의 Rust화**: Turbopack, Rspack, Biome처럼 네이티브 도구가 속도 면에서 기존 도구를 빠르게 따라잡고 있습니다.
- **웹 플랫폼의 약진**: View Transitions, 스크롤 기반 애니메이션, 앵커 포지셔닝 등 JS로 구현하던 기능이 브라우저 기본 기능으로 들어오고 있습니다.
