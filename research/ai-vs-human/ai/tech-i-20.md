# Process Management & PCB

## 1. 프로세스란?
- **프로세스(Process)**: 실행 중인 프로그램. 디스크의 프로그램(정적)이 메모리에 적재되어 CPU 할당을 받는 **동적 개체**입니다.
- 메모리 구조: **Code(Text)**, **Data**(전역·static), **Heap**(동적 할당, 아래→위), **Stack**(지역변수·함수 호출, 위→아래).
- 프로세스끼리는 독립된 주소 공간을 가지므로 서로의 메모리에 직접 접근할 수 없습니다. 통신에는 IPC(파이프, 소켓, 공유 메모리, 메시지 큐)가 필요합니다.

## 2. PCB (Process Control Block)
운영체제가 프로세스를 관리하기 위해 프로세스마다 유지하는 **메타데이터 자료구조**입니다. 커널 영역에 저장됩니다.

| 항목 | 내용 |
|---|---|
| PID | 프로세스 고유 식별자 |
| 프로세스 상태 | New, Ready, Running, Waiting, Terminated |
| Program Counter | 다음에 실행할 명령어 주소 |
| CPU 레지스터 | 문맥 복원에 필요한 레지스터 값 |
| 스케줄링 정보 | 우선순위, 스케줄링 큐 포인터 |
| 메모리 정보 | 페이지 테이블, 베이스/리밋 레지스터 |
| 입출력 정보 | 열린 파일 목록, 할당된 I/O 장치 |
| 계정 정보 | CPU 사용 시간, 사용자 ID |

## 3. 프로세스 상태 전이
1. **New → Ready**: 생성 후 승인(admit)
2. **Ready → Running**: 스케줄러가 CPU 할당(dispatch)
3. **Running → Ready**: 타임 슬라이스 만료 또는 선점(preemption)
4. **Running → Waiting**: I/O 요청, 이벤트 대기
5. **Waiting → Ready**: I/O 완료
6. **Running → Terminated**: 종료(exit)

## 4. 컨텍스트 스위칭 (Context Switching)
- 실행 중인 프로세스의 상태를 **PCB에 저장**하고, 다음 프로세스의 PCB에서 상태를 **복원**하여 CPU를 넘기는 작업입니다.
- 이 시간은 순수한 **오버헤드**입니다. 그동안 유용한 작업을 하지 못합니다.
- 캐시 미스와 TLB flush 때문에 전환 직후 성능이 떨어집니다.
- 스레드 간 전환은 주소 공간을 공유하므로 프로세스 간 전환보다 비용이 작습니다.

## 5. 프로세스 생성과 종료
- **fork()**: 부모를 복제해 자식을 생성합니다. 반환값은 부모에게 자식 PID, 자식에게 0입니다. 현대 OS는 **Copy-on-Write**로 복사 비용을 줄입니다.
- **exec()**: 현재 프로세스의 이미지를 새 프로그램으로 교체합니다.
- **wait()**: 부모가 자식의 종료를 기다리고 종료 상태를 수거합니다.
- **좀비 프로세스**: 종료됐지만 부모가 wait()하지 않아 PCB가 남아 있는 상태입니다.
- **고아 프로세스**: 부모가 먼저 종료된 자식입니다. init(PID 1)이 입양하여 정리합니다.

## 6. 스케줄러 종류
- **장기(Job) 스케줄러**: 메모리에 올릴 프로세스를 선택하며, 멀티프로그래밍 정도를 조절합니다.
- **단기(CPU) 스케줄러**: Ready 큐에서 다음 실행할 프로세스를 선택하며, 매우 자주 호출됩니다.
- **중기(Swapper) 스케줄러**: 프로세스를 swap-out/in 하여 메모리 부하를 조절합니다.

## 7. 면접 예상 질문
1. **PCB에는 무엇이 들어 있나요?** → PID, 상태, PC, 레지스터, 스케줄링·메모리·I/O 정보입니다.
2. **컨텍스트 스위칭이 왜 비용이 큰가요?** → 상태 저장·복원 자체의 비용에 더해 캐시·TLB 무효화가 발생하기 때문입니다.
3. **프로세스와 스레드의 차이는?** → 프로세스는 독립된 주소 공간을 갖고, 스레드는 Code·Data·Heap을 공유하며 Stack과 레지스터만 따로 갖습니다.
4. **좀비 프로세스는 어떻게 해결하나요?** → 부모가 wait()를 호출하거나, SIGCHLD를 처리하거나, 부모를 종료시켜 init이 수거하게 합니다.

## 핵심 요약
> PCB는 프로세스의 신분증이자 상태 저장소입니다. 컨텍스트 스위칭은 PCB를 통해 이뤄지며, 이 비용을 이해하는 것이 스레드, 스케줄링, 동기화로 이어지는 학습의 출발점입니다.
