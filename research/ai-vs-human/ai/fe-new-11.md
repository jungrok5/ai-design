# 🗞️ 프론트엔드 월간 소식 — 2024-01

> 새해 첫 호입니다. 연말연시에 나온 굵직한 릴리스와 1월의 주요 소식을 정리했습니다. 올해 프론트엔드 흐름을 미리 짐작해 볼 수 있는 소식이 많습니다.

## 📌 이번 호 요약

- **Vue 3.4**: 파서와 반응성 시스템을 다시 작성해 성능 개선
- **Angular 17.1**: 시그널 기반 입력(Signal Inputs) 개발자 프리뷰 공개
- **Next.js 14.1**: 셀프 호스팅과 개발자 경험 개선
- **TypeScript 5.4 베타**: `NoInfer` 유틸리티 타입 추가
- **Chrome 121**: CSS로 스크롤바 스타일 지정 가능

## 1. 프레임워크 소식

### 🟢 Vue 3.4 "Slam Dunk"

연말에 나온 Vue 3.4는 겉으로 드러나지 않는 부분에서 변화가 큰 릴리스입니다. 템플릿 파서를 새로 작성해 **파싱 속도가 약 2배 빨라졌고**, 반응성 시스템도 리팩터링했습니다. 그 결과 computed 값이 실제로 바뀌었을 때만 다시 계산되도록 개선되었습니다.

개발자가 바로 체감할 변화도 있습니다.

- `defineModel` 매크로 정식 안정화로 양방향 바인딩 컴포넌트 작성이 훨씬 간단해졌습니다.
- `v-bind` 같은 이름 축약 문법을 지원합니다. `:id="id"`를 `:id`로 줄여 쓸 수 있습니다.

```vue
<script setup>
const model = defineModel()
</script>

<template>
  <input v-model="model" />
</template>
```

### 🔴 Angular 17.1 — 시그널 입력

Angular 17에서 새 제어 흐름 문법(`@if`, `@for`)과 지연 로딩 블록(`@defer`)을 선보인 데 이어, 17.1에서는 **시그널 기반 입력(`input()`)**을 개발자 프리뷰로 공개했습니다. 기존 `@Input()` 데코레이터 대신 함수로 입력을 선언하므로, 파생 상태를 `computed()`로 자연스럽게 만들 수 있습니다.

```ts
@Component({ /* ... */ })
export class UserCard {
  name = input.required<string>();
  greeting = computed(() => `안녕하세요, ${this.name()}님`);
}
```

Zone.js 없이도 동작하는 "zoneless" Angular로 가는 큰 흐름 안에 있는 변화라서 계속 지켜볼 만합니다.

### ⚫ Next.js 14.1

Next.js 14.1은 새 기능보다 다듬기에 집중한 릴리스입니다.

- **셀프 호스팅 개선**: 이미지 최적화, ISR 캐시 관련 문서와 설정이 보강되었습니다. Vercel 외 환경에 배포하는 팀에 반가운 소식입니다.
- **Turbopack 안정성 향상**: `next dev --turbo`의 테스트 통과율이 크게 올랐습니다.
- **에러 메시지 개선**: 프레임워크 내부 스택을 걸러 내 원인을 찾기 쉬워졌습니다.
- `next/image`에 `getImageProps()`가 추가되어 `<picture>` 태그 같은 고급 사용 사례를 지원합니다.

### 🟠 그 밖의 소식

- **Svelte 5**: 룬(Runes) 기반 프리뷰가 계속 다듬어지고 있습니다. `$state`, `$derived`, `$effect`로 반응성을 명시적으로 다루는 방식이 커뮤니티에서 활발히 논의되고 있습니다.
- **Astro 4.x**: 12월 4.0 출시 이후 마이너 버전이 빠르게 나오고 있습니다. 개발 툴바(Dev Toolbar)와 i18n 라우팅을 다듬는 중입니다.
- **Nuxt 3.9**: 연말 릴리스에서 Vite 5를 도입하고 인터랙티브 서버 컴포넌트 같은 실험 기능을 추가했습니다.

## 2. 언어와 도구

### 🔷 TypeScript 5.4 베타

이번 베타에서 가장 눈에 띄는 기능은 **`NoInfer<T>` 유틸리티 타입**입니다. 특정 위치에서 타입 추론이 일어나지 않도록 막아, 제네릭 함수의 의도하지 않은 추론을 방지합니다.

```ts
function createLight<C extends string>(
  colors: C[],
  defaultColor?: NoInfer<C>
) { /* ... */ }

createLight(["red", "yellow", "green"], "blue"); // ❌ 이제 오류
```

또한 **마지막 할당 이후 클로저 안에서도 타입 좁히기(narrowing)가 유지**되어, 불필요한 non-null 단언(`!`)을 줄일 수 있습니다.

### 🦕 Deno 1.40

Deno 1.40은 **Temporal API**를 불안정(unstable) 플래그로 지원하고, 표준 **데코레이터**를 도입했습니다. 날짜와 시간을 다루는 고질적인 문제를 해결할 Temporal을 런타임에서 직접 실험해 볼 수 있다는 점이 흥미롭습니다.

### 🛠️ 도구 생태계 한 줄 소식

- **Vite 5** 생태계 전환이 대부분 마무리되었습니다. Rollup 4 기반으로 빌드 성능이 좋아졌으니, 아직 4.x를 쓰고 있다면 마이그레이션 가이드를 확인해 보세요.
- **Biome**은 지난해 Prettier 호환성 챌린지를 계기로 주목받은 뒤 꾸준히 업데이트되고 있습니다. "하나의 도구로 린트와 포맷을"이라는 흐름이 더 뚜렷해지고 있습니다.

## 3. 브라우저와 웹 플랫폼

### 🌐 Chrome 121

- **`scrollbar-color`, `scrollbar-width` 지원**: 이제 비표준 `::-webkit-scrollbar` 대신 표준 속성으로 스크롤바를 꾸밀 수 있습니다.

```css
.panel {
  scrollbar-width: thin;
  scrollbar-color: #8b5cf6 transparent;
}
```

- **`::spelling-error`, `::grammar-error` 의사 요소**: 맞춤법 검사 표시를 사이트 디자인에 맞게 스타일링할 수 있습니다.

### 🦊 Firefox · 🧭 Safari

Firefox 122와 Safari 17.3도 1월에 함께 출시되었습니다. 큰 기능보다는 호환성 개선과 버그 수정 위주입니다. 브라우저 간 기능 차이를 줄이려는 공동 프로젝트 **Interop**의 새해 목표 발표도 곧 있을 예정이니 다음 호에서 다루겠습니다.

## 4. 이달의 읽을거리 📚

- **"2024년, 프레임워크는 시그널로 수렴하는가?"**: Angular, Vue, Svelte, Solid, Preact가 모두 세밀한 반응성(fine-grained reactivity)으로 모이고 있습니다. TC39에서 시그널 표준화 논의가 시작될 수 있다는 이야기도 나옵니다.
- **서버 컴포넌트 회고**: React Server Components를 실무에 도입한 팀들의 경험담이 많이 공유되고 있습니다. 캐싱 동작을 이해하기 어렵다는 점이 공통으로 지적됩니다.
- **CSS의 르네상스**: 컨테이너 쿼리, `:has()`, 네이티브 중첩(nesting)이 주요 브라우저에 모두 들어오면서 "이제 전처리기가 꼭 필요한가?"라는 질문이 다시 나오고 있습니다.
