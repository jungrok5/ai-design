flowkit은 사내 데이터 파이프라인 도구입니다. 작업 파일에 실행할 단계, 스케줄, 재시도 횟수를 적어 저장소에 올리면 flowkit 스케줄러가 그 시각에 단계를 순서대로 실행하고 결과를 기록합니다.

작업 파일의 최상위 키

필수 키가 빠지면 flowkit validate가 실패합니다. 단계별 키(run, depends_on, env)는 YAML 레퍼런스에 있습니다.

키설명기본값
name필수작업 이름. 저장소 안에서 겹치면 안 됩니다.없음
owner필수실패 알림을 받는 팀없음
schedule실행 시각. cron과 timezone을 씁니다. 빼면 수동 실행 전용 작업이 됩니다.없음
steps필수실행할 단계 목록. depends_on이 없으면 적은 순서대로 실행합니다.없음
retries실패한 단계를 다시 실행하는 횟수[TODO]
timeout작업 전체 제한 시간. 넘으면 실패로 끝냅니다.[TODO]

schedule.cron은 분, 시, 일, 월, 요일 다섯 칸으로 씁니다. timezone을 빼면 [TODO: 기본 시간대] 기준으로 실행합니다.

실행 상태

대기
예약 시각 전, 또는 앞 단계를 기다리는 중
실행 중
단계 하나 이상이 실행되고 있음
재시도
실패한 단계를 retries 횟수 안에서 다시 실행하는 중
성공
모든 단계가 종료 코드 0으로 끝남
실패
재시도를 다 쓰거나 timeout을 넘김. owner 팀에 알림

전체 문서

  • YAML 레퍼런스작업과 단계에 쓰는 모든 키, 템플릿 변수
  • 스케줄과 재실행cron, 시간대, 지난 날짜 재처리(backfill)
  • CLI 명령validate, run, status, logs
  • 알림 설정실패 알림을 받을 채널과 조건
  • 장애 대응실패한 작업의 로그 확인과 수동 재실행
  • 변경 이력버전별 추가·변경된 키
