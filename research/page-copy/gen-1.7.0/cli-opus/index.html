로그를 따라가며 거르고, 묶고, 센다

logpipe는 로그 파일을 tail 하면서 조건에 맞는 줄만 남기고, 원하는 필드로 묶어 몇 초마다 집계표를 다시 그립니다. grep | awk | sort | uniq -c를 매번 조립하던 일을 명령 하나로 줄입니다.

go install github.com/your-org/logpipe@latest
GitHub에서 보기 사용 예 보기

Go로 작성한 단일 바이너리 · Linux, macOS, Windows · MIT 라이선스

이렇게 씁니다

JSON, logfmt, 일반 텍스트 로그를 자동으로 알아봅니다. 텍스트 로그는 정규식으로 필드를 뽑을 수 있습니다.

필요한 줄만 남기기

필드 조건은 --where로 겁니다. and, or, 비교 연산자, 정규식 매칭(~)을 쓸 수 있습니다.

logpipe tail app.log --where 'status>=500 and path~"^/api/"'
14:05:11 ERROR status=502 path=/api/orders  upstream reset
14:05:13 ERROR status=500 path=/api/cart    nil pointer in CartService
14:05:13 ERROR status=503 path=/api/orders  circuit open

지난 로그를 한 번에 집계하기

tail 대신 scan을 쓰면 파일을 끝까지 읽고 결과를 한 번 출력합니다. 압축된 .gz 파일도 그대로 읽습니다.

logpipe scan access.log.gz --by path --count --top 5
PATH              COUNT
/api/search      48,120
/api/orders      19,877
/api/cart        11,402
/health           8,640
/api/login        3,215

다른 도구로 넘기기

--out json을 주면 갱신마다 한 줄짜리 JSON을 내보냅니다. jq나 알림 스크립트에 바로 연결할 수 있습니다.

logpipe tail app.log --by level --every 1m --out json | jq .
{
  "window": "1m",
  "at": "2026-10-22T14:06:00+09:00",
  "groups": { "info": 9812, "warn": 204, "error": 17 }
}

설치

Go가 있다면

go install github.com/your-org/logpipe@latest

Go 1.22 이상이 필요합니다. 바이너리는 $GOPATH/bin에 설치됩니다.

바이너리로 받기

curl -sSL https://github.com/your-org/logpipe/releases/latest/download/logpipe_linux_amd64.tar.gz | tar xz

macOS, Windows, ARM 빌드는 릴리스 페이지에 있습니다.

자주 쓰는 옵션

옵션하는 일예
--where조건에 맞는 줄만 남깁니다'level=error'
--by이 필드 값으로 묶습니다. 쉼표로 여러 개service,host
--every집계표를 다시 그리는 간격10s, 1m
--count / --sum / --p95그룹마다 계산할 값--p95 latency_ms
--parse텍스트 로그에서 필드를 뽑을 정규식'(?P<level>\w+) (?P<msg>.*)'
--out출력 형식: table, json, csvjson

전체 옵션은 logpipe help나 README에서 볼 수 있습니다.
