흘러가는 로그를 바로 거르고 셉니다

logpipe는 로그 파일이나 표준 입력을 읽으면서 조건에 맞는 줄만 남기고, 원하는 필드로 묶어 일정 시간마다 집계를 출력하는 Go CLI입니다. grep, awk, sort | uniq -c를 이어 붙이던 일을 명령 하나로 끝냅니다.

go install github.com/your-org/logpipe@latest
GitHub에서 보기 사용 예 보기

단일 바이너리 · 의존성 없음 · Linux, macOS, Windows

nginx 접근 로그에서 5xx 응답만 골라 10초마다 경로별로 셉니다 예시 출력

어떻게 동작하나요

한 줄씩 읽고, 필드로 나누고, 조건으로 거른 뒤, 구간마다 묶어서 출력합니다. 파일 전체를 메모리에 올리지 않아서 몇 GB짜리 로그나 끝나지 않는 스트림에도 그대로 쓸 수 있습니다.

이런 때 씁니다

배포 직후 에러가 늘었는지 확인

에러 레벨 로그만 골라 1분마다 서비스별 개수를 봅니다. 숫자가 튀는 서비스가 바로 보입니다.

logpipe app.log --follow \
  --where 'level == "error"' \
  --by service --every 1m

느린 요청이 몰리는 엔드포인트 찾기

응답 시간이 1초를 넘는 요청을 경로별로 묶고 많은 순으로 10개만 보여 줍니다.

logpipe access.log \
  --where 'duration_ms > 1000' \
  --by path --top 10

집계 결과를 다른 도구로 넘기기

JSON으로 내보내면 jq로 다시 가공하거나 알림 스크립트에 그대로 넣을 수 있습니다.

kubectl logs -f deploy/api \
  | logpipe --where 'status >= 500' \
      --by status --every 30s -o json

셸 파이프라인과 비교

같은 일을 기존 도구로 하면 이렇게 됩니다.

하려는 일grep + awk + sortlogpipe
스트림을 구간별로 집계직접 구현하거나 스크립트를 따로 작성--every 10s
JSON 로그의 필드로 거르기jq를 추가로 연결--where 'level == "error"'
숫자 비교 (>=, <)필드 위치를 세어 awk로 비교필드 이름으로 바로 비교
개수 많은 순 상위 N개sort | uniq -c | sort -rn | head--top N

주요 옵션

전체 목록은 logpipe --help로 볼 수 있습니다.

옵션설명기본값
--where남길 줄의 조건식모든 줄
--by묶을 필드. 쉼표로 여러 개없음 (개수만)
--every집계를 출력하는 간격입력이 끝날 때 한 번
--top개수 많은 순으로 상위 N개만전부
--formatjson, logfmt, nginx, autoauto
-o출력 형식: table, json, csvtable
--follow파일 끝에서 새 줄을 계속 읽음꺼짐

설치

Go 1.22 이상이 있으면

go install github.com/your-org/logpipe@latest

$GOPATH/bin이 PATH에 있어야 합니다.

소스에서 빌드

git clone https://github.com/your-org/logpipe
cd logpipe && go build -o logpipe .

미리 빌드한 바이너리는 Releases에 있습니다.
