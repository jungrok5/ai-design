flowkit
개요 시작하기 YAML 레퍼런스 스케줄 CLI

배치 작업을 YAML 파일 하나로 정의하고 스케줄에 올립니다

flowkit은 사내 데이터 파이프라인 도구입니다. 무엇을 어떤 순서로, 언제 돌릴지를 파일 하나에 적으면 스케줄러가 그대로 실행하고, 실패하면 재시도한 뒤 알림을 보냅니다. 크론탭이나 개인 서버에 흩어진 스크립트를 한곳으로 모으는 것이 목적입니다.

첫 작업 올리기 YAML 레퍼런스 보기

jobs/daily_orders.yaml

# 매일 03시, 주문 데이터를 정리해 BigQuery에 적재
name: daily_orders
owner: data-platform
schedule:
  cron: "0 3 * * *"
  timezone: Asia/Seoul
tasks:
  - id: extract
    run: sql/extract_orders.sql
    source: mysql.orders
  - id: transform
    run: python transforms/clean_orders.py
    needs: [extract]
  - id: load
    target: bigquery.analytics.orders_daily
    needs: [transform]
retry:
  attempts: 3
  backoff: 10m
notify:
  on_failure: "#data-alerts"

작업 파일에 적는 것

위 예시의 최상위 키입니다. 필수는 name, tasks 두 개이고 나머지는 기본값이 있습니다.

name
작업 이름. 영문 소문자, 숫자, _만 씁니다. CLI와 알림에서 이 이름으로 찾습니다.
owner
책임 팀. 실패 알림과 대시보드의 담당자 칸에 표시됩니다.
schedule
언제 실행할지. cron, every, after 중 하나 이상을 씁니다. 없으면 수동 실행만 됩니다.
tasks
실행할 단계 목록. needs로 앞 단계를 지정하면 그 단계가 성공한 뒤에 시작하고, 의존 관계가 없는 단계는 동시에 돕니다.
retry
실패한 단계를 다시 시도하는 횟수와 간격. 기본값은 재시도 없음입니다.
notify
실패하거나 오래 걸릴 때 알림을 보낼 Slack 채널.

첫 작업 올리기

로컬에서 파일을 만들고 한 번 돌려 본 뒤 스케줄러에 등록합니다.

  1. CLI 설치

    Python 3.10 이상이 필요합니다.

    pip install flowkit

  2. 작업 파일 만들기

    jobs/daily_orders.yaml이 기본 템플릿으로 생성됩니다.

    flowkit init daily_orders

  3. 검사

    YAML 문법, 단계 사이의 순환 의존, 연결 이름(mysql.orders 같은)이 실제로 있는지 확인합니다.

    flowkit validate jobs/daily_orders.yaml

  4. 로컬에서 한 번 실행

    날짜를 지정해 실행합니다. 스케줄에는 영향이 없습니다.

    flowkit run daily_orders --date 2026-10-21

  5. 스케줄러에 등록

    등록이 끝나면 다음 예약 시각이 출력됩니다.

    flowkit deploy jobs/daily_orders.yaml

시작 전에

DB와 BigQuery 접속 정보는 파일에 적지 않습니다. 데이터플랫폼팀에 연결 이름을 등록해 두고, YAML에는 그 이름만 씁니다.

연결 목록은 flowkit connections로 볼 수 있습니다.

스케줄 지정

시각 기준, 간격 기준, 다른 작업 기준 세 가지가 있고 섞어 쓸 수 있습니다.

키예실행 시점
cron"0 3 * * *"매일 03:00
every15m이전 실행이 끝나고 15분 뒤
after[raw_orders]raw_orders 작업이 성공한 직후
cron + after"0 3 * * *", [raw_orders]03:00 이후, raw_orders가 그날 성공했을 때

timezone을 비워 두면 cron은 UTC로 해석됩니다. 한국 시각으로 돌리려면 Asia/Seoul을 적으세요.

등록한 뒤에 자주 쓰는 명령

상태 보기

최근 실행 10건과 단계별 소요 시간을 보여 줍니다.

flowkit status daily_orders

지난 기간 다시 돌리기

날짜마다 한 번씩, 순서대로 실행합니다.

flowkit backfill daily_orders --from 2026-10-01 --to 2026-10-07

잠시 멈추기

예약 실행만 멈춥니다. resume으로 다시 켭니다.

flowkit pause daily_orders

더 읽을 문서

  • YAML 레퍼런스모든 키와 기본값, 단계 유형별 옵션
  • 스케줄과 의존 관계작업 사이의 순서, 늦게 끝난 실행 처리, 휴일 건너뛰기
  • CLI 명령 전체run, backfill, logs 등 명령별 옵션
  • 크론탭에서 옮겨 오기기존 셸 스크립트를 작업 파일로 바꾸는 순서
