문서 보기
특징
스케줄, 의존성, 재시도, 알림은 파이프라인 YAML 파일에서 설정합니다.
선언적 정의
작업, 의존성, 환경 변수를 YAML로 적습니다. 일반 코드처럼 리뷰를 받고 버전을 관리할 수 있습니다.
내장 스케줄러
cron 표현식과 단축 문법을 지원하며, 타임존을 작업 단위로 지정할 수 있습니다.
의존성 그래프
으로 실행 순서를 정의하면 독립적인 작업은 자동으로 병렬 실행됩니다.
재시도와 백필
실패한 작업만 다시 실행하고, 과거 기간의 데이터를 날짜 범위로 다시 채울 수 있습니다.
사전 검증
로 배포 전에 문법 오류와 순환 의존성을 검사합니다.
실패 알림
작업이 실패하면 지정한 채널로 알림을 보냅니다. 알림 대상은 파이프라인마다 설정합니다.
빠른 시작
CLI를 설치하고 첫 파이프라인을 스케줄에 등록하는 순서입니다.
설치
사내 패키지 저장소에서 CLI를 설치합니다.
파이프라인 만들기
위 예시처럼 YAML 파일을 직접 작성하거나, 아래 명령으로 템플릿 파일을 만듭니다.
검증하고 실행
문법을 검사한 뒤 한 번 수동으로 실행해 결과를 봅니다.
스케줄 등록
등록하면 YAML의 에 따라 자동 실행됩니다.
스케줄 문법
필드에는 cron 표현식 또는 단축 문법을 쓸 수 있습니다.
