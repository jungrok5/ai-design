실시간 로그에서 필요한 줄만 골라 집계
logpipe는 로그에서 조건에 맞는 줄을 골라 키별로 집계하는 Go CLI 도구입니다. 로 이어 붙이던 작업을 명령 하나로 처리합니다.

필터, 집계, 출력을 명령 하나로
카드 위의 이름은 해당 기능에 쓰는 플래그나 입력입니다.
실시간 스트리밍
파일을 따라가며 새 줄을 즉시 처리합니다. 로그 로테이션도 자동으로 따라갑니다.
구조 인식 필터
JSON, logfmt, 일반 텍스트를 자동 감지하고 필드 단위로 조건을 겁니다. 정규식도 지원합니다.
즉석 집계
키별 카운트, 합계, 백분위수(p50/p95/p99)를 슬라이딩 윈도우로 계산합니다.
파이프 입출력
stdin을 읽고 stdout으로 씁니다. , 뒤에 파이프로 연결해 씁니다.
여러 출력 형식
결과를 표, JSON, CSV 중 하나로 출력합니다. JSON과 CSV는 다른 도구의 입력으로 넘길 수 있습니다.
의존성 없음
Go로 작성된 정적 바이너리입니다. 런타임 설치 없이 Linux·macOS·Windows에서 동작합니다.

동작 방식
로그 한 줄은 다음 다섯 단계를 거쳐 결과에 반영됩니다.
입력
파일을 따라가거나 stdin을 읽습니다.
파싱
JSON·logfmt·텍스트를 필드로 나눕니다.
필터
조건에 맞지 않는 줄은 버립니다.
집계
키별로 세고, 합하고, 백분위를 구합니다.
출력
새 줄이 들어올 때마다 결과를 다시 출력합니다.
설치
환경에 맞는 방법 하나를 고릅니다.
