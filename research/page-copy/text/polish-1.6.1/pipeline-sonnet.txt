flowkit에서는 작업 간 의존성, 재시도 횟수, 실행 주기를 코드가 아닌 YAML 설정으로 지정합니다.

문서 목록
기능
아래 기능은 파이프라인 YAML 파일과 flowkit CLI로 사용합니다.
선언적 정의
작업, 의존성, 환경 변수를 YAML로 적습니다. 파이프라인이 파일이므로 다른 코드와 같은 방식으로 버전을 관리하고 리뷰합니다.
내장 스케줄러
cron 표현식과 단축 문법을 지원합니다. 타임존은 작업마다 지정할 수 있습니다.
의존성 그래프
으로 실행 순서를 정하면, 서로 의존하지 않는 작업은 병렬로 실행됩니다.
재시도와 백필
실패한 작업만 다시 실행할 수 있습니다. 날짜 범위를 지정해 과거 기간의 데이터를 다시 채우는 백필도 지원합니다.
사전 검증
는 배포 전에 문법 오류와 순환 의존성을 검사합니다.
실패 알림
작업이 실패하면 파이프라인마다 지정한 채널로 알림을 보냅니다.
빠른 시작
CLI 설치부터 스케줄 등록까지의 순서입니다.
설치
사내 패키지 저장소에서 CLI를 설치합니다.
파이프라인 만들기
위 예시처럼 YAML 파일을 직접 작성하거나, 아래 명령으로 템플릿 파일을 만듭니다.
검증하고 실행
문법을 검사한 뒤, 한 번 수동으로 실행해 결과를 확인합니다.
스케줄 등록
배포한 파이프라인은 YAML의 에 따라 자동으로 실행됩니다.
스케줄 문법
필드에는 cron 표현식 또는 단축 문법을 쓸 수 있습니다.
표현
의미
매일 02:00
15분마다
평일 09:00
6시간마다 (직전 실행 완료 기준)
자동 실행 없이 수동으로만 실행
