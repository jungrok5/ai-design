장바구니 및 주문 화면 개발 — 쿠폰, 적립금, 배송비 계산 로직을 공통 훅으로 추출해 중복 코드를 제거했습니다.

주요 프로젝트
프로젝트 A — 상품 검색 UI
자동완성, 최근 검색어, 필터 조합을 지원하는 검색 화면입니다. 입력마다 나가던 요청을 디바운스하고 결과를 캐싱해 체감 응답 속도를 높였습니다.
프로젝트 B — 공통 UI 라이브러리
팀 내 여러 서비스에서 함께 쓰는 컴포넌트 라이브러리입니다. 접근성(WAI-ARIA)과 다크 모드를 기본으로 지원하고 문서 사이트를 함께 운영합니다.
프로젝트 C — 웹 성능 대시보드
배포마다 Lighthouse 점수와 Core Web Vitals를 수집해 추이를 보여주는 내부 도구입니다. 성능이 떨어지면 PR 단계에서 알림을 보냅니다.
