배치 작업을 YAML 파일로 정의하고 cron 주기로 실행합니다
flowkit은 데이터 수집, 변환, 적재 작업을 선언형 YAML 파일로 작성하고,
cron 표현식으로 실행 주기를 지정하는 배치 파이프라인 도구입니다.
실행 이력과 단계별 로그는 로 조회합니다.

주요 기능
작업 정의부터 실패 알림까지 flowkit이 처리하는 범위입니다.
선언형 YAML
로직은 단계 스크립트에 두고 흐름과 설정은 YAML에 두므로, 실행 순서 변경은 YAML 변경분만 보고 리뷰합니다.
의존성 그래프
으로 DAG를 구성하면 독립 단계는 병렬로 실행되고, 가 순환 여부를 검사합니다.
cron 스케줄링
표준 cron 표현식과 시간대를 지정하고, 등록한 스케줄을 일시 중지하거나 재개합니다.
재시도와 타임아웃
단계별 재시도 횟수와 백오프, 작업 단위 타임아웃을 설정합니다. 실패한 실행은 로 실패 단계부터 다시 시작합니다.
실행 이력과 알림
실행 결과와 단계별 로그를 보관하고, 실패 시 지정한 채널로 알림을 보냅니다.
템플릿 변수
같은 변수로 실행 날짜와 파라미터를 쿼리와 스크립트에 넣습니다. 기준 날짜는 로 바꿉니다.
