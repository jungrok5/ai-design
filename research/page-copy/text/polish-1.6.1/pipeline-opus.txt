flowkit 문서
배치 작업을 YAML로 정의하고, 정해진 시간에 실행하세요.
flowkit은 사내 데이터 파이프라인 도구입니다. 작업과 의존 관계, 실행 주기를 YAML 파일 하나에 적으면 스케줄링, 재시도, 실패 알림은 flowkit이 처리합니다.

핵심 개념
파이프라인을 정의하는 방식과 실행 중에 flowkit이 처리하는 일입니다.
YAML 하나로 정의
파이프라인 하나가 파일 하나입니다. Git으로 리뷰하고 버전을 관리할 수 있습니다.
cron 스케줄링
cron 표현식이나 같은 별칭으로 주기를 정합니다. 기본 시간대는 KST입니다.
의존성 기반 실행
로 순서를 적으면 flowkit이 DAG(Directed Acyclic Graph)를 만들고, 서로 의존하지 않는 작업은 병렬로 실행합니다.
재시도와 알림
실패한 작업은 지수 백오프로 재시도합니다. 재시도 횟수를 모두 쓰고도 실패하면 에 적은 Slack 채널로 알립니다.
빠른 시작
로컬에서 한 번 실행해 결과를 확인한 뒤 스케줄러에 배포합니다.
CLI 설치
사내 패키지 저장소에서 설치합니다. Python 3.10 이상이 필요합니다.
