배치 작업을 YAML로 정의하고 스케줄에 맡기세요.
flowkit은 데이터 수집, 변환, 적재 작업을 선언형 YAML 파일로 작성하고,
cron 표현식으로 실행 주기를 지정하는 배치 파이프라인 도구입니다.
코드를 줄이고, 실행 이력은 한곳에서 확인하세요.

복사
YAML로 작업 정의
하나의 파일이 하나의 배치 작업입니다. 작업 이름, 실행 주기, 재시도 정책, 단계(step)와
단계 사이의 의존 관계를 한 파일에 선언합니다.
복사

명령
설명
YAML 스키마와 DAG 순환 여부를 검사합니다.
작업을 즉시 한 번 실행합니다. 로 기준 날짜를 지정합니다.
스케줄을 등록합니다.
최근 실행 이력과 단계별 로그를 조회합니다.
실패한 실행을 실패 단계부터 다시 시작합니다.
주요 기능
작업 정의와 운영에 필요한 기능을 한 도구에 담았습니다.
선언형 YAML
로직은 단계 스크립트에, 흐름과 설정은 YAML에 둡니다. 코드 리뷰 대상이 명확해집니다.
의존성 그래프
으로 DAG를 구성하고, 독립 단계는 자동으로 병렬 실행합니다.
cron 스케줄링
표준 cron 표현식과 시간대 지정을 지원합니다. 일시 중지와 재개가 가능합니다.
재시도와 타임아웃
단계별 재시도 횟수와 백오프, 작업 단위 타임아웃을 설정할 수 있습니다.
실행 이력과 알림
실행 결과와 단계별 로그를 보관하고, 실패 시 지정한 채널로 알림을 보냅니다.
템플릿 변수
같은 변수로 실행 날짜와 파라미터를 쿼리와 스크립트에 주입합니다.
