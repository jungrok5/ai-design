1API 키 발급
모든 API 요청은 시크릿 키로 인증합니다. 처음에는 실제 돈이 오가지 않는 테스트 키로 시작하세요.
대시보드에 로그인한 뒤 개발자 → API 키 메뉴로 이동합니다.
상단 토글이 테스트 모드인지 확인합니다.

3웹훅 설정
가상계좌 입금, 취소, 비동기 승인처럼 요청 시점 이후에 일어나는 일은 웹훅으로 전달됩니다. 주문 상태의 기준은 API 응답이 아닌 웹훅 이벤트로 삼는 것을 권장합니다.
엔드포인트 등록
개발자 → 웹훅 → 엔드포인트 추가를 엽니다.
HTTPS URL을 입력합니다. (예: )
수신할 이벤트를 고릅니다: , ,
생성된 서명 비밀값을 에 저장합니다.
💡 팁
로컬 개발 중이라면 같은 터널링 도구로 공개 URL을 만들어 등록하세요.
서명 검증하고 이벤트 처리하기
모든 웹훅에는 헤더가 포함됩니다. 형식은 이며, 을 비밀값으로 HMAC-SHA256 한 값과 비교해 검증합니다. 반드시 파싱 전의 원본 본문(raw body)을 사용해야 합니다.

동작 확인과 재시도
대시보드의 웹훅 → 테스트 이벤트 보내기로 즉시 전송해 볼 수 있습니다.
2xx 이외의 응답이나 10초 초과 시 실패로 간주하며, 최대 24시간 동안 지수 백오프로 재전송합니다.
같은 이벤트가 두 번 올 수 있으니 로 중복 처리를 막으세요.
라이브 전환 체크리스트
테스트에서 모든 흐름이 확인되면 아래 항목을 점검하고 라이브 키로 교체하세요.
대시보드에서 사업자 심사를 완료하고 라이브 모드를 활성화했다
환경 변수의 키를 로 교체했고 저장소에 키가 남아 있지 않다
웹훅 엔드포인트를 라이브 모드에서 다시 등록하고 새 서명 비밀값을 적용했다
웹훅에서 서명·타임스탬프 검증과 중복 처리를 한다
결제 요청마다 를 사용한다
