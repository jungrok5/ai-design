로그를 흐르는 동안
필터링하고 집계하세요.

logpipe는 파일이나 표준 입력으로 들어오는 로그 스트림을 실시간으로 걸러내고, 원하는 기준으로 집계하는 단일 바이너리 CLI입니다. 로그를 디스크에 쌓아두고 나중에 뒤지는 대신, 흐르는 순간에 바로 답을 얻으세요.

시작하기 → GitHub에서 보기
$ go install github.com/your-org/logpipe@latest 
# 실시간 에러 로그만 추적하고, 5초 단위로 상태 코드별 개수를 집계
$ tail -F /var/log/app/access.log \
    | logpipe filter --match "level=error" \
    | logpipe count --by status --every 5s

5분 안에 첫 집계까지.

설치 후 바로 실행해 볼 수 있는 최소 예시입니다.

  1. Go 1.22 이상을 설치한 뒤 logpipe를 받아옵니다.

    go install github.com/your-org/logpipe@latest

  2. 로그 파일을 따라가며 조건에 맞는 줄만 출력해 봅니다.

    tail -F app.log | logpipe filter --match "level=warn"

  3. 같은 스트림을 10초 단위로 집계합니다.

    tail -F app.log | logpipe filter --match "level=warn" | logpipe count --every 10s
