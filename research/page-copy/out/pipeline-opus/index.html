flowkit 문서

배치 작업을 YAML로 정의하고,
정해진 시간에 실행하세요.

flowkit은 사내 데이터 파이프라인 도구입니다. 작업과 의존 관계, 실행 주기를 YAML 파일 하나에 적으면 스케줄링, 재시도, 실패 알림은 flowkit이 처리합니다.

빠른 시작 → YAML 레퍼런스
pipelines/daily_sales.yaml
name: daily_sales
owner: data-platform
schedule: "0 6 * * *"        # 매일 오전 6시 (KST)
retries: 3
notify:
  on_failure: "#data-alerts"

jobs:
  extract_orders:
    run: python extract.py --date {{ ds }}
  transform:
    needs: [extract_orders]
    run: sql transform/sales.sql
  load_warehouse:
    needs: [transform]
    run: python load.py --table sales_daily
    timeout: 30m

핵심 개념

flowkit이 알아서 해 주는 것들입니다.

YAML 하나로 정의

파이프라인 하나가 파일 하나입니다. Git으로 리뷰하고 버전을 관리하세요.

cron 스케줄링

cron 표현식이나 @daily 같은 별칭으로 주기를 정합니다. 기본 시간대는 KST입니다.

의존성 기반 실행

needs로 순서를 적으면 DAG를 만들어, 독립적인 작업은 병렬로 실행합니다.

재시도와 알림

실패하면 지수 백오프로 재시도하고, 끝내 실패하면 Slack 채널로 알립니다.

빠른 시작

설치부터 첫 실행까지 5분이면 됩니다.

  1. CLI 설치

    사내 패키지 저장소에서 설치합니다. Python 3.10 이상이 필요합니다.

    터미널
    $ pip install flowkit --index-url https://pypi.internal/simple
$ flowkit login

  2. 파이프라인 만들기

    템플릿으로 YAML 파일을 생성하고 jobs를 채웁니다.

    터미널
    $ flowkit init daily_sales
  ✓ pipelines/daily_sales.yaml 생성됨

  3. 검증 후 로컬에서 실행

    문법과 의존성을 검사한 뒤 특정 날짜로 한 번 돌려 봅니다.

    터미널
    $ flowkit validate pipelines/daily_sales.yaml
$ flowkit run daily_sales --date 2026-10-21 --local

  4. 배포

    배포하면 스케줄러에 등록되어 다음 주기부터 자동으로 실행됩니다.

    터미널
    $ flowkit deploy pipelines/daily_sales.yaml
  ✓ daily_sales 등록됨 · 다음 실행 2026-10-23 06:00 KST

주요 필드

자주 쓰는 필드만 모았습니다. 전체 목록은 YAML 레퍼런스를 보세요.

필드위치설명
name최상위파이프라인 고유 이름. 영문 소문자, 숫자, _만 씁니다.
schedule최상위cron 표현식 또는 별칭. 생략하면 수동 실행만 됩니다.
timezone최상위스케줄 기준 시간대. 기본값 Asia/Seoul.
retries최상위 · 작업실패 시 재시도 횟수. 작업에 적으면 그 값이 우선합니다.
run작업실행할 명령. {{ ds }}는 실행 기준 날짜로 바뀝니다.
needs작업먼저 성공해야 하는 작업 목록.
timeout작업최대 실행 시간 (45s, 30m, 2h).

스케줄 문법

표준 5필드 cron(분 시 일 월 요일)과 별칭을 지원합니다.

값의미
@hourly매시 정각
@daily매일 00:00
"0 6 * * *"매일 06:00
"*/15 * * * *"15분마다
"0 9 * * 1-5"평일 09:00
"0 2 1 * *"매월 1일 02:00
스케줄 미리보기
$ flowkit schedule "0 9 * * 1-5" -n 3
  2026-10-23 (목) 09:00 KST
  2026-10-26 (월) 09:00 KST
  2026-10-27 (화) 09:00 KST

참고: cron 값은 *로 시작하면 YAML이 다르게 해석할 수 있으니 항상 따옴표로 감싸세요.

자주 쓰는 명령어

flowkit --help로 전체 명령을 볼 수 있습니다.

명령설명
flowkit validate <file>YAML 문법, 순환 의존성, 스케줄 값을 검사합니다.
flowkit run <name>지금 바로 한 번 실행합니다. --local은 내 PC에서 실행합니다.
flowkit deploy <file>스케줄러에 등록하거나 갱신합니다.
flowkit status <name>최근 실행 결과와 다음 실행 시각을 보여 줍니다.
flowkit logs <name> --job <job>특정 작업의 로그를 봅니다.
flowkit backfill <name> --from --to지난 기간을 날짜별로 다시 실행합니다.
flowkit pause <name>스케줄 실행을 멈춥니다. resume으로 다시 켭니다.
