logpipe
기능 시작하기 GitHub

// 오픈소스 · Go로 작성

로그는 흘러가게 두고,
필요한 것만 건져 올리세요.

logpipe는 로그 파일을 tail하면서 실시간으로 필터링하고 집계하는 CLI 도구입니다. grep, awk, sort | uniq -c를 이어 붙이던 파이프라인을 명령 하나로 줄여 줍니다.

시작하기 GitHub에서 보기
$ go install github.com/your-org/logpipe@latest
~/app — logpipe
$ logpipe -f app.log --level ERROR,WARN --count-by service

위 화면은 동작을 설명하기 위한 예시 애니메이션입니다.

쓰던 방식 그대로, 더 간단하게

파일을 계속 따라가며 읽고, 조건에 맞는 줄만 골라, 바로 집계합니다. 별도 서버나 에이전트는 필요 없습니다.

follow

실시간 스트리밍

파일에 새로 쓰이는 줄을 즉시 읽어 처리합니다. 로그 로테이션 이후에도 이어서 따라갑니다.

filter

유연한 필터링

레벨, 정규식, 필드 값 조건으로 원하는 로그만 남깁니다. 조건은 여러 개 조합할 수 있습니다.

aggregate

즉석 집계

필드별 카운트와 시간 구간별 집계를 화면에서 바로 확인합니다. 따로 정렬하고 합칠 필요가 없습니다.

single binary

의존성 없는 바이너리

Go로 작성된 단일 실행 파일입니다. 서버에 복사해서 바로 실행할 수 있습니다.

pipe

파이프 친화적

표준 입력을 받고 표준 출력으로 내보내므로 기존 쉘 도구와 자연스럽게 연결됩니다.

open source

투명하게 공개

소스 코드는 모두 공개되어 있습니다. 이슈와 풀 리퀘스트를 환영합니다.

3단계로 시작하기

설치부터 첫 집계까지 1분이면 충분합니다.

1

설치

$ go install github.com/your-org/logpipe@latest
2

로그를 따라가며 필터링

# ERROR 레벨만 실시간으로 출력
$ logpipe -f app.log --level ERROR
3

집계 붙이기

# 서비스별 에러 수를 집계
$ logpipe -f app.log --level ERROR --count-by service

# 다른 명령과 파이프로 연결
$ kubectl logs -f web-0 | logpipe --level WARN,ERROR
