flowkit v1.0
특징 빠른 시작 스케줄 문서

사내 데이터 파이프라인 도구

배치 작업을 YAML로 정의하고, 스케줄까지 한 번에.

flowkit은 데이터 배치 작업을 선언적인 YAML 파일로 관리합니다. 작업 간 의존성, 재시도, 실행 주기를 코드 대신 설정으로 표현하세요.

빠른 시작 문서 둘러보기
daily_sales.yaml
name: daily_sales
schedule: "0 2 * * *"   # 매일 02:00
timezone: Asia/Seoul

tasks:
  - id: extract
    run: python extract_orders.py
    retries: 3

  - id: transform
    run: dbt run --select sales
    depends_on: [extract]

  - id: load
    run: python load_dw.py
    depends_on: [transform]

특징

파이프라인 운영에 필요한 기본기를 YAML 하나로 다룹니다.

{ }

선언적 정의

작업, 의존성, 환경 변수를 YAML로 기술합니다. 코드 리뷰와 버전 관리도 그대로 적용됩니다.

◷

내장 스케줄러

cron 표현식과 every 단축 문법을 지원하며, 타임존을 작업 단위로 지정할 수 있습니다.

→

의존성 그래프

depends_on으로 실행 순서를 정의하면 독립적인 작업은 자동으로 병렬 실행됩니다.

↻

재시도와 백필

실패한 작업만 다시 실행하고, 과거 기간의 데이터를 날짜 범위로 다시 채울 수 있습니다.

✓

사전 검증

flowkit validate로 배포 전에 문법 오류와 순환 의존성을 잡아냅니다.

!

실패 알림

작업이 실패하면 지정한 채널로 알림을 보냅니다. 알림 대상은 파이프라인마다 설정합니다.

빠른 시작

5분 안에 첫 파이프라인을 실행해 보세요.

  1. 설치

    사내 패키지 저장소에서 CLI를 설치합니다.

    $ pip install flowkit

  2. 파이프라인 만들기

    위 예시처럼 YAML 파일을 작성하거나 템플릿으로 시작하세요.

    $ flowkit init daily_sales

  3. 검증하고 실행

    문법을 확인한 뒤 한 번 수동으로 실행해 결과를 확인합니다.

    $ flowkit validate daily_sales.yaml
$ flowkit run daily_sales.yaml

  4. 스케줄 등록

    등록하면 YAML의 schedule에 따라 자동 실행됩니다.

    $ flowkit deploy daily_sales.yaml
$ flowkit status

스케줄 문법

schedule 필드에는 cron 표현식 또는 단축 문법을 쓸 수 있습니다.

표현의미
"0 2 * * *"매일 02:00
"*/15 * * * *"15분마다
"0 9 * * 1-5"평일 09:00
every: 6h6시간마다 (직전 실행 완료 기준)
manual자동 실행 없이 수동으로만 실행
