API 키 발급
약 2분
Paygrid 대시보드에 로그인합니다. 계정이 없다면 이메일로 가입하세요. 가입 즉시 테스트 모드를 쓸 수 있습니다.
왼쪽 메뉴에서 개발자 → API 키로 이동합니다.
테스트 키 만들기를 누르고, 화면에 한 번만 표시되는 시크릿 키를 복사해 둡니다.
키는 두 종류이며, 접두사로 환경과 용도를 구분합니다.

키를 환경 변수로 저장한 뒤, 잘 동작하는지 확인합니다.

웹훅 설정
약 8분
결제 결과는 API 응답만 믿지 말고 웹훅으로 한 번 더 확인하세요. 고객이 결제 도중 창을 닫거나, 카드사 승인이 늦게 오는 경우에도 웹훅은 최종 상태를 알려줍니다.
