빠른 시작
테스트 키를 발급받고, 1,000원짜리 테스트 결제를 한 번 보내고, 결제 완료를 웹훅으로 받는 데까지 따라 합니다. 실제 돈은 움직이지 않습니다.

Tolpay 계정(사업자 등록 없이 테스트 모드 사용 가능), 터미널, Node.js 18 이상

API 키 발급
모든 요청은 비밀 키로 인증합니다. 가입하면 테스트 키가 바로 만들어지고, 라이브 키는 사업자 심사가 끝난 뒤에 열립니다.

웹훅 받는 서버 만들기
