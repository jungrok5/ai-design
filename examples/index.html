Clear 디자인 시스템

흰 바탕과 진한 남색 글자, 동작과 사람의 판단에만 쓰는 파란색 하나로 구성합니다. 다크 테마는 그래파이트입니다. 이 페이지의 모든 값은 토큰에서 옵니다.

색 토큰

--bg
--surface
--fg
--accent
--accent-soft
--code-bg

실행할 명령: .ds-cmd

make setup      # 의존성 설치와 검사 준비
make check      # 린트, 타입체크, 테스트

순서: .ds-steps

  1. 이슈 등록

    양식대로 작성합니다.

  2. 작업 승인

    사람이 판단하는 단계는 파란 번호로 표시합니다.

    사람

  3. 머지

    검사를 통과하면 반영합니다.

비교: .ds-table
